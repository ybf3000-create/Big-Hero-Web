# 大勇者 Godot Web 客户端

本目录使用Godot 4.4开发浏览器游戏。自2026-09-16起，只维护Web交付，不开发、发布或验收桌面原生客户端。玩法改动仍在本目录的GDScript、场景和素材中实现，继续复用原版UI、透视地图、逐格移动、装备、技能与战斗表现；不切换到已停用的`web-client/`原型。

## 开发与发布

| 步骤 | 要求 | 失败处理 |
|------|------|----------|
| 确认规则 | 以本地策划案《网页网络游戏改造总案【定案】》§3.3和对应系统定案为准；`策划案/`目前未上传本仓库 | 代码与定案冲突或表现不明确时先讨论，不自行简化或改变数值 |
| 修改源码 | 复用现有GDScript、场景、素材和规则回归 | 不为旧桌面客户端另做功能或兼容分支 |
| 检查脚本 | 在仓库根目录执行`client\tools\check-gdscript.ps1` | 任一GDScript无法解析时停止发布 |
| 导出网页 | 使用`export_presets.cfg`中的`Web`预设，保持`variant/thread_support=false`，导出到`../SERVER/public/game/index.html` | 导出失败时不发布旧包冒充新版本；线程开启时重新导出 |
| 兼容与自动检查 | 在`SERVER`目录执行`npm run web:patch`和`npm run check` | 检查失败则修复后重试，不跳过HTTP兼容检查 |
| 浏览器验收 | 用真实导出包验证Chrome/Edge及ZeroTier入口 | 编辑器运行不作为浏览器功能通过的证据；跨机访问需另一台电脑验证 |

Godot编辑器可用于开发和检查，但不是面向玩家的客户端。旧桌面入口和本地存档代码暂留作参考，不迁移玩家旧存档，不上传客户端资产快照覆盖服务端。

## 玩家入口与当前进度

玩家通过`http://服务器的ZeroTier地址:3000/game/`进入游戏，需先安装、加入并获准使用同一ZeroTier网络；服主完成监听与防火墙配置后，玩家无需证书或额外命令。详细部署和失败处理见[服务端说明](../SERVER/README.md) §2、§4。真正公网开放仍需HTTPS/WSS，不能直接沿用ZeroTier私网HTTP方案。

当前Web包已恢复Godot原版表现并接入账号、单角色、WebSocket会话、聊天和拍卖行；地图、Boss 1～200、装备、宝石、技能、属性点、掉落、彩票、离线收益和战斗均由服务端计算，客户端只发送操作意图并播放服务器结果。HTTP响应丢失、战斗中断线或WebSocket重连时，主界面会重新读取服务器快照；若服务器已经提交战斗，奖励会直接出现在服务器背包中，不会因重试重复结算。另一台ZeroTier电脑的跨机验收仍需实际执行。

> 设计柱检验：复用原版客户端保护柱2的Build深度与柱4的格子策略；只维护一种交付形态降低柱5的维护负担；权威资产不信任客户端快照，保护柱6的玩家经济。
