## 0-A. 术语表（必读）

本文档涉及多种"等级"，按以下约定区分：

| 术语 | 符号 | 范围 | 含义 | 何时变化 |
|------|------|------|------|---------|
| **玩家等级** | `Lv` | 1→100 | 角色的经验等级，决定基础HP/ATK/DEF | 战斗获得EXP |
| **档位** | `Tier` | 0→200 | 已击败Boss数量，决定怪物难度 | 击败Boss |
| **Boss序号** | `Boss#` | 1→200 | 第几只Boss，每次击败+1 | 击败Boss |
| **装备档位(EqTier)** | — | 1→138+ | 装备等级系数来源 = Lv + floor(BossTier/X) | 掉落时快照 |
| **强化等级** | — | 0→200/槽 | 槽位强化次数，提升该槽位装备主属性 | 🔨锻造格触发 |
| **品质** | — | 普通/精良/稀有/史诗/传说 | 装备品质，影响主属性倍率和词条数 | 掉落时随机 |

> **核心关系**：档位 = Boss# = 已击败Boss数。档位驱动怪物难度。Lv(1→100) + Boss档位共同驱动装备档位。
> Lv持续成长到100，封顶后装备档位通过Boss推进继续增长。

```
装备占比(Lv) = 0.05 + 0.75 × (Lv - 1) / 99
总属性 = 基础属性 / (1 - 装备占比)
装备属性 = 总属性 - 基础属性
```

### 1.4 总攻击力公式（修正）

```
总攻击力 = (基础攻击力 + 装备攻击力) × (1 + 自由攻击点×0.018 + 装备攻击% + 套装/buff%)
```

### 1.5 总 HP 公式

```
总HP = (基础HP + 装备生命值) × (1 + 装备生命%)
```

## 2. 防御公式（重制 v1.0）

### 2.1 废弃旧公式

```
~~旧: 减伤 = max(0.05, 1 - DEF/(DEF + 85×Lv + 400))~~
问题: Lv.50 时 320 防仅减伤 6.3%，防御是废属性。
```

### 2.2 新公式 [已锁定]

```
防御减伤率 = DEF / (DEF + 400)

特征:
  - 无等级衰减 → 每点防御始终有效
  - 边际递减 → 堆高仍有收益但非线性
  - 50% 减伤需要 400 防
  - 无保底 → 0 防 = 0% 减伤（白板就是脆）
```

| 总 DEF | 减伤率 | 等效 HP 倍率 | 说明 |
|--------|--------|-------------|------|
| 0 | 0.0% | ×1.00 | 裸体 |
| 16 (Lv.1) | 3.8% | ×1.04 | 新手 |
| 50 | 11.1% | ×1.13 | |
| 100 | 20.0% | ×1.25 | |
| 150 | 27.3% | ×1.38 | |
| 200 | 33.3% | ×1.50 | 中期 |
| 300 | 42.9% | ×1.75 | |
| 320 (Lv.50) | 44.4% | ×1.80 | 满配 |
| 400 | 50.0% | ×2.00 | 极限 |
| 500 | 55.6% | ×2.25 | 理论极值 |

### 2.4 自由防御减伤（乘算叠加）

```
自由防御减伤 = min(自由防御点 × 1.2%, 50%)
最终伤害 = 原始伤害 × (1 - 防御减伤率) × (1 - 自由防御减伤)
```

> 两层乘算：满防 44.4% + 满自由防 50% → 伤害 = 原始 × 0.556 × 0.5 = 原始 × 0.278（等效 HP ×3.6）

## 3. 档位驱动怪物系统（v2.1 重写）

### 3.0 核心设计理念

```
怪物为什么不锚定玩家属性？

  锚定玩家 → 装备变好→怪物跟着变强→成长感归零 ❌
  锚定档位 → 档内怪物固定→玩家刷装备变强→碾压当前档→挑战Boss提档→新挑战 ✅

循环: [进入新档位] → [怪稍强, 被压制] → [刷装备/升级] → [碾压档内怪] → [挑战Boss] → [提档!]
                                                                              ↓
                                                                      [更高奖励+更强怪物]
```

### 3.1 档位参考属性表（v2.2 计入全部养成）

每个档位有固定的"参考玩家属性"——代表刚进入该档位的**典型玩家全养成状态**。
怪物数值从这些参考值衍生，**不随该档位内玩家的实际成长浮动**。

#### 参考属性计算公式

```
参考 ATK = (基础ATK + 装备ATK_baseline × 强化倍率) × (1 + 自由点% + 词条% + 套装%) + 宝石ATK
参考 DEF = (基础DEF + 装备DEF_baseline × 强化倍率) × (1 + 词条% + 套装%) + 宝石DEF
参考 HP  = (基础HP  + 装备HP_baseline  × 强化倍率) × (1 + 词条% + 套装%) + 宝石HP

其中：
  · 基础ATK/DEF/HP = §1.1 等级公式
  · 装备ATK/DEF/HP_baseline = §1.2 该等级"装备属性"列（未强化时的装备白值）
  · 强化倍率 = 1 + 0.03 × 强化等级（每个槽位独立，取预期均值）
  · 自由点% = 自由攻击点 × 0.018 / 自由防御点 × 0.012（上限50%）
  · 词条% = 装备附加词条攻击%/防御%/生命%总和的预期均值
  · 套装% = 15%（13套任一套装提供10~15%攻击加成，取均值）
  · 宝石ATK/DEF/HP = 镶嵌宝石的数值总和（线性成长: 红/蓝+10/级, 绿+50/级; 24孔上限; ATK/DEF/HP按50/25/25%分配）
```

### 3.4 Boss [已锁定]

```
Boss HP  = 普通 HP × Boss_HP_Multiplier
Boss ATK = 普通 ATK × Boss_ATK_Multiplier

Boss_HP_Multiplier  = 8 + Boss# × 0.15     (Boss1=8.15, Boss200=38)
Boss_ATK_Multiplier = 1.5 + Boss# × 0.003   (Boss1=1.503, Boss200=2.1)
Boss 出手 CD = 3.0 × (1-速度点×0.008)（Boss1~15=标准15→2.64s, Boss16~50=快速25→2.40s, Boss51~200=极速35→2.16s）
Boss 等级    = 玩家等级 + 2
```

## 4. 装备主属性基础值 [新]

### 4.1 计算逻辑

```
装备主属性 = 装备占比 × 总属性
分配到 8 个槽位 + 加成（强化/宝石/套装）后，反推每槽基础值

简化方法：
  每槽基础值(EqTier, 品质) = BaseValue × 等级系数 × 品质系数
  
  等级系数 = 1 + (EqTier - 1) × 0.015   ← 使用装备档位，非玩家等级
  品质系数：普通 1.0 / 精良 1.2 / 稀有 1.5 / 史诗 2.0 / 传说 3.0
```

## 5. 伤害管道（修正版）

### 5.1 全流程 [已锁定]

```
Step 1 — 原始伤害 = 总攻击力 × 技能倍率（普攻=100%）

Step 2 — 防御减伤（重制公式）
  伤害 = 原始伤害 × (1 - DEF / (DEF + 400))

Step 3 — 自由防御减伤
  伤害 = 伤害 × (1 - min(自由防御点 × 0.012, 0.50))

Step 4 — 命中判定
  实际闪避 = max(0, 目标闪避 - 我方命中)
  掷骰 < 实际闪避 → MISS（伤害=0）

Step 5 — 暴击判定（所有攻击，含普攻）
  掷骰 < 暴击率 → 伤害 × 暴击伤害倍率（基础 150%）

Step 6 — 格挡判定
  掷骰 < 格挡率 → 伤害 × 0.5
  暴击+格挡可同时 → 伤害 × 暴击倍率 × 0.5

Step 7 — 其他修正（神祇/buff/套装 乘算叠加）

Step 8 — 吸血 = 最终伤害 × 吸血%

Step 9 — 护盾吸收 → 剩余扣 HP
```

### 5.2 与旧版差异

| 项目 | 旧版 v0.1 | 新版 v1.0 |
|------|----------|----------|
| 防御公式 | DEF/(DEF+85Lv+400) | DEF/(DEF+400) |
| 普攻暴击 | 不暴击 | **可暴击**（统一判定） |
| 怪物防御 | 套玩家公式 | 档位固定 DR% |

## 8. 离线收益（v2.0：12h离线=0.8×12h在线）[已锁定]

### 8.1 核心公式

```
离线每小时金币 = min(怪物Lv, 100) × K_gr × 1200 × 离线系数 × (1+金币加成%)

K_gr = 2.50（v2.2：普通3.5+精英7.5+挑战14 加权）
离线系数 = 0.8

在线每小时 = min(怪物Lv, 100) × K_gr × 1200

验证 (MLv=50, Lv.50玩家):
  在线每小时 = 50 × 2.50 × 1200 = 150,000
  离线每小时 = 150,000 × 0.8 = 120,000
  离线12h = 1,440,000
  在线12h = 1,800,000
  比值 = 0.8 ✓
```

### 8.2 离线规则

```
掷骰间隔 = 3s | 12h 上限 | 仅战斗格收益
普/精/挑比例按在线格子分布（38%/10%/3%）
全胜计算（挂机游戏，离线=纯收益）

离线 EXP = 同公式，EXP系数替换为 K_exp
  K_exp = 普通(38%)×14 + 精英(10%)×32.5 + 挑战(3%)×60
        = 5.32 + 3.25 + 1.80
        = 10.37

装备掉落 = 按在线掉率独立判定（15%基础+幸运修正）
```

### 8.3 边界情况

```
离线 > 12h → 仅计算 12h，超出不累计
离线 < 1min → 不计算，直接继续在线
离线期间复活币 → 不消耗
离线期间背包满 → 自动分解最低品质未锁定装备
非战斗格 → 离线不触发（宝箱/命运/神祇等）
```
