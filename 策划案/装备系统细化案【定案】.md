# 装备系统细化案 v1.8

> 对应 GDD §6 装备系统 + §11 宝石 + §12 强化
> 版本：v1.8 | 日期：2026-09-23 | 状态：已定案
> v1.7→v1.8 变更：新增绑定锁定的新手训练剑与旧角色一次性补发；装备奖励在首次集齐8部位前优先生成未拥有部位，集齐后恢复均匀随机。

## 1. 装备品质与等级

### 1.1 品质体系

```
普通(灰) → 精良(绿) → 稀有(蓝) → 史诗(紫) → 传说(橙)
```

| 品质  | 颜色  | 主属性     | 附加随机词条 | 套装词条     |
| --- | --- | ------- | ------ | -------- |
| 普通  | 白   | 1 条（固定） | 1 条    | 可出（概率最高） |
| 精良  | 绿   | 1 条（固定） | 2 条    | 可出       |
| 稀有  | 蓝   | 1 条（固定） | 3 条    | 可出       |
| 史诗  | 紫   | 1 条（固定） | 4 条    | 可出（概率较低） |
| 传说  | 橙   | 1 条（固定） | 5 条    | 可出（概率最低） |

> **核心改动**：套装与品质脱钩。普通装备也能出套装词条，品质越低套装出现概率越高。
> 玩家抉择：穿低品质凑套装吃效果 vs 穿高品质靠属性硬打。

### 1.2 套装出现概率（独立于品质判定）

```
每件装备生成时，独立判定是否附带套装词条。

套装概率公式：
  套装概率 = (3% + 幸运 × 0.3%) × 品质修正

品质修正（品质越低概率越高，鼓励"低品凑套装"策略）：
  普通(灰) → ×1.5 → 基础 4.5%
  精良(绿) → ×1.2 → 基础 3.6%
  稀有(蓝) → ×1.0 → 基础 3%
  史诗(紫) → ×0.7 → 基础 2.1%
  传说(橙) → ×0.4 → 基础 1.2%

例：幸运 20 点 + 普通品质 → (3% + 20×0.3%) × 1.5 = 9% × 1.5 = 13.5%
例：幸运 50 点 + 传说品质 → (3% + 50×0.3%) × 0.4 = 18% × 0.4 = 7.2%

若判定通过 → 从 13 套中均匀随机 1 套作为该装备的套装类型
```

### 1.3 装备等级

```
装备等级 = 掉落时玩家等级（快照机制）

影响：
  - 主属性数值（高等级更强）
  - 附加词条 roll 值（高等级 roll 更高）
  - 分解产出

不影响：
  - 品质 / 词条数量 / 套装概率 / 强化上限（槽位强化上限固定+200）
```

### 1.4 掉落品质概率（不变）

```
普通(灰) 60% / 精良(绿) 28% / 稀有(蓝) 10% / 史诗(紫) 1.7% / 传说(橙) 0.3%
修正：战斗类型/幸运/福神/宝箱建设格 → 见 [[大地图规则细化案【定案】]] §2
```

### 1.5 新手武器与首次集齐保护

| 项目 | 规则 |
|------|------|
| 新角色 | 创建时获得普通训练剑，固定攻击力+40、0词缀、0孔、无套装，自动装备 |
| 保护状态 | 训练剑默认锁定且交易绑定；可手动解锁、卸下或分解，但永久不可上架拍卖 |
| 旧角色补发 | 旧存档首次加载时，若装备背包不存在任何武器且从未执行过补发，则补发并自动装备1把；只执行一次 |
| 缺失部位判定 | 服务器检查装备背包已有部位，已装备物也因保留在装备背包而计入 |
| 缺失部位顺序 | 武器→防具→鞋子→戒指→项链→披风→头盔→护符；奖励生成时取第1个未拥有部位 |
| 集齐后 | 8个部位均至少拥有1件后，恢复8部位等概率随机，每个部位12.5% |
| 明确指定部位 | 装备合成等规则明确指定产出部位时，以该规则为准，不触发缺失部位替换 |

```text
成功：背包有空间且存在未拥有部位 → 本次装备奖励生成该部位，再按原品质、词缀、套装流程生成。
失败：装备背包已满 → 沿用§10与[[背包道具货币系统案【定案】]]的满格处理，不额外扩容或覆盖锁定装备。
自动分解：缺失部位装备生成后仍执行玩家的自动分解规则；若被分解，该部位仍视为未拥有，后续奖励继续优先该部位。
旧角色满包：无法放入训练剑时本次不补发，也不写入“已补发”；玩家腾出空间并再次上线后重试。
玩家主动分解训练剑：已写入“补发完成”，之后不会反复领取训练剑；正常装备奖励仍会优先补回武器部位。
```

性能：每次装备生成只检查固定8个部位，时间与空间开销均为常数级；不遍历其他玩家，也不增加数据库查询。

> 设计柱检验：新手武器切断“无武器→战败→无掉落→继续无武器”的负反馈；首次集齐保护只控制部位、不提高品质和套装概率，满足柱5且保留柱2的长期刷装深度。

### 1.3 装备命名规则

装备名称由 **品质前缀 + 套装标识(可选) + 部位基础名** 三段构成，在装备生成时同步确定。

#### 1.3.1 命名公式

```
装备全名 = [品质前缀] + [套装标识] + [部位基础名]

品质前缀 — 由品质决定（固定）
套装标识 — 仅当装备拥有套装词条时出现，取套装名
部位基础名 — 由部位决定（固定），品质为史诗/传说时升级为高阶基础名
```

#### 1.3.2 品质前缀

| 品质 | 前缀 |
|------|------|
| 普通(灰) | （无前缀） |
| 精良(绿) | 精良的 |
| 稀有(蓝) | 稀有的 |
| 史诗(紫) | 史诗的 |
| 传说(橙) | 传说的 |

#### 1.3.3 部位基础名

| 部位  | 基础名（普通~稀有）          | 高阶名（史诗~传说）        |
| --- | ------------------- | ----------------- |
| 武器  | 剑 / 弓 / 法杖（3选1随机）   | 圣剑 / 龙弓 / 贤者法杖    |
| 防具  | 皮甲 / 锁甲 / 板甲（3选1随机） | 龙鳞甲 / 暗影战甲 / 圣盾铠甲 |
| 鞋子  | 靴子                  | 疾风之靴              |
| 戒指  | 戒指                  | 王者之戒              |
| 项链  | 项链                  | 星辰项链              |
| 披风  | 披风                  | 暗影斗篷              |
| 头盔  | 头盔                  | 王者头盔              |
| 护符  | 护符                  | 守护圣符              |

> 武器/防具的基础名在 3 种中均匀随机（各 33.3%），为装备增加视觉多样性。

#### 1.3.4 装备命名实例

| 品质  | 套装  | 部位名称   | 生成名称       | 说明                     |
| --- | --- | ------ | ---------- | ---------------------- |
| 普通  | 龙鳞  | 武器（剑）  | 龙鳞剑        | 普通无品质前缀 + 龙鳞套装标识 + 基础名 |
| 精良  | 无套装 | 鞋子     | 精良的 靴子     | 精良品质前缀 + 无套装标识 + 基础名   |
| 稀有  | 烈焰  | 防具（板甲） | 稀有的 烈焰板甲   | 稀有的 + 烈焰 + 板甲          |
| 史诗  | 雷霆  | 戒指     | 史诗的 雷霆王者之戒 | 史诗 + 雷霆 + 高阶名"王者之戒"    |

| 传说  | 无套装 | 头盔     | 传说的 王者头盔   | 传说 + 无标识 + 高阶名         |

#### 1.3.5 命名与词缀的关系

```
装备名称不直接包含词缀信息——词缀通过装备详情面板展示。
```

#### 1.3.6 名称唯一性与显示

```
装备名仅为展示用途，不要求唯一性。
同名装备可以同时存在（如两件"稀有的 龙鳞剑"），通过词缀/强化等级/孔数区分。

UI 显示规则：
  品质色边框 + 装备名称（品质色文字）
  例：橙色边框 +"传说的 引力贤者法杖"（橙色文字）
```

> **设计柱检验**：命名规则满足柱 3（世界观统一 — 品质与名称视觉挂钩，高阶名拉开品质差距）+ 柱 5（不肝不氪 — 名称仅展示，无附加属性，不产生强迫收集压力）。名称中的套装标识让玩家在拍卖行/背包中一眼识别套装归属。

## 2. 装备属性体系

### 2.1 主属性（每个部位固定 1 条，不随机）

| 槽位 | 固定主属性 | 说明 |
|------|-----------|------|
| 武器 | **攻击力** | 基础伤害来源 |
| 防具 | **防御力** | 基础减伤来源 |
| 鞋子 | **闪避率** | 基础生存 |
| 戒指 | **暴击率** | 均衡输出 |
| 项链 | **技能伤害** | 技能增幅 |
| 披风 | **速度** | 出手频率 |
| 头盔 | **格挡率** | 基础格挡 |
| 护符 | **生命值** | 基础血量 |

> **核心改动**：主属性不再随机。武器一定加攻击力、防具一定加防御力。
> 避免"武器随机到暴击率但没有任何攻击力"的尴尬。

```
主属性数值 = 基础值 × 品质系数 × 装备档位系数
品质系数：普通 1.0 / 精良 1.2 / 稀有 1.5 / 史诗 2.0 / 传说 3.0
装备档位系数：1 + (EqTier - 1) × 0.015
  EqTier（装备档位）= 玩家Lv + Σfloor(BossTier / X)（见数值设计总表 §4.0）

受装备档位系数影响的属性（纯数值类）：
  攻击力、防御力、生命值、速度
不受装备档位系数影响的属性（百分比类，仅品质系数生效）：
  闪避率、暴击率、技能伤害%、格挡率
  理由：百分比类若随档位膨胀会导致后期堆到100%+，失去设计空间。
```

## 3. 词条生成规则

### 3.1 生成流程

```
[装备掉落时]

Step 1 — 确定品质（按掉落权重随机）
Step 2 — 确定主属性（该部位固定属性，纯数值类=基础值×品质系数×装备档位系数，百分比类=基础值×品质系数）
Step 3 — 确定附加词条数量（品质对应 + 额外1条随机附加属性）
        普通=1条 / 精良=2条 / 稀有=3条 / 史诗=4条 / 传说=5条
Step 4 — 逐条抽取附加词条（冲突检查+重抽≤5次）
        抽取时仅从该部位可出的词条池中随机（见 §2.2 投放限制）
Step 5 — 检查类别上限（攻击类≤2条，防御类≤2条，通用类不限）
        攻击%和暴击率已通过部位限制自然减半，此处不再单独削减
Step 6 — **独立判定套装词条**（不影响品质、不影响词条数）
        套装概率 = (3% + 幸运 × 0.3%) × 品质修正（见 §1.2）
        若通过 → 从13套中均匀随机1套，附带该套的1条专属词条
Step 7 — 各词条独立随机数值（在对应范围内 roll）
Step 8 — 确定插孔数（见 §7.3 打孔规则）
```

### 3.2 套装词条与套装身份的关系

```
套装身份与专属词条是绑定的：

  装备属于某套装 ⟺ 该装备拥有1条该套装的专属词条

  例：装备上有"【龙鳞】-硬皮" → 该装备属于龙鳞套装
      装备上没有任何【套装名】-xxx 词条 → 该装备不属于任何套装

生成流程：
  Step 6 掷骰通过 → 分配套装 → 从该套4条专属词条中随机1条（额外，不占附加词条位）
  Step 6 掷骰未通过 → 无套装 → 无专属词条

玩家辨认方式（UI）：
  1. 专属词条前缀【套装名】直接标识归属（如"【龙鳞】-硬皮"）
  2. 装备名称颜色边框 → 带套装的装备显示对应套装的色调边框
  3. 装备详情页 → 显示"套装：龙鳞 (1/4)"，当前已装备几件该套装
  4. 套装效果预览 → 已凑齐2/3/4件时，对应效果高亮显示

同名专属词条效果不叠加，但算套装件数：
  若玩家拥有 2 件带"【龙鳞】-硬皮"的装备 → 只生效 1 次，但 2 件都算龙鳞件数。
  若拥有"【龙鳞】-硬皮"+"【龙鳞】-再生"+"【龙鳞】-坚韧"+"【龙鳞】-龙威" → 4 条全生效 = 极品。
  不同词条名但效果相同可叠加（如"【口才】-魅力"+"【口才】-超级魅力" = 普通+10%）。
  完整叠加规则见 §4.6。
```

### 3.3 附加词条冲突规则

```
§3.1 Step 4 中"冲突检查+重抽≤5次"的冲突定义：

冲突类型（3类）：
  ① 同词条重复：同一件装备不能出现2条同名词条（如2条"暴击率"）
  ② 百分比/数值互斥：攻击% 与 攻击(数值) 互斥，防御% 与 防御(数值) 互斥
  ③ 类别上限超标：加入后攻击类>2条 或 防御类>2条

重抽流程：
  抽第N条附加词条时：
    1. 从17条词条池随机抽1条
    2. 冲突检查：
       - 与本件已有词条重复？ → 冲突
       - 与本件已有词条互斥（攻击%↔攻击数值）？ → 冲突
       - 加入后该类别超标（攻击>2 / 防御>2）？ → 冲突
    3. 若冲突 → 重新抽取（最多重试5次）
    4. 5次仍冲突 → 该词条位作废（不补）

设计意图：5次上限防止死循环（词条池小时大部分冲突），作废比死循环更合理。
极端情况：攻击类已满2条 + 剩余需抽3条 → 可能有2条攻击类冲突作废，最终防御+通用填满。
```

### 4.3 设计说明

```
套装设计原则：

1. 2/3/4 件套：8 个格子中留 4 个自由位，允许"4+4"、"4+2+2"、"2+3+3"、"2+2+2+2"混搭

2. 铁壁（格挡）与幻影（闪避）互补：
   - 铁壁=格挡流（稳定减伤 + 生命反伤 + 护盾续航）
   - 幻影=闪避流（高风险高回报 + 闪避后反击增伤）

3. 口才套（搞怪）：利用"口才"说服敌人，概率跳过普通/精英战斗
   - 不触发 Boss/挑战，避免破坏核心体验
   - 配合幸运属性可堆高概率

4. 奢侈套（搞怪）：扣钱换战力，高风险 Build
   - 金币归零后效果失效，玩家需要持续"赚钱养套"

5. 引力套（终局刷宝）：核心终局玩法，突破8格2套上限
   - 3件幸运+15：提高所有幸运相关判定（含自身4件的双词条概率）
   - 4件1%（受幸运加成）使装备额外获得1条不同套装词条
   - 终局目标：刷出多件双套装词条装备 → 8格实现3套甚至4套搭配
   - 自循环：3件+15幸运 → 4件双词条概率从1%提升 → 越多幸运越容易出

5. 暗影套（暗杀/先手）：体验链 = 先手爆发 → 连杀滚雪球
   - 2件：暴击伤害+25%（铺垫伤害基础）
   - 3件：战斗开场5秒高暴击+高命中（确保先手爆发，不可驱散/刷新）
   - 4件：击杀→必暴×2.5+重置出手CD（可连续出手）→ 击杀新敌人刷新持续时间 → 滚雪球连杀
   - 核心风险：若5秒内未能击杀任何敌人，暗影潜行结束后爆发力骤降

6. 幻影3件"最终伤害+50%"：加在伤害管道 Step 5（其他修正层），乘算叠加

7. 概率触发型套装效果与 AOE/多段攻击的交互规则：
   - 每次攻击动作（1次普攻或1次技能释放）对每个目标独立掷骰判定
   - AOE 技能打 N 个目标 → 每目标各自掷骰
   - 多段攻击技能（如连击 ×2次）→ 每段独立掷骰，每次命中都是独立判定机会
   - 例：冰霜套 3 件 + 连击打 1 个目标 → 掷骰 2 次，每次 <15% 即冰冻
   - 例：冰霜套 3 件 + AOE 打 3 个目标 → 每目标掷骰 1 次，共 3 次
```

### 4.4 引力套装——终局刷宝核心

```
引力套是游戏的终局玩法之一。

核心价值：让1件装备携带2条不同套装的专属词条，
         从而在不占用额外装备格子的前提下获得第2个套装的效果。
         这是突破"8格=2套"上限的唯一途径。

引力 4 件效果触发流程：

  前提条件：
    ① 玩家已凑齐引力 4 件套
    ② 掉落的装备已通过 §1.2 套装概率判定（即该装备本身有套装词条）

  触发判定：
    基础概率 = 1%
    幸运加成 = 每点幸运 +0.2%（加算到基础概率上）
    例：幸运 50 点 → 1% + 10% = 11%

  触发成功后：
    → 从该装备当前套装的专属词条池中，再随机 1 条**不同于已有词条**的
    → 该条额外词条计入同名唯一检查（同 §3.2）
    → 该条词条不可与引力套的专属词条池重合（只从该装备自身套装的池中抽）
    → 该条词条显示为紫色底色，标记为"引力赋予"

  触发失败 / 不满足前提：
    → 装备原本没有套装（未通过 §1.2 判定）→ 引力效果不生效
    → 概率判定未通过 → 装备正常生成，无额外词条

终局意义：
  正常上限：8 格 = 最多凑 2 个 4 件套
  引力突破：1 件双套装词条装备 = 节省 1 格 → 多出 1 格自由位或额外凑 1 套
  终局目标：刷出多件双套装词条装备，实现 8 格 3 套甚至 4 套的极限搭配
```

### 4.6 专属词条叠加规则

```
规则：同名词条效果不叠加，但算套装件数。

  同名不叠加：
    拥有 3 件带"【龙鳞】-硬皮"的装备 → 仅生效 1 次（-4% 受击伤害）
    但 3 件都算龙鳞套件数 → 可凑齐 4 件套效果

  不同名全叠加：
    拥有"【龙鳞】-硬皮"+"【龙鳞】-再生"+"【龙鳞】-坚韧"+"【龙鳞】-龙威"
    → 4 条全部生效，合计 -4%受击 +10%反伤 +3%格挡 +30%龙威伤害
    → 这是龙鳞套的极品搭配

  不同词条名但效果相同 = 可叠加：
    "【口才】-魅力"（普通跳过+5%）+ "【口才】-超级魅力"（普通跳过+5%）
    → 两条名字不同 → 效果叠加 → 普通战斗跳过概率合计 +10%

  引力赋予的额外词条同样适用：
    引力赋予的第 2 条套装词条，若与已有词条同名 → 不叠加
    若与已有词条不同名 → 叠加
    极品 = 引力4件+幸运堆高 → 刷出1件带2条不同词条的装备 → 4件套穿4件 = 最多5条不同词条生效

  数值叠加方式：
    百分比类 → 加算叠加（如 魅力+5% + 超级魅力+5% = +10%）
    数值类 → 加算叠加（如 速度+5 + 疾风套其他速度 = 直接相加）
    层数/层数减少类 → 不叠加，取最优值（如 涌动最多减1层，不会降到3层）
```

## 5. 装备强化系统（槽位强化）

### 5.1 核心改动：强化装备槽位，而非装备本身

```
强化对象不再是装备个体，而是**装备槽位**。
装备放入槽位后，自动获得该槽位的强化等级加成。
更换装备时，强化等级保留在槽位上——无需继承，无需转移。

[关键变化]
  ├─ 每个装备槽位（武器槽/防具槽/...）有独立的强化等级
  ├─ 装备本身不再携带强化等级
  ├─ 放入槽位的装备自动享受该槽位的强化效果
  ├─ 卸下装备时，强化等级留在槽位，不影响装备
  └─ 继承、转移、保护石 → 全部废弃
```

> 规则5（货币/道具）：强化消耗只用金币，不消耗任何道具，简化经济模型。

### 5.2 槽位强化等级

```
每个装备槽位（共 8 个）独立计算强化等级。
3 套装备槽位中，相同位置的强化等级共享（见 §6）。

强化效果：
  本槽位装备的主属性数值 × (1 + 0.03 × 强化等级)
  例：武器槽+10 → 放入其中的武器攻击力×1.3

强化上限：+200（每个槽位独立上限）

每级强化效果：该槽位主属性+3%（按基础主属性线性累计；+200时倍率为7.0）

强化不影响：
  - 附加词条（数量/数值/类型均不受影响）
  - 套装词条
  - 品质/装备等级
  - 宝石效果
```

### 5.3 强化消耗

```
每次强化消耗 = 当前槽位强化等级 × 500金币
（注：消耗按槽位当前等级计算，与放入的装备无关）

示例：
  +0 → +1：0 × 500 = 0金（首次免费）
  +1 → +2：1 × 500 = 500金
  +5 → +6：5 × 500 = 2,500金
  +50 → +51：50 × 500 = 25,000金
  +199 → +200：199 × 500 = 99,500金

消耗统计（估算）：
  0 → +10总计：22,500金
  0 → +20总计：95,000金
  0 → +30总计：217,500金
  0 → +200总计：9,950,000金/槽位
```

### 5.4 成功率

```
槽位强化无成功率概念——每级强化固定消耗金币，100% 成功。
玩家不需要担心"降级""碎装备""保护石"等问题。
```

> 设计柱检验：100% 成功确保玩家不会因强化失败产生挫败感，符合柱5（不肝不氪）——强化只是金币水槽，不是概率抽奖。

### 5.5 触发方式

```
强化通过 🔨 锻造格 触发，具体执行逻辑见 [[大地图规则细化案【定案】]] §7。

锻造格触发强化流程：
  Step 1 — 从当前已装备且未满+200的槽位中，均匀随机选1个
  Step 2 — 按 §5.3 公式计算消耗 → 检查金币是否足够
  Step 3 — 够 → 扣金 + 该槽位强化等级 +1
  Step 4 — 不够 → 跳过（不扣除金币）

规则3（极限情况）：
  - 没有已装备槽位或所有已装备槽位都到+200：本次锻造无效果，不扣金币
  - 金币不足：跳过，不影响其他格子
  - 3 套槽位共享等级（见 §6.2），只升级 1 次影响 3 套

离线行为：与在线相同，自动执行。金币不足则跳过。
```

### 5.6 关于继承、转移、保护石的说明

```
【v1.0 废除声明】

继承：
  旧设计：装备分解/出售时强化等级清空，通过转移操作继承。
  现设计：强化等级在槽位上，与装备无关。换装备不需要继承。
  → 无需实现

转移：
  旧设计：同部位消耗金币转移强化等级。
  现设计：强化等级在槽位上，装备只是"乘客"。
  → 无需实现

保护石：
  旧设计：保护下一次强化不掉等级（为失败降级预留）。
  现设计：槽位强化 100% 成功，不存在失败降级。
  → 无需实现

旧版相关字段/道具/UI → 全部删除。
```

## 6. 多套装备切换规则（新增 v1.0）

### 6.1 3 套装备槽位

```
每位玩家拥有 3 套独立的装备槽位，每套 8 个位置（武器/防具/鞋子/戒指/项链/披风/头盔/护符）。
玩家可快速在 3 套之间切换，适应不同战斗场景。

| 套号 | 名称（玩家自定）| 用途建议 |
|-----|---------------|---------|
| 套1 | 默认 | 日常挂机 Build |
| 套2 | （自定）| PvP / 针对性 Build |
| 套3 | （自定）| 刷宝 / 搞怪 Build |
```

### 6.2 槽位强化等级共享（规则3 极限情况）

```
3 套装备槽位中，相同位置的强化等级是共享的。

  例：
    套1 武器槽 = +10
    套2 武器槽 = +10  （自动与套1 武器槽相同）
    套3 武器槽 = +10  （自动与套1 武器槽相同）

  强化 1 次武器槽（从 +10 → +11）→
    套1 武器槽 = +11、套2 武器槽 = +11、套3 武器槽 = +11

  原因：
    强化升级的是"武器槽"这个抽象位置本身，不区分属于哪套。
    玩家只需强化 8 个槽位 × 1 次 → 3 套全受益。

设计意图：
  1. 玩家不需要为 3 套分别强化 → 减少 3 倍的金币消耗压力
  2. 切换装备不受强化等级差异影响 → 换套就是真的"换装备"不换强度
  3. 8个槽位各强化到+200即可毕业 → 目标清晰
```

### 6.3 装备归属规则

```
[核心原则]
  1. 装备放入槽位 = 从背包中取出（装备进入该槽位）
  2. 同一件装备不能同时放入不同套的槽位中
     └─ 例：某武器放入套1武器槽 → 不能再放入套2/套3武器槽
     └─ 必须先从套1卸下 → 再放入套2
  3. 每次切换套时：卸下当前套的装备 → 装备自动返回背包
     └─ 因为有"同件不能同时入2套"规则，所以必须返回背包
     └─ 切换后的套：玩家需要提前在该套槽位中放好装备
  4. 放入/卸下操作不消耗金币

[存储数据]
  玩家数据表：
    ├─ 套1装备槽 × 8（8 个 slot_id → 装备实例ID，null = 空）
    ├─ 套2装备槽 × 8（同上）
    ├─ 套3装备槽 × 8（同上）
    ├─ 当前激活套（1 个字段：1/2/3）
    └─ 8 个强化等级字段（共享，不区分套）
```

### 6.4 切换规则

```
[切换流程]
  玩家点击切换按钮（主界面或装备界面）：
    Step 1 — 当前套的所有装备属性取消
    Step 2 — 切换激活套为新的套号
    Step 3 — 目标套的所有装备属性生效
    Step 4 — UI 更新

[切换频率]
  无冷却限制——玩家可任意随时切换。
  切换不触发战斗相关事件（不打断挂机）。

[离线]
  离线时使用当前激活套的配置进行战斗。
  离线期间不可切换套。

[UI]
  ├─ 主界面显示当前激活套编号 + 名称（如"套1·日常"）
  ├─ 装备界面 → 顶部 3 个 TAB（套1/套2/套3）
  ├─ 当前 TAB 显示该套 8 个槽位的装备情况
  └─ 未放入装备的槽位显示为空（灰色 + 无装备图标）
```

### 6.5 极限情况（规则3）

```
[装备不够填满 3 套]
  玩家总共只有 8 件好装备 → 只填满套1
  套2/套3 可以只填部分槽位（空位无属性）
  切换前需确认目标套是否有足够装备（不然战力暴跌）

[切换时装备被锁定]
  锁定装备（见 §9）可放入槽位，也可从槽位卸下
  锁定不影响切换操作

[3 套全部清空]
  极端情况：玩家将所有装备从 3 套中卸下
  → 当前激活套=套1但8个槽全空 → 实际战斗时无装备属性加成
  → 允许，这是玩家的自由选择

[高强化槽位放低品质装备]
  允许：+200武器槽放一把普通品质武器 → 主属性倍率为7.0（即基础值+600%）
  但装备本身的低品质导致主属性基础值低 → 最终仍不如高品质装备
```

### 7.2 宝石等级与数值

```
宝石等级范围：Lv.1 ~ Lv.10
合成方式：3 颗同等级同类型 → 1 颗等级 +1（无损合成）

合成消耗：
  金币消耗 = 目标等级 × 500 金
  例：Lv.1 × 3 → Lv.2，消耗 500 金
  例：Lv.5 × 3 → Lv.6，消耗 3,000 金
  例：Lv.9 × 3 → Lv.10，消耗 5,000 金

合成总成本（从 Lv.1 合成到目标等级）：
  Lv.1 → Lv.2：3 颗 Lv.1 + 500 金
  Lv.1 → Lv.5：81 颗 Lv.1 + (500+1000+1500+2000) = 5,000 金
  Lv.1 → Lv.10：19683 颗 Lv.1 + (500+1000+...+5000) = 27,500 金

数值增长（v1.4修正：线性成长，删除旧版指数）：
  - 红宝石（攻击力）：每级 +10，Lv.10 = 100
  - 蓝宝石（防御力）：每级 +10，Lv.10 = 100
  - 绿宝石（生命值）：每级 +50，Lv.10 = 500
  - 紫宝石（技能伤害）：每级 +0.5%，Lv.10 = 5%
  - 黄宝石（暴击率）：每级 +0.5%，Lv.10 = 5%
  - 钻石（命中率）：每级 +0.5%，Lv.10 = 5%
  - 橙宝石（暴击伤害）：每级 +2%，Lv.10 = 20%
  - 银宝石（格挡率）：每级 +0.5%，Lv.10 = 5%

各等级所需同类型宝石数（3 合 1）：
  Lv.1 → Lv.2：需要 3 颗 Lv.1
  Lv.1 → Lv.5：需要 3^(5-1) = 81 颗 Lv.1
  Lv.1 → Lv.10：需要 3^(10-1) = 19683 颗 Lv.1
```

### 7.3 打孔规则（v1.0 重制）

```
每件装备的插孔数由品质决定：

  普通(灰)：0 孔（天生无孔，不能打孔）
  精良(绿)：0 孔（天生无孔，不能打孔）
  稀有(蓝)：0 孔（天生无孔，不能打孔）
  史诗(紫)：1~3孔（随机生成）
  传说(橙)：1~3 孔（随机生成）

生成算法（规则6 随机明确）：
  史诗与传说使用同一累计区间：
    随机值r∈[0,1)；r<0.60为1孔，0.60≤r<0.90为2孔，0.90≤r<1为3孔
    即1/2/3孔概率分别为60%/30%/10%，每件装备独立抽取，不设保底

打孔器（消耗品）：
  来源：极其稀有的掉落物（见下方获取表），不属于商店商品
  用途：给未达到品质上限的装备增加 1 个插孔
  单次效果：+1 孔
  限制：
    └─ 只能用于史诗和传说品质的装备
    └─ 史诗和传说都不能超过3孔；普通、精良、稀有始终不能打孔
  可重复使用：未达上限时可多次打孔
    例：传说装备出 1 孔 → 可用 2 次打孔器 → 到 3 孔
    例：传说装备出 2 孔 → 可用 1 次打孔器 → 到 3 孔
    例：史诗装备出2孔 → 可用1次打孔器 → 到3孔

打孔器掉落：
  ├─ Boss 击杀：Boss6+ 每战 0.5% 概率掉落
  ├─ 挑战格（高层）：3% 概率（宝箱选项）
  └─ 拍卖行交易：可上架（极其稀有，价格由市场决定）

设计意图：
  - 宝石是成长线，打孔器限制成长速度
  - 高品质装备才有孔 → 宝石成为追求高品质的动力之一
  - 打孔器稀有 + 不可商店购买 → 游戏内经济循环（拍卖行交易）
```

## 9. 装备重铸系统

### 9.1 核心规则

```
仅史诗（紫）和传说（橙）品质装备可重铸。
重铸 = 消耗分解精华 + 金币，重新随机生成装备的词条。
```

| 规则 | 内容 |
|------|------|
| 可重铸品质 | 史诗 / 传说 |
| 消耗货币 | 分解精华 + 金币 |
| 锁定词条 | 0~2 个（不锁定 = 全部词条重铸） |

### 9.2 重铸消耗表

| 锁定词条数 | 分解精华消耗 | 金币消耗（史诗） | 金币消耗（传说） | 说明 |
|-----------|------------|----------------|----------------|------|
| 0（全重铸） | 15 | 5,000 | 10,000 | 所有词条重新随机，赌脸 |
| 锁定 1 条 | 30 | 10,000 | 20,000 | 保护 1 条核心词条，其余重铸 |
| 锁定 2 条 | 100 | 30,000 | 60,000 | 保护 2 条，高风险高投入 |

```
消耗逻辑：
  锁定词条越多 → 分解精华 + 金币双重消耗指数级增长
  原因：锁定2条几乎等于定向造神装，必须高成本
  传说品质的重铸成本 = 史诗的 2 倍（传说装备基础价值更高）

重铸流程：
  Step 1 — 选择装备（史诗或传说）
  Step 2 — 勾选要锁定的词条（0~2 个）
  Step 3 — 界面显示本次消耗：分解精华 × N + 金币 × M
  Step 4 — 确认重铸 → 扣除分解精华和金币
  Step 5 — 锁定词条保留不变，其余词条重新随机生成
  Step 6 — 展示新装备 → 玩家确认 / 继续重铸 / 取消
```

### 9.3 词条重铸规则（规则6 随机明确）

```
重铸时：
  ├─ 锁定词条 → 词条ID + 数值完全保留（品质、类型、数值均不变）
  ├─ 重铸词条 → 从该装备品质对应的词条池中按权重重新随机
  └─ 同一条词条可能被重新随机到（即使原来已经存在，也会重新生成新数值）

词条数量：装备原本的词条数在重铸后保持不变
  例：传说装备有 4 条词条 → 锁定 1 条 → 其余 3 条重铸 → 仍是 4 条

反向情况（规则2）：
  ├─ 分解精华不足 → 按钮灰掉，提示"分解精华不足（需要 XX，当前 YY）"
  ├─ 金币不足 → 按钮灰掉，提示"金币不足（需要 XX，当前 YY）"
  ├─ 分解精华+金币都不足 → 两个都提示不足
  ├─ 非史诗/传说装备 → 重铸按钮不显示
  └─ 锁定后点击取消 → 不消耗任何资源，装备不变
```

### 9.4 极限情况（规则3）

```
全词条完美 → 重铸没意义，界面提示"该装备已无可优化词条"
连续重铸不提升 → 无保底（纯随机），每次重铸都是独立事件
分解精华归零 → 无法重铸，正常分解装备获取
金币归零 → 无法重铸，需继续跑圈积累
锁定2条后重铸（传说） → 100精华 + 60,000金/次，传说橙装分解才 50 精华 → 重铸 1 次需要分解 2 件橙装 + 刷 60,000 金
```

### 9.5 设计柱检验

> 重铸系统 → 满足柱2（Build深度）+ 柱6（玩家经济）
> - 锁定词条=定向Build追梦，分解精华=分解装备的经济循环出口，金币=双重水槽确保重铸不是无脑操作
> - 分解装备 → 获得精华 → 重铸追神装 → 继续刷装备分解
> - 消耗不低 → 决策有分量（是囤精华还是立刻赌？）

## 10. 装备锁定与保护

```
背包上限：100 件
  - 超出上限时无法继续获得装备（掉落的装备转化为碎片）
  - 已移至 [[背包道具货币系统案【定案】]] §4

锁定规则：
  - 背包中每件装备可手动锁定（🔒 图标）
  - 锁定装备：不可出售/分解/用作合成材料
  - 锁定装备：可镶嵌/拆卸宝石，可装备/卸下，可放入/移出槽位
  - 解锁：任意时间可手动解锁，无消耗

设计意图：
  防止误操作销毁好装备。
  锁定 = 装备保护的保险，解锁自由。
```

## 11. 装备绑定与交易规则（联网版生效）

> 联网版拍卖行规则生效；桌面单机回归模式不提供交易入口，但不能覆盖联网规则。

### 10.1 交易范围

```
只有满足以下任一条件的物品可以进入拍卖行/玩家间交易：

  ① **套装装备** —— 身上带有任意套装词条的装备
  ② **传说（橙）品质装备** —— 品质=传说（不论是否带套装词条）
  ③ **宝石** —— 所有类型宝石（Lv.1~Lv.10）均可单独拍卖
  ④ **打孔器** —— 极其稀有的消耗品，可上架拍卖

以下物品不可交易：
  - 非套装 + 非传说品质的装备
  - 天命卡、合成券、分解精华等消耗品/货币
  - 已装备在角色身上的装备
  - 已处于上架状态的装备
  - 锁定状态的装备（见 §9）
```

> 规则2（正向+反向）：可交易 vs 不可交易明确列全。
> 拍卖行完整的上架流程、判定和费用见[[拍卖行系统细化案【定案】]] §3~§7。

### 10.2 绑定规则

```
[核心原则] 玩家自己掉落的合格物品可首次交易；从拍卖行买到的物品永久标记为“交易绑定”。

详细规则：
  1. 玩家自己掉落的套装装备或传说装备 → 未锁定、未装备、未交易绑定且无镶嵌宝石时可上架
  2. 自己掉落的装备装到角色槽位后 → 卸下不会自动绑定，仍按第1条检查
  3. 拍卖成交 → 买家收到的物品永久交易绑定，不可再次上架
  4. 交易绑定装备可正常装备、镶嵌、拆卸和分解；拆下的原宝石保持自己的绑定状态
  5. 已锁定装备（§9）→ 手动解锁后才可继续判断交易资格

设计意图：
  1. 挂机游戏的核心是"刷→配→换"，频繁更换装备是常态
  2. 首次交易帮助玩家补齐Build，保留市场价值
  3. 成交后永久绑定限制倒卖和盗号后的反复转移
  4. 创建订单免费；成交手续费5%，只在成交时回收金币
```

> 规则3（极限情况）：
> - 交易绑定装备再次上架 → 服务端拒绝，物品不移动
> - 自己掉落的合格装备装备后再卸下 → 若已拆下宝石且未锁定，仍可首次上架

### 10.3 宝石交易

> 宝石交易细则见[[拍卖行系统细化案【定案】]] §3。自己掉落的未绑定宝石可上架；拍卖购得的宝石永久交易绑定，镶嵌后拆下仍保持绑定。

## 12. 设计柱检验

| 设计决策 | 满足柱 | 说明 |
|---------|--------|------|
| 套装与品质脱钩 | 柱2 Build深度 | 普通装备可出套装，玩家抉择：低品质凑套装 vs 高品质靠属性 |
| 8格2/3/4件套 | 柱2 Build深度 | 4+4/4+2+2/2+3+3/2+2+2+2 多种混搭，Build深度大幅提升 |

| 13套×4条专属词条 | 柱2 Build深度 | 52条词条池+同名不叠加=极品追求，Build选择空间大 |
| 套装基础概率3% | 柱5 不肝不氪 | 套装是意外惊喜不是硬性门槛，低概率可被幸运叠加 |
| **槽位强化（v1.0）** | **柱5 不肝不氪** | 强化在槽位不在装备，换装备不损失强化等级，无需继承/转移/保护石 |

| **3套切换（v1.0）** | **柱2 Build深度** | 储备3套不同Build，切换即改变战斗风格 |
| **3套共享强化等级** | **柱5 不肝不氪** | 只需强化8个槽位=3套全受益，避免3倍消耗 |
| **重制打孔规则（v1.0）** | **柱2 Build深度** | 史诗传说有孔是高品质价值，打孔器稀有掉落保持经济稀缺 |
| **免费拆卸** | **柱5 不肝不氪** | 自由尝试宝石搭配，不消耗额外资源 |
| **新增银宝石** | **柱2 Build深度** | 补全格挡流宝石，8种宝石覆盖8个槽位需求 |
| **首次可交易、成交后绑定（v1.6）** | **柱6 玩家经济** | 支持掉落物首次流通，同时抑制反复倒卖 |
| **宝石/打孔器可拍卖（v1.1）** | **柱6 玩家经济** | 宝石和打孔器成为高价值交易品，拉动拍卖行活跃度 |
| **新手武器与首次集齐保护（v1.8）** | **柱5 不肝不氪** | 保证基础战斗能力并优先补齐空部位；不抬高品质和套装概率，不替代长期刷装 |
