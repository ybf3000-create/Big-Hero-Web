### 0.4 Q32费用定案

Q32采用A：创建订单费用0金币；成交手续费为`floor(成交价 × 5 / 100)`；交易失败不扣费；成交价1~19金币时因向下取整，手续费为0。完整规则见[[拍卖行系统细化案【定案】]] §6。

## 9. 答案维护、失败分支与边界

| 场景 | 处理 |
|------|------|
| 全部答案已确认 | 拍卖案升为定案，开始同步旧策划冲突 |
| 某题选择“自定义”但未写规则 | 该题仍视为未回答，列出缺失内容，不替用户决定 |
| 某题明确“延期” | 只暂停依赖该题的阶段，其余无依赖工作可继续 |
| 答案互相冲突 | 标出具体题号和冲突，不进入受影响的代码开发 |
| 回答超过选项范围 | 以用户的具体文字为准，并把新规则补入对应细案 |
| 同一题后续改答案 | 使用最新明确答案，文档升版并记录变更，不覆盖历史记录 |

容量边界：确认单固定38个产品问题和8个规则冲突，共46项；当前46项均已确定。

性能说明：问题确认是人工、低频流程，不产生运行时服务负载。文档更新应一次批量处理答案，避免对同一规则反复升版；代码开发阶段的性能限制分别以四份系统案为准。

随机算法说明：确认流程完全由用户选择，不使用随机推荐或随机默认值。用户写“采用推荐”时按表中固定推荐执行；没有答案时保持待确认，不随机补全。
