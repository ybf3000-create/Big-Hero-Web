# 行为日志系统案 v0.4

> 对应：新增本地日志系统，记录玩家在线期间发生的重要事件
> 版本：v0.4 | 日期：2026-09-11 | 状态：已同步联网交易规则
> v0.1→v0.2 变更：① 删除所有离线日志规则（离线不移动不触发事件）；② 存储改为本地文件；③ 新增装备品质色标签；④ 明确容量含义；⑤ 删除锁定/手动删除功能；⑥ 全部事件给出具体记录文本示例；⑦ 移除服务端/MongoDB 相关描述

| 在线逐一记录 | 柱1 挂机爽感 | 玩家回来后翻阅日志 = "刚才跑圈期间发生了这些事"的收获反馈 |

## 2. 日志基础规则

### 2.1 日志结构

```
每条日志 = {
  时间戳（HH:MM:SS）,
  分类（重要奖励 / 战斗 / 事件）,
  图标（emoji）,
  标题（一行摘要，装备名含品质色）,
}
```

### 2.2 容量与清理

```
日志以纯文本或 JSON 行格式存储在游戏本地目录。
每个分类独立计数，单个分类上限 200 条。
满 200 条后，该分类中最早（最旧）的记录自动删除，新记录正常写入。
删除为自动静默操作，不弹窗提示。
```

> 为什么是"每个分类 200 条"：三个分类合计最多 600 条本地日志，滚动翻阅时不卡顿，文件体积可控（约 60KB 内）。

### 2.3 持久化

```
日志记录在游戏本地目录下的 activity_log.jsonl 文件。
不涉及服务端存储，不同步到云端，不跟随账号跨设备。
卸载游戏或手动删除该文件 → 日志永久丢失（接受此代价）。
```

### 2.4 离线行为

```
离线期间角色不移动，不触发任何事件，不生成日志。
玩家上线后，离线结算弹窗独立展示收益，不计入日志系统。
日志仅发生在角色在线走圈期间。
```

## 3. 日志分类体系

日志分为三大类：

| 分类 | 图标 | 用途 |
|------|------|------|
| ⭐ 重要奖励 | ⭐ | 获得高价值物品时记录 |
| ⚔️ 战斗 | ⚔️ | 每次战斗结算记录 |
| 📋 事件 | 📋 | 地图格子触发/系统事件记录 |

### 3.1 ⭐ 重要奖励 —— 具体记录文本

以下事件发生时写入一条重要奖励日志。装备名称按 [[装备系统细化案【定案】]] §1.3 命名规则生成。

| 触发条件 | 记录文本（用参数占位） | 异常文本（不满足时） |
|---------|---------------------|-------------------|
| 获得传说(橙)装备 | `⭐ 获得橙色装备：（装备名称）[（部位）]（套装名）` | — |
| 获得史诗(紫)装备 | `⭐ 获得紫色装备：（装备名称）[（部位）]（套装名）` | — |
| 获得天命卡 | `⭐ 获得天命卡 ×（数量）` | 不区分品质或卡名 |
| 彩票中奖 | `⭐ 彩票开奖中奖！号码（三位数） 获得：金币 +（数量）/（宝石名称）Lv.（等级）/（装备名称）/天命卡（卡名）/（装备名称）/（装备名称）` | 彩票未中奖 → 不记入本分类 |
| Boss 首次击败 | `⭐ 击败 Boss（编号）！掉落传说装备（件数）件` | 非首次击败 → 不记入本分类 |
| Boss 击败（非首次） | `⭐ 击败 Boss（编号）` | 无传说掉落 → 不记入本分类 |
| 拍卖行成交（≥10万金） | `⭐ 拍卖行售出：（装备名称） 成交价（金额）金（实收（金额）金）` | 成交价 < 10 万金 → 不记入本分类 |
| 宝石合成 Lv.5+ | `⭐ 合成（宝石名称）Lv.（等级）` | 合成等级 < Lv.5 → 不记入本分类 |
| 合成格产出传说/史诗 | `⭐ 合成获得（颜色）装备：（装备名称） 材料：（装备名称）+（装备名称）` | 产出精良/稀有/普通 → 不记入本分类 |
| 道具背包扩容 | `⭐ 道具背包扩容至（格数）格（消耗（金额）金币）` | — |
| 装备背包扩容 | `⭐ 装备背包扩容至（格数）格（消耗（金额）金币）` | — |

#### 装备品质色规则

日志中装备名称按品质着色显示：

| 品质 | 颜色 | HTML色值 |
|------|------|---------|
| 普通(灰) | 灰色 | `#9D9D9D` |
| 精良(绿) | 绿色 | `#1EFF00` |
| 稀有(蓝) | 蓝色 | `#0070DD` |
| 史诗(紫) | 紫色 | `#A335EE` |
| 传说(橙) | 橙色 | `#FF8000` |

> 例：`获得橙色装备：传说的 引力贤者法杖 [武器] 引力` ——"传说的 引力贤者法杖"显示为橙色文字。

### 3.2 ⚔️ 战斗 —— 具体记录文本

每场战斗结算时写入一条。文本格式固定，用参数填充。

| 战斗类型 | 记录文本 | 失败时文本 |
|---------|---------|-----------|
| 普通战斗 | `⚔️ 击杀（怪物名）Lv.（等级）×（数量）` | `⚔️ 战败！被（怪物名）击败` |
| 精英战斗 | `⚔️ 击败精英·（精英名）` | `⚔️ 战败！被精英·（精英名）击败` |
| Boss 战斗 | `⚔️ 击败 Boss（编号）·（Boss名）（档位）档` | `⚔️ 战败！Boss（编号）·（Boss名） 复活币 -1` |
| 挑战格战斗 | `⚔️ 挑战完成！造成（伤害量）伤害` | `⚔️ 挑战完成！造成（伤害量）伤害`（挑战格无失败） |

**每条战斗日志末尾统一追加结算行**：

```
  → 金币 +（金额） EXP +（数值） 掉落（件数）件
```

**掉落中有重要装备时追加补充行**：

```
  → 额外获得：橙色（装备名称）/ 紫色（装备名称）
```

> 精良/稀有/普通装备掉落不单独列出，仅合并计入"掉落 N 件"。

### 3.3 📋 事件 —— 具体记录文本

#### 3.3.1 地图格子事件

每个格子触发时写入一条。来源见 [[大地图规则细化案【定案】]] 对应章节。

| 格子 | 记录文本 | 变体/异常文本 |
|------|---------|-------------|
| 🏠 勇者之家 | `📋 完成第（圈数）圈` | 持续效果倒计时 → 追加 `（神祇名/天气名）剩余（N）圈` |
| 🎁 宝箱格 | `📋 开出（品质色）宝箱：（宝石名称）Lv.（等级）+（装备名称）` | 开出天命卡 → `📋 开出（品质色）宝箱：天命卡（卡名）`；宝箱为空 → `📋 开出（品质色）宝箱：空无一物` |
| 🎲 命运事件格 | `📋 命运：（事件名称）` | 获得装备 → 追加 `获得（装备名称）`；扣金币 → 追加 `金币 -（金额）` |
| 🛌 休息格 | `📋 休息：复活币 +1（当前（数量）/3）` | 复活币已满 → `📋 休息：复活币已满，金币 +100` |
| 🔨 锻造格 | `📋 锻造：（槽位名）强化至 +（等级）（消耗（金额）金币）` | 金币不足 → `📋 锻造跳过：金币不足`；已达上限 → `📋 锻造跳过：已达上限` |
| 🟩 空地格 | `📋 空地：捡到（金额）金币` | — |
| ⚡ 闪电格 | `📋 闪电！向前跳跃（步数）格` | 连续跳跃 → `📋 闪电连跳！第（次数）次，再跳（步数）格`；跳到空地 → 追加 `获得（金额）金币` |
| 🏛 神祇格 | `📋 神祇：（神祇名）降临！持续（圈数）圈` | — |
| 🔧 建设格 | `📋 建设：（方向名）收益（金额）金币` | 未建设 → `📋 建设：选择建设方向`；升级 → `📋 建设：（方向名）升级至 Lv.（等级）` |
| 🔮 合成格 | `📋 合成：（装备名称）+（装备名称）→（品质色）（装备名称）` | 离线超时 → `📋 合成超时：获得合成券 ×1` |
| 🏆 挑战格 | `📋 挑战：造成（伤害量）伤害` | — |
| 🪙 彩票格 | `📋 彩票：获得 #（三位数号码）` | 彩票已满 → `📋 彩票：已满，未获得新票` |
| 🌀 折跃格 | `📋 折跃：从第（起点格号）格 → 第（终点格号）格` | 挂机中自动折跃 → `📋 折跃（自动）：第（起点格号）格 → 第（终点格号）格` |

#### 3.3.2 系统事件

| 事件 | 记录文本 |
|------|---------|
| 天气变更 | `📋 天气变更：（新天气名）` |
| 神祇到期 | `📋 （神祇名）效果结束` |
| 装备自动分解 | `📋 自动分解：（品质色）（装备名称）→ 分解精华 +（数量）` |
| 拍卖行上架 | `📋 拍卖行：上架（物品名称），一口价（金额）金` |
| 拍卖行成交 | `📋 拍卖行成交：（物品名称）以（金额）金售出，手续费（金额）金，实收（金额）金` |
| 拍卖行到期 | `📋 拍卖行到期：（物品名称）已进入待领取` |
| 天命卡使用 | `📋 使用天命卡：（卡名）` |

## 5. 反面与特殊情况

### 5.1 不记录日志的情况

```
以下事件不生成日志：
  ├─ 精良(绿)/稀有(蓝)/普通(灰)装备掉落 → 仅在战斗日志的"掉落 N 件"中合并计数
  ├─ 天命卡获得 → 统一记录数量，不记录品质
  ├─ 获得宝石 Lv.1~3 → 不单独记录（宝箱日志中可附带）
  ├─ 空地格获得少量金币 → 仍记录事件（占格子就记录）
  ├─ 彩票未中奖 → 不记录（开奖事件在勇者之家事件中合并："第N圈触发开奖，未中奖"这个本身要不要记录？——不记录，仅中奖才记录）
  ├─ 锻造跳过/金币不足 → 记录事件（见 §3.3.1）
  └─ 离线期间 → 角色不移动，不触发任何事件，不生成日志
```

### 5.2 容量边界（规则 3）

```
├─ 单分类日志达到 200 条 → 该分类中最早一条自动删除，新记录正常写入
├─ 三个分类合计最多 600 条 → 游戏启动时恢复，滚动性能无压力
├─ 日志文件损坏 → 游戏启动时若无法解析，删除重建空文件，不阻塞启动
├─ 短时间内同类型事件密集触发 → 每条独立记录，不合并（例：闪电连跳3次=3条）
└─ 本地文件大小 → 单条平均约 100 字节，600 条约 60KB，忽略不计
```
