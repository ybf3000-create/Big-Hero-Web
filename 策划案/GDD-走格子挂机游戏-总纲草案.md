### 2.4 角色移动规则

#### 核心：掷骰前进 + 停走停留

```
每次移动 = 自动掷1颗骰子（数值1~6）+ 附带花色（♦♣♥♠）
         → 角色向前移动 骰子数值 格
         → 最终踩到的格子触发事件
         → 停留解决事件
         → 冷却间隔后自动掷下一次骰子
走过最后1格 → 回到🏠勇者之家(位置0) → 开始下一圈

【路过不触发】：骰子数值>1时，中间经过的格子不触发事件。
               除非该格子特别标注"每路过触发"。
```

#### 掷骰间隔（固定）

```
每次掷骰之间有固定冷却，与速度属性无关。
事件处理完毕后，等待3秒自动掷下一次骰子，无需玩家操作。

【速度属性与移动完全脱钩】：速度不影响掷骰频率，也不影响走格速度。
速度属性的唯一作用：缩减战斗中角色的出手CD（见§5.3）。
```

#### 速度属性：战斗出手CD

```
速度属性只作用于战斗系统，不与移动系统产生任何关联。

出手CD公式：3.0 × (1 - speed × 0.008)
               上限：速度最多缩减50%的出手CD（需63点）

speed=0   → 出手CD × 1.0（无加成）
speed=32  → 出手CD × 0.744
speed=63  → 出手CD × 0.5（最大缩减上限）
speed≥63  → 按63上限算，不再继续缩减

设计意图：速度堆高 → 技能轮次更快 → 更高DPS，强化"速攻型" Build的价值。
```

#### 不同格子停留规则

| 格子类别 | 停留处理 | 说明 |
|---------|---------|------|
| 🟢 绿色格（战斗/宝箱/命运/锻造/空地/神祇/闪电等） | 事件自动触发 → **停留2秒** → 离开 | 比旧版统一为固定2秒 |
| 🟡 黄色操作格（建设/合成/彩票/折跃） | **倒计时暂停：玩家操作多久就停多久**，关闭界面后离开 | 在线时间无限制；离线按兜底规则 |
| ⚔ 战斗格（普通+精英） | **战斗期间停留** → 战斗结束**立即离开**（无额外延迟）| 不停留战斗外的额外时间 |
| 🏠 勇者之家 | 快速通过 | 功能待定 |

#### 特殊移动修正

- **⚡闪电格**：走到该格 → 触发跳跃 → 角色**立即向前跳2~5格**（跳过中间格子，不触发跳过格的事件）
- **🌀折跃格**：走到该格 → 触发折跃 → 角色**立即传送到目标建设格**（跳过所有中间格）
- **🎲命运事件"传送门"**：从当前格直接跳到最近的闪电格，再触发一次跳跃

> 掷骰牌型奖励的完整规则已移至 [[大地图规则细化案【定案】]] §掷骰奖励系统。

#### 离线模式

```
玩家离线 → 停在原格，不掷骰、不走格、不触发任何格子或战斗。
服务端按最近有效在线金币/经验时薪的10%一次性估算收益。
有效离线时长最多12小时，不足1分钟不结算。
上线时在一个事务内发放金币和经验，并刷新最后在线时间；失败则整体不发放并允许重试。
```

类似大富翁的"神"—— 踩到后获得/被施加一种神祇状态，持续**固定圈数**后消失。

| 神祇 | 类型 | 效果 | 持续时间 |
|------|------|------|---------|
| 🧧 **财神** | 增益 | 所有金币收益×2 | 3圈 |
| ⚔️ **战神** | 增益 | 造成伤害×1.5，受到伤害×0.7 | 3圈 |
| 🌪 **速神** | 增益 | 技能行动冷却×0.8 | 3圈 |
| 🍀 **福神** | 增益 | 掉落装备30%概率品质+1 | 2圈 |
| 💀 **衰神** | 减益 | 战神反向：伤害×0.7，受伤×1.5 | 2圈 |
| 😈 **穷神** | 减益 | 财神反向：所有金币收益×0.5 | 2圈 |

## 3. 战斗系统（基础规则）

### 3.1 战斗宏观流程

```
踩到🗡战斗格 / ⚔精英格 / 🏆挑战格
  → 进入战斗场景
  → 自动开始战斗循环
  → 战斗结束（胜/败/平/撤退）
  → 结算 → 回到地图继续走圈
```

- 战斗全自动进行，无需玩家操作
- 战斗期间地图走圈暂停，战斗结束立即恢复
- 角色在战斗期间不可移动，不受掷骰/路过影响

### 3.2 行动顺序与回合机制

#### 3.2.1 行动队列（出手CD队列）

```
所有参战单位（玩家+怪物）各自拥有独立出手CD。
出手CD归零时，该单位进入"等待行动"队列。
队列按出手CD剩余值从小到大排序，越短越先行动。

出手CD计算公式：
  3.0 × (1 - speed × 0.008)   —— 上限缩减50%
  speed属性来源：
    玩家：自由速度点 + 装备速度点（上限 63 点 = CD 最低 1.5s）
    怪物：固定速度类型，见怪物案 §2.3（极慢5=2.88s / 慢速8=2.81s / 标准15=2.64s / 快速25=2.40s / 极速35=2.16s）
    Boss：Boss1~15=标准15, Boss16~50=快速25, Boss51~200=极速35
```

#### 3.2.2 单回合行动流程

```
Step 1 — 倒计时：所有单位出手CD同步减少（按真实时间流逝）
Step 2 — 入列：出手CD归零的单位进入"行动队列"
Step 3 — 行动队列处理（按CD归零先后顺序）：
   → 先入列者先行动
   → 行动流程：
     检查是否有技能行动冷却已归零？
       ├─ 是 → 执行技能释放规则（§3.4）
       └─ 否 → 执行普攻（§3.3）
   → 行动完毕后：
     该单位出手CD重置（重新计算 CD = 3.0 × (1 - 速度点 × 0.008)）
     回到 Step 1
Step 4 — 每次行动结束后检查胜负条件（§3.6）
```

#### 3.2.3 战斗时间流速

```
战斗内时间 = 真实时间流逝（无加速/减速）
即：3秒出手CD = 真实世界的3秒
```

> **设计意图**：出手CD系统的本质是"谁更快谁先动"而非严格回合制轮次。速度属性直接影响行动频率，速度×2 ≈ DPS翻倍。这与 §2.4 中掷骰冷却固定3秒（与速度无关）形成对比，强化速度属性在战斗中的核心价值。

### 3.3 普攻规则

#### 3.3.1 普攻触发条件

```
每个单位总是拥有"基础普攻"技能：
  - 无CD，始终可用
  - 当该单位行动轮到时，若没有其他技能行动冷却归零 → 自动执行普攻
  - 普攻不消耗任何资源
```

#### 3.3.2 普攻伤害公式

```
普攻伤害 = 攻击力 × 100%  × 伤害修正系数
              ↓            ↓
         来自角色属性    攻击buff / 减益 / 神祇效果等
```

- 普攻与伤害技能均可暴击，按命中→暴击→格挡三步独立判定
- 普攻受目标防御减伤影响（见 §3.10 伤害公式）
- 普攻不会触发特殊效果（如冰冻、燃烧等）

#### 3.3.3 普攻目标选择

```
普攻目标 = 当前自动锁定的敌人

自动锁定规则：
  1. 优先攻击敌方前排（若敌方有前排单位）
  2. 同排优先攻击血量最低的敌人
  3. 若全场敌方只有1个目标 → 直接攻击该目标

前排/后排定义：
  普通战斗（1个怪物）：无前排概念，直接攻击
  精英战斗（2~3个怪物）：系统自动按"受到的伤害"排序
    前排 = 受到的累计伤害更少的单位（更晚被击杀）
    实际实现：固定1个前排坦克型怪物 + 1~2个后排输出型怪物
```

### 3.4 技能释放规则

#### 3.4.1 技能释放判定

```
当单位行动轮到时：
  1. 检查所有已装备技能的CD状态
  2. 收集CD已归零的技能列表
  3. 若有技能可用 → 从列表中按优先级选1个施放
  4. 若无可用的技能 → 执行普攻
```

#### 3.4.2 技能优先级（多个技能行动冷却归零时）

> 技能优先级的完整规则已移至 [[技能系统细化案【定案】]] §1.2。
>
> 核心变更：玩家手动设定每个技能槽的优先级等级（1~3 级），
> 取代旧版固定 4 级逻辑。详见细化案。

#### 3.4.3 技能目标选择

```
技能的目标由技能本身的"目标类型"标签决定：

| 技能标签 | 目标选择规则 | 示例 |
|---------|------------|------|
| 单体伤害 | 当前普攻目标（见§3.3.3） | 重击、毒刃 |
| AOE伤害 | 敌方全体 | 旋风斩、毒雾 |
| 治疗 | 自身（除非指定"己方最低HP单位"）| 治疗波、生命绽放 |
| 护盾/防御 | 自身 | 护盾、冰墙 |
| 单体控制 | 当前普攻目标 | 冰冻射击、眩晕锤 |
| AOE控制 | 敌方全体 | 冰霜新星 |
| 增益（自身）| 自身 | 铁壁姿态、不屈意志 |
| 减益/debuff | 当前普攻目标 | 撕裂（Dot型）|

注：Dot型技能（毒刃/烈焰灼烧等）目标选择同"单体伤害"。
```

### 3.5 战斗胜负条件

#### 3.5.1 胜利

```
条件：敌方全体单位HP ≤ 0
结果：
  → 立即结束战斗
  → 结算奖励（EXP + 金币 + 装备掉落）
  → 角色回到地图，继续走圈
```

#### 3.5.2 失败

```
条件：玩家角色HP ≤ 0
结果：
  → 立即结束战斗
  → 无任何收益（不获得EXP、金币、装备）
  → 角色原地复活，HP回满
  → 回到地图，继续走圈
  → 无额外死亡惩罚（挂机友好设计）
```

#### 3.5.3 平局（超长回合兜底）

```
条件：战斗累计回合数达到 50回合 上限
  （1回合 = 所有参战单位行动1轮完毕）
结果：
  → 强制结束战斗
  → 按失败处理（无任何收益）
  → 角色HP回满，回到地图

设计意图：防止多单位精英战中"双方回血>伤害"导致的无限循环。
          50回合 ≈ 正常战斗的3~5倍时长，实际极少触发。
```

### 3.6 玩家主动放弃（撤退）

```
触发方式：
  → 战斗进行中，HUD角落显示"撤退"按钮
  → 点击后弹出确认："确定撤退？本次战斗无收益"
  → 确认 → 立即结束战斗

放弃结果：
  → 无任何收益
  → 角色不死亡，HP保持当前值
  → 回到地图，继续走圈
  → 不触发任何负面效果

可用场景：
  → 玩家在线时随时可用
  → 离线时不触发（服务器自动战斗直至结束）
```

>
> 核心变更：离线不执行战斗，按最近有效在线时薪的10%估算金币和经验，12小时上限。具体公式见[[战斗系统规则案【定案】]] §11。

## 10. 天命卡系统（简化定案）

天命卡只有一种品质，是服务器内部的即时事件触发标记，不进入背包、不占容量、不参与交易。宝箱格、命运事件“天命降临”和彩票大奖获得后，服务器立即消耗并按 [[大地图规则细化案【定案】]] §5 随机执行 1 次命运事件；若再次触发“天命降临”，继续立即执行，最多连续10次，达到上限后停止并记录提示。

旧存档中已有天命卡仍兼容 `item_use` 消耗；新版本不再产生库存卡，也不存在背包满格分支。
