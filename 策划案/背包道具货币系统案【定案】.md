## 1. 存储三通道总览

```
角色持有物
├── 💰 货币通道（纯数值，不占格子）
│   ├─ 金币
│   ├─ 复活币（上限3）
│   └─ 分解精华
│
├── 🎒 道具背包（初始100格，存储堆叠道具，可扩容至1000格）
│   ├─ 宝石（8种 × 10级，每格堆叠99）
│   ├─ 天命卡（每格1张，上限8张）
│   ├─ 合成券（每格堆叠99，上限5张）
│   └─ 强化符 / 打孔器 / 其他消耗品
│
├── 🎫 彩票背包（独立存储，不占道具格子）
│   └─ 彩票（3位随机数，上限10张，详见 §3.6）
│
├── 📦 拍卖行背包（独立30格，与装备背包分离）
│   └─ 上架托管 / 一口价购买所得 / 到期或取消退回（详见§4.6）
│
└── ⚔️ 装备背包（初始100格，不可堆叠，可扩容至1000格）
    ├─ 已装备（8槽）
    └─ 未装备（100格）
```

## 2. 货币通道

货币不占背包格子，以独立数值字段存储。每种货币有独立的上限和获取/消耗逻辑。

### 2.1 货币总表

| 货币   | 存储类型  | 上限             | 获取方式              | 消耗方式                    |
| ---- | ----- | -------------- | ----------------- | ----------------------- |
| 金币 | int64 | 无上限（程序侧用64位存储） | 战斗/宝箱/商店/空地/彩票/闲逛 | 建设/强化/合成/拍卖成交手续费/战败惩罚 |
| 复活币  | int32 | 3              | 初始3，休息格+1         | 战斗失败-1                  |
| 分解精华 | int64 | 无上限 | 分解装备（见 [[装备系统细化案【定案】]] §8） | 装备重铸（见 [[装备系统细化案【定案】]] §9） |

### 2.2 各货币详细规则

#### 金币

```
金币 = 角色主要经济货币，用于强化、建设、合成、拍卖行等所有经济行为。

无存储上限 → 离线长时间挂机后不会溢出。
程序建议：int64 存储，最高约 9.2×10^18，远超实际需求。

惩罚消耗：
  - 战败（复活币耗尽时）：扣当前金币 × 15%
  - 穷神路过建设格：扣建设格等级 × 30 金
  - 最低扣除到 0（不欠债）

显示格式：
  - < 10000 → "9,999"
  - ≥ 10000 → "1.2万"
  - ≥ 1亿 → "1.2亿"
```

#### 复活币

```
详见 [[角色属性策划案【定案】]] §2.4。

补充：复活币为货币字段，不使用道具格子。
      超出上限时获取 → 静默忽略（不弹提示）。
```

#### 分解精华

```
详见 [[装备系统细化案【定案】]] §8（分解）和 §9（重铸）。

分解精华为货币字段，不使用道具格子。理由：精华数量可极大，背包上限会严重限制。
分解装备获得精华，精华用于重铸装备追词条。
```

#### 打孔器

打孔器是可堆叠消耗品，不是货币字段。每个道具格最多99个，可通过稀有掉落和命运事件获得，也可在拍卖行首次交易；使用时消耗1个并为合格装备增加1孔，具体规则见[[装备系统细化案【定案】]] §7.3。数量为0或目标装备不能打孔时不消耗。

## 3. 道具背包

### 3.1 背包基础规则

| 项目 | 内容 |
|------|------|
| 初始格数 | 100 格 |
| 最大格数 | 1000 格（通过金币扩容） |
| 堆叠规则 | 同种道具同等级可堆叠；不同等级占用不同格子 |

### 3.3 道具满格处理

```
[在线]
  背包满 + 新道具无法堆叠到已有格子
  → 弹出提示："背包已满，请清理或扩容后再获取该道具"
  → 该道具不掉落（暂存到临时邮件，7天有效期）

[离线]
  背包满 → 该道具不掉落，记录日志"离线期间背包满，X道具未获取"

[例外]
  宝石镶嵌到装备上时 → 从背包扣除，不触发满格检查
  宝石从装备回收 → 回到背包空位；若无空位 → 暂存邮件
```

### 3.4 道具背包扩容

#### 3.4.1 扩容规则

```
扩容方式：金币购买
  每次购买 → 道具背包容量 + 50 格
  容量上限 → 最大 1000 格（初始 100 格，最多可扩容 18 次）
  购买入口 → 道具背包界面底部「扩容 +50 格」按钮
```

#### 3.4.3 扩容边界与反向（规则 2 + 3）

```
├─ 容量已达 1000 格 →「扩容」按钮灰掉，提示"已满"
├─ 金币不足 → 按钮显示为红色，点击提示"金币不足，还需要 XXX 金"
├─ 扩容后立即生效 → 无需重载或刷新
├─ 离线期间不自动扩容 → 需玩家在线操作
└─ 扩容为永久提升 → 不随角色重置
```

> **设计柱检验**：扩容满足柱 1（挂机爽感 — 容量大到无需频繁清理）+ 柱 6（玩家经济 — 金币水槽，回收）

### 3.5 天命卡系统

天命卡只有一种，不设品质、稀有度、卡名或独立卡面效果。它是可堆叠消耗品，单格最多 99 张。

使用流程：背包点击“使用” → 立即消耗 1 张 → 按 [[大地图规则细化案【定案】]] §5 的常规命运事件权重随机执行 1 次。使用后无二次选择；库存为 0 时按钮不可用且不触发事件。

获取来源：宝箱格抽中卡牌、命运事件“天命降临”、彩票大奖。所有来源产出的都是同一种天命卡。天气专属命运事件仍按当前天气优先判定，因此使用天命卡与踩命运格保持同一规则入口。

> 设计柱检验：删除品质与独立效果后，玩家一眼理解“卡=再抽一次命运”，满足柱1（低操作负担）和柱4（保留随机决策资源）。
### 3.6 彩票背包系统

彩票为独立存储通道，不占道具背包格子（规则 5：避免与宝石/天命卡/消耗品互相挤压）。

#### 3.6.1 存储规则

| 项目 | 内容 |
|------|------|
| 存储类型 | 独立数组 `int[10]`，非道具背包格子 |
| 上限 | 10 张 |
| 数据结构 | 每个槽位存一个整数0~999，显示固定补足3位；空槽位=-1 |
| 堆叠 | 不可堆叠，每张独占 1 个槽位 |
| 同号规则 | 允许重复号码出现，但重复号码不增加中奖概率 |

#### 3.6.2 获取与消耗

```
获取：
  踩彩票格 → 服务端安全随机源等概率生成整数[0,999]并自动获得1张
  免费、无需确认、无金币消耗
  获取触发逻辑详见 [[大地图规则细化案【定案】]] §14

消耗：
  每 5 圈开奖一次（开奖触发详见 [[大地图规则细化案【定案】]] §1 + §14）
  无论中奖与否，开奖后清空全部彩票
```

#### 3.6.3 满格处理

```
彩票背包满 10 张时再踩彩票格：
  → 显示弹窗"彩票已满，请等待开奖"
  → 不给新票，不补偿，本次踩格无任何奖励

离线期间：
  → 彩票格不触发，彩票不累积也不开奖
```

#### 3.6.4 中奖奖励与背包满格

```
中奖后获得 7 项奖励（详见 [[大地图规则细化案【定案】]] §14 中奖奖励表）：
  金币、宝石、天命卡、装备 ×3

各项奖励的满格处理：
  金币 → 货币无上限，直接入账
  宝石 → 道具背包满 → 不获取，记录日志
  天命卡 → 库存满 → 弹出替换/放弃选择（见 §3.5.3）
  装备 → 装备背包满 → 自动分解最低品质未锁定装备（见 §4.2）
```

> **反向（规则 2）**：未中奖 → 无奖励，清空彩票；彩票 0 张时开奖 → 跳过，无提示。
> **极限（规则 3）**：10 张全满再踩 → 无效；重复号码 → 不增加概率；离线 → 不触发。
> **设计柱检验**：彩票独立存储满足柱 1（挂机爽感 — 不与道具背包争格子）+ 柱 5（不肝不氪 — 独立空间=零管理成本）。

## 4. 装备背包

### 4.1 装备存储规则

| 项目 | 内容 |
|------|------|
| 初始格数 | 100 格（独立于道具背包）|
| 最大格数 | 1000 格（通过金币扩容，见 §4.3） |
| 已装备 | 8 槽（武器/防具/鞋子/戒指/项链/披风/头盔/护符）|
| 堆叠 | 不可堆叠，每件装备占 1 格 |
| 锁定 | 已锁定装备不可分解/不可合成，标记 🔒 |
| 自动锁定 | 传说品质自动锁定 |

### 4.2 满格处理

```
装备背包满：
  在线 → 新装备掉落 → 自动分解最低品质未锁定装备（1件）→ 新装备入包
        若全部已锁定 → 新装备不掉落，提示"装备背包已满且全部锁定"
  离线 → 同上，自动处理
  若启用了自动分解规则（§4.5）→ 先执行自动分解再判定满格

偷盗传闻（命运事件）：
  → 删除装备背包中最低品质未锁定装备 1 件
  → 若无未锁定装备 → 改为扣金币 100
  → 不触发背包空位变化
```

### 4.3 装备背包扩容

扩容规则与道具背包完全一致（见 §3.4），但独立计数：

```
扩容方式：金币购买
  每次购买 → 装备背包容量 + 50 格
  容量上限 → 最大 1000 格（初始 100 格，最多可扩容 18 次）
  价格公式 → 与道具背包相同（见 §3.4.2 成本表）
  购买入口 → 装备背包界面底部「扩容 +50 格」按钮

道具背包和装备背包的扩容各自独立：
  - 两个背包各需单独购买扩容
  - 扩容次数独立计数（道具背包第N次 ≠ 装备背包第N次）
  - 成本公式相同，但各自从第1次开始计算
```

### 4.4 装备筛选与显示

#### 4.4.1 默认排序

```
装备背包列表默认按以下规则排序（从左到右，从上到下）：

1. 品质（传说→史诗→稀有→精良→普通）
2. 同品质内按 强化等级 降序
3. 同强化等级内按 装备等级 降序
4. 同装备等级内按 获取时间 倒序（新获取的在前面）
```

#### 4.4.2 筛选条件（6 维度取交集）

装备背包支持 6 个维度的组合筛选，各维度间取**交集**（AND 逻辑）。各维度内部多选时取**并集**（OR 逻辑）。

| 维度        | 可选值                                                                  | 选择方式     | 说明                                                     |
| --------- | -------------------------------------------------------------------- | -------- | ------------------------------------------------------ |
| D1 品质     | 普通(灰) / 精良(绿) / 稀有(蓝) / 史诗(紫) / 传说(橙)                                | **多选勾选** | 勾选多个品质 = 任意选中品质均显示                                     |
| D2 装备部位   | 武器 / 防具 / 鞋子 / 戒指 / 项链 / 披风 / 头盔 / 护符                                | **多选勾选** | 勾选多个部位 = 任意选中部位均显示                                     |
| D3 词缀数量   | `0 ~ 8` 范围滑块                                                         | 滑块选区间    | 拖动两端设定 min~max 范围。依据装备当前拥有的附加词条 + 套装词条总数判定             |
| D4 词缀类型   | 每种词缀类型单独勾选默认全选                                                       | **多选勾选** | 勾选多种类型 = 装备拥有任意一种选中类型的词缀即显示。词缀分类见 [[装备系统细化案【定案】]] §1.2 |
| D5 初始宝石孔数 | `0 / 1 / 2 / 3`                                                      | **多选勾选** | 依据装备生成时的初始孔数（非镶嵌后状态）。宝石孔规则见 [[装备系统细化案【定案】]] §7.3       |
| D6 套装类型   | 无套装 / 龙鳞 / 烈焰 / 冰霜 / 雷霆 / 疾风 / 铁壁 / 暗影 / 自然 / 引力 / 星辰 / 幻影 / 口才 / 奢侈 | **多选勾选** | 勾选多个套装 = 任意选中套装均显示。"无套装"可单独勾选，用于筛选非套装装备                |

```
筛选逻辑：
  维度间：AND（取交集）
    D1(品质) AND D2(部位) AND D3(词缀数) AND D4(词缀类型) AND D5(孔数) AND D6(套装)
  维度内（多选）：OR（取并集）
    例：D1 勾选"传说+史诗" = 传说 OR 史诗
    例：D2 勾选"武器+戒指" = 武器 OR 戒指
    例：D6 勾选"龙鳞+烈焰" = 龙鳞 OR 烈焰

筛选示例：
  例1：D1=传说/史诗 + D2=武器 + D6=无套装
       → 显示所有非套装的传说或史诗武器
  例2：D3=3~6 + D5=2/3 + D6=龙鳞
       → 显示所有龙鳞套装、词缀数3~6个、初始2~3孔的装备
  例3：D4=攻击类 + D1=稀有/史诗
       → 显示所有拥有攻击类词缀的稀有或史诗装备

筛选重置：关闭背包界面后自动重置为"全部"（所有维度不限制）。
筛选后结果实时刷新，无需手动确认。
```

#### 4.4.3 排序切换

```
玩家可切换排序方式（单选）：

| 排序方式 | 说明 |
|---------|------|
| 品质优先（默认）| 传说→史诗→稀有→精良→普通 |
| 等级优先 | 装备等级高→低 |
| 强化优先 | 强化等级高→低 |
| 槽位优先 | 武器→防具→鞋子→戒指→项链→护符→头盔 |
| 套装优先 | 已有套装件数多→少（优先显示能凑成套的）|
| 获取时间 | 新→旧 |
```

长按/右键 → 弹出快捷菜单：

### 4.5 装备自动分解

玩家可设置最多 10 条自动分解规则：**掉落时立即判定，命中任意一条规则的装备自动分解为分解精华**。每条规则可只启用一个条件列，也可启用多个条件列。

#### 4.5.1 规则定义

```
自动分解 = 掉落后立即执行，对每件新装备判定

判定逻辑：
  同一列勾选多项 = OR（命中任意勾选项即可）
  同一条规则启用多列 = AND（所有已启用列都满足才命中）
  未选择的列 = 忽略，不参与判断
  多条规则 = OR（命中任意一条即自动分解）
```

#### 4.5.2 6 维度配置

与筛选使用相同的 6 个条件维度，但语义为“**满足规则中已启用的全部条件时自动分解**”：

| 维度 | 可选值 | 说明 |
|------|--------|------|
| D1 品质 | 普通/精良/稀有/史诗/传说 | 品质命中任意勾选项时，该列通过 |
| D2 装备部位 | 武器/防具/鞋子/戒指/项链/披风/头盔/护符 | 部位命中任意勾选项时，该列通过；可单独只选本列 |
| D3 词缀数量 | 范围滑块 min~max | 词缀总数处于范围内时，该列通过；默认 0~8 表示未启用 |
| D4 随机词缀 | 装备可能随机获得的非固定基础属性 | 拥有任意勾选词缀时，该列通过 |
| D5 初始宝石孔数 | 0/1/2/3 | 初始孔数命中任意勾选项时，该列通过 |
| D6 套装类型 | 无套装/龙鳞/…/奢侈 | 套装归属命中时，该列通过；“无套装”代表非套装装备 |

> **逻辑**：只计算玩家实际启用的列。单条规则至少启用 1 列；只选择品质或只选择部位都是合法规则。若启用多列，则已启用列取交集；未启用列直接跳过。

#### 4.5.3 执行流程

```
Step 1 — 装备生成完成（词条、品质、套装、孔数均已确定）
Step 2 — 判定是否「已锁定」（传说品质自动锁定 / 手动锁定）
  → 已锁定 → 跳过自动分解，直接入包
Step 3 — 依次应用最多 10 条自动分解规则
  → 任意一条规则的已启用列全部满足 → 进入 Step 4
  → 所有规则都未命中 → 保留，入包
Step 4 — 自动分解
  产出分解精华 = 该装备品质对应的分解精华数量（见 [[装备系统细化案【定案】]] §8）
  分解精华直接入账（货币通道，无背包压力）
Step 5 — 记录日志
  "[时间] 自动分解：传说·龙鳞武器（词缀4条/2孔）→ 分解精华 +X"
```

#### 4.5.4 预设模板

| 模板名 | D1 品质 | D2 部位 | D3 词缀数 | D4 词缀 | D5 孔数 | D6 套装 | 效果 |
|--------|---------|---------|----------|---------|---------|---------|------|
| 低品质清理 | 普通+精良 | 不启用 | 不启用 | 不启用 | 不启用 | 不启用 | 只要品质为普通或精良就分解 |
| 防具清理 | 不启用 | 防具 | 不启用 | 不启用 | 不启用 | 不启用 | 不考虑其他属性，只分解防具 |
| 低品质武器 | 普通+精良 | 武器 | 不启用 | 不启用 | 不启用 | 不启用 | 同时满足低品质和武器才分解 |
| 无孔非套装 | 不启用 | 不启用 | 不启用 | 不启用 | 0孔 | 无套装 | 同时满足无孔且非套装才分解 |
| 全分解 | 全部品质 | 不启用 | 不启用 | 不启用 | 不启用 | 不启用 | 所有装备均命中；锁定装备除外 |

> 玩家可添加、编辑或删除规则；最多 10 条规则同时生效，不设置单独的规则切换状态。

#### 4.5.5 反向与极限（规则 2 + 3）

```
├─ 未启用自动分解 → 所有装备正常入包，不触发分解
├─ 规则列表为空 → 即使开关已启用也不分解任何装备
├─ 单条规则全部列留空 → 禁止保存并提示“请至少选择一项分解条件”
├─ 只启用 1 列 → 仅检查该列，其他 5 列不参与判断
├─ 同时启用多列 → 已启用列全部满足才命中；任一列不满足则该规则不命中
├─ 装备背包满 + 自动分解开启 → 先自动分解释放空间，再判定满格
├─ 离线期间 → 自动分解正常生效（与在线相同逻辑）
├─ 已锁定装备 → 永不触发自动分解（安全兜底）
├─ 保存规则时数据不合法 → 服务器拒绝本次保存，继续使用上一次有效规则
└─ 词缀类型"套装专属"与 D6 套装的关系 →
     D4 勾选"龙鳞" = 保留拥有任意龙鳞词条的装备
     D6 勾选"龙鳞" = 保留属于龙鳞套装的装备
     两者独立可选：D4 检查词缀内容，D6 检查套装归属
```

#### 4.5.6 性能考量（规则 4）

```
触发时机：仅在装备掉落、宝箱开出、合成产出时触发
  非高频操作 → 无性能压力
  每次判定最多遍历 10 条规则 × 6 个维度（固定上限，O(1)），不遍历背包列表
  离线结算时批量处理 → 按相同逻辑一次性判定 + 批量分解入账
```

> **设计柱检验**：自动分解满足柱 1（挂机爽感 — 离线自动清理垃圾）+ 柱 5（不肝不氪 — 玩家自定规则，零手动操作）= 柱 2（Build 深度 — 精细筛选帮助玩家定向保留所需装备，加速 Build 成型）

### 4.6 拍卖仓库

拍卖仓库是独立于装备背包和道具背包的服务端存储空间，完整规则见[[拍卖行系统细化案【定案】]] §2、§4。此处只提供速查映射。

| 项目 | 内容 |
|------|------|
| 容量 | 30 格（不可扩容） |
| 存储类型 | 订单托管与待领取物品；装备和道具均按实际格数占用 |
| 谁放入 | 服务端事务自动处理上架托管、一口价购买所得、到期或取消退回 |
| 谁取出 | 玩家只能领取`claimable`状态物品；出售中的托管物不可取 |
| 一键领取 | 按订单结束时间从旧到新处理；普通背包满时停止，已领取部分不回滚 |
| 满格处理 | 无法购买或新增上架；已有托管物转为原角色待领取时仍占原格，不溢出 |
| 详见 | [[拍卖行系统细化案【定案】]] §4、§7、§8 |

> 说明：拍卖行背包不纳入 §3.2 道具总表（因其专属于拍卖行系统，不参与常规道具流转）。相关道具总表仅收录可上架的宝石/打孔器，上架后的存储逻辑见拍卖行案。

### 5.3 设计柱检验汇总

| 设计决策 | 满足柱 | 说明 |
|---------|--------|------|
| 货币/道具/装备三通道 | 柱1 挂机爽感 | 货币无上限=离线不溢出；装备独立=掉落不受道具背包影响 |

| 分解精华=货币 | 柱5 不肝不氪 | 分解精华可大量累积不占格子，分解=稳定价值回收 |
| 传说品质自动锁定 | 柱5 不肝不氪 | 防止自动分解误删极品，保护玩家核心资产 |
