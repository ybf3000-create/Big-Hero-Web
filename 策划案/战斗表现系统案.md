## 4. 伤害/判定视觉反馈

### 4.1 伤害数字规则

所有伤害数字从受击者头顶弹出，向上漂浮 1 秒后消失。

| 判定结果    | 数字颜色         | 字体大小    | 特殊标记                     | 触发来源                      |
| ------- | ------------ | ------- | ------------------------ | ------------------------- |
| 普通伤害    | 白色 `#FFFFFF` | 标准 24px | 无                        | 攻击通过命中、未触发暴击/格挡           |
| 暴击伤害    | 橙红 `#FF4500` | 放大 36px | 数字后含 `!` + 屏幕边缘金色闪光      | [[战斗系统规则案【定案】]] §4 Step 3 |
| 格挡伤害    | 蓝色 `#00BFFF` | 标准 24px | 数字前含 `🛡` 图标，受击者出现护盾碎裂粒子 | [[战斗系统规则案【定案】]] §4 Step 4 |
| 闪避/MISS | 灰色 `#888888` | 标准 24px | 显示 "MISS" 文字而非数字         | [[战斗系统规则案【定案】]] §4 Step 1 |
| Dot 伤害  | 暗紫 `#9932CC` | 小号 18px | 无特殊标记                    | [[技能系统细化案【定案】]] §6.5      |
| 治疗      | 绿色 `#00FF00` | 标准 24px | 数字前含 `+`                 | [[技能系统细化案【定案】]] §5.1      |
| 护盾获得    | 浅蓝 `#87CEEB` | 标准 24px | 数字前含 `🛡`，HP 条上出现蓝色护盾条   | [[技能系统细化案【定案】]] §5.2      |
| 破冰增伤    | 金色 `#FFD700` | 放大 36px | 数字后含 `💥`，目标冰块碎裂粒子       | [[技能系统细化案【定案】]] §4.2      |

> 多个数字同时弹出时（如 AOE）→ 错开弹出时间，每个间隔 0.1 秒。[规则 4 性能]

### 4.2 受击特效（按判定类型）

| 判定 | 受击者特效 | 攻击者特效 |
|------|----------|----------|
| 普通命中 | 闪白 0.05 秒 + 小血花粒子 | 无 |
| 暴击 | 闪金 0.1 秒 + 大血花粒子 + 屏幕边缘金色闪光 | 武器/法杖短暂发光 |
| 格挡 | 蓝色圆形护盾出现 0.3 秒 → 碎裂粒子 | 武器被弹开的视觉反馈 |
| MISS | 角色/怪物半透明化 0.2 秒（闪避残影） | 无 |
| Dot 跳伤 | 绿色毒雾粒子飘出 | 无 |

### 4.3 HP/护盾条变化

```
HP 条变化规则：
  - 扣血时：红色部分从右向左收缩，0.3 秒过渡动画
  - 治疗时：红色部分从左向右增长
  - 护盾获得时：HP 条上方出现蓝色护盾条，长度 = 护盾值/最大HP
  - 护盾消耗时：护盾条受击闪白，扣减动画
  - 过量治疗：HP 条短暂高亮绿色后恢复正常（表示已满）
```

## 6. 技能施放表现

### 6.1 玩家技能表现流水线

```
技能施放表现 = 3 段流水线：

Step 1 — 蓄力/前摇（0.2~0.5 秒）
  ├─ 角色身上出现技能范围预览（圆形/扇形/矩形区域提示）
  ├─ 蓄力粒子从四周向角色中心汇聚
  └─ 角色头顶显示技能名称飘字（0.5 秒后消失）

Step 2 — 释放（瞬时）
  ├─ 技能特效从角色向目标发射（投射物 / 范围爆发 / 自身环绕）
  ├─ 音效播放
  └─ 技能名称飘字消失

Step 3 — 命中反馈（0.3 秒）
  ├─ 目标播放受击特效（见 §4.2）
  ├─ 伤害/治疗/护盾数字弹出
  └─ 若施加控制 → 目标出现控制状态特效（§5）
```

### 6.2 技能类型通用表现

| 技能类型 | 视觉特征 | 音效类型 |
|---------|---------|---------|
| 单体直伤 | 投射物飞行（火球/冰箭/光弹）→ 命中爆发 | 清脆打击音 `sfx_skill_hit` |
| AOE 伤害 | 范围圈 → 从地面爆发（火焰/冰霜/闪电环） | 厚重爆发音 `sfx_skill_aoe` |
| Dot 施加 | 投射物命中后目标身上持续粒子（火焰/毒雾） | 嘶嘶声 `sfx_dot` |
| 控制技能 | 投射物 + 目标出现对应控制特效（§5） | 低沉命中音 `sfx_control` |
| 治疗 | 绿色光柱从天而降 → 角色身体发绿光 | 舒缓音 `sfx_heal` |
| 护盾 | 蓝色光球包裹角色 → 护盾成形 | 嗡鸣音 `sfx_shield` |
| Buff/Debuff | 自身环绕光效（红=增伤/蓝=减伤/金=免疫） | 轻快的效果音 |

## 7. 战斗流程表现

### 7.1 战斗开始

```
Step 1 — 画面切入（0.5 秒）
  ├─ 屏幕从两侧黑幕收缩 → 战斗场景显现
  └─ 战斗类型飘字居中显示（0.8 秒后消失）

战斗类型飘字对照表：
  ├─ 普通战斗："⚔️ 遭遇战！"（白色）
  ├─ 精英战斗："⚠ 精英来袭！"（紫色）
  ├─ Boss 战斗："💀 BOSS 战！"（红色，金色边框）
  └─ 挑战格战斗："🏆 伤害挑战！"（金色）

Step 2 — 怪物出场（0.3~0.8 秒）
  ├─ 普通/精英：怪物从画面右侧滑入 / 从地面升起
  ├─ Boss：Boss 从上方降落 → 地面震动 → 屏幕震动 0.2 秒
  └─ 怪物头顶显示名称 + 等级（1 秒后渐隐）

Step 3 — 战斗正式开始
  └─ 角色开始自动普攻（出手 CD 倒计时开始）
```

### 7.2 战斗 BGM

```
根据战斗类型切换背景音乐，无缝过渡（交叉淡入淡出 1 秒）：

| 战斗类型 | BGM | 特点 |
|---------|-----|------|
| 普通战斗 | `bgm_battle_normal` | 轻快节奏，不喧宾夺主 |
| 精英战斗 | `bgm_battle_elite` | 鼓点加重，紧张感提升 |
| Boss 战斗 | `bgm_battle_boss` | 宏大管弦，持续高潮 |
| 挑战格 | `bgm_challenge` | 快节奏电子，配合 60 秒倒计时 |

战斗结束后 BGM 淡出 1 秒，恢复走格子背景音乐。
```

### 7.3 波次切换

```
普通战斗可能有多波怪物（最多 3 波，见 [[怪物系统细化案【定案】]] §2）。

波间切换表现：
  Step 1 — 当前波最后一只怪物死亡
  Step 2 — 画面短暂冻结 0.3 秒
  Step 3 — 屏幕中央飘字 "第 N 波"（白色，1 秒后消失）
  Step 4 — 新怪物出场动画（同 §7.1 Step 2）
  Step 5 — 继续战斗

最后一波结束 → 直接进入战斗结束流程（§7.7）
```

### 7.4 战斗进行中

```
战斗中持续显示：
  ├─ 角色 HP 条（左上角）
  │   └─ 护盾条（HP 条上方蓝色）
  ├─ 怪物 HP 条（每个怪物头顶）
  │   └─ Boss HP 条（屏幕顶部中央巨大红色条）
  ├─ 状态图标（角色 + 怪物头顶）
  ├─ 技能行动冷却（技能栏右下角显示剩余自身行动数，允许显示1位小数）
  └─ 伤害数字/飘字（实时弹出，1 秒后消失）
```

### 7.5 怪物死亡

```
普通怪物死亡：
  Step 1 — HP 归零 → 播放死亡动画（溶解/碎裂）
  Step 2 — 尸体渐隐（0.5 秒）
  Step 3 — 若为该波最后一只 → 自动进入下一波

精英怪物死亡：
  Step 1 — 同上
  Step 2 — 额外播放一次小爆炸特效
  Step 3 — 掉落装备图标从尸体位置弹出 → 飞入背包区域

Boss 死亡：
  Step 1 — 画面暂停 0.3 秒（hitstop 效果）
  Step 2 — Boss 播放大型死亡动画 + 屏幕震动
  Step 3 — 屏幕中央显示 "Boss（编号）·（Boss名） 已被击败！"（金色大字）
  Step 4 — 掉落装备依次弹出展示（见 §8）
```

### 7.6 角色死亡与复活

```
角色死亡：
  Step 1 — HP 归零 → 角色倒地动画
  Step 2 — 检查复活币
    → 有复活币（≥1）：0.5 秒后角色复活动画 + 飘字"🪙 复活币 -1"
    → 无复活币（=0）：画面变暗 → 飘字"战败：传送回勇者之家"
  Step 3 — 战斗结束（见 §7.5 失败分支）
```

## 8. 掉落装备展示

### 8.1 品质色边框规则

掉落装备图标的外框颜色与品质对应：

| 品质 | 边框颜色 | 发光效果 |
|------|---------|---------|
| 普通(灰) | `#9D9D9D` | 无 |
| 精良(绿) | `#1EFF00` | 无 |
| 稀有(蓝) | `#0070DD` | 轻微发光 |
| 史诗(紫) | `#A335EE` | 紫色光晕 |
| 传说(橙) | `#FF8000` | 橙色光芒辐射 + 旋转光粒 |

### 8.2 掉落展示顺序

```
多件掉落时：
  Step 1 — 高品质优先展示（传说→史诗→稀有→精良→普通）
  Step 2 — 同品质按部位排序
  Step 3 — 每件展示 0.5 秒，依次弹出
  Step 4 — 全部展示完毕 → 进入结算面板
```

## 9. 性能考量（规则 4）

```
特效分级（低配/标准/高配）：
  低配：无粒子特效、无屏幕震动、伤害数字简化、怪物死亡无溶解动画（直接消失）
  标准：基础粒子 + 关键震动（Boss死亡/暴击）+ 正常伤害数字
  高配：全特效 + 全屏粒子效果

同屏伤害数字上限：20 个（超出部分不渲染，后台仍计算）
同屏特效数量上限：30 个（超出部分按 FIFO 移除最早的特效）
屏幕震动频率上限：每 2 秒最多 1 次（防止连续震动引起不适）
[需与程序确认] 上述数值在实机上测试后调整
```

## 10. 反向与极限情况（规则 2 + 3）

```
反向：
  ├─ 攻击被闪避 → 显示 "MISS" 而不是伤害数字
  ├─ 攻击被格挡 → 蓝色伤害数字 + 护盾碎裂粒子
  ├─ 暴击被格挡 → 显示金色数字但附加 🛡 图标（暴击伤害 × 格挡减伤）
  ├─ 治疗时已满血 → 显示 "+0" 绿色数字（告知过量）
  ├─ 护盾已满再获护盾 → 护盾条增长动画 + 叠加数字弹出
  └─ 控制被免疫（坚毅状态）→ 目标身上弹出 "免疫" 飘字

极限：
  ├─ AOE 命中 6 只怪物 → 6 个数字同时弹出，错开 0.1 秒每个
  ├─ Dot + 直伤 + 暴击同时触发 → 优先显示暴击数字，其余 0.05 秒后依次弹出
  ├─ 同一帧多个怪物死亡 → 依次播放死亡动画（间隔 0.2 秒），不叠加震动
  └─ Boss 死亡 + 大量掉落 → 掉落展示限 10 件，超过 10 件的部分缩略为"…还有 N 件"
```
