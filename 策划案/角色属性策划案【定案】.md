## 1. 属性体系全景

```
                     ┌─ 基础属性（自带，随等级成长）
                     │   ├─ HP（生命值）
                     │   ├─ 基础攻击力
                     │   └─ 基础防御力
                     │
                     ├─ 战斗资源
                     │   └─ 🪙 复活币（初始3/上限3，战斗失败-1，休息格+1；
                     │       3枚耗尽后战斗失败 → 强制回勇者之家 + 扣15%金币 + 回复到3枚）
                     │
角色属性 ─────────────┼─ 自由属性点（玩家分配，每级+2点，Lv.100=198点）
                     │   ├─ 攻击（每点+1.8%最终伤害，无上限）
                     │   ├─ 防御（每点+1.2%直接减伤，上限50%需42点）
                     │   ├─ 速度（每点-0.8%出手CD，上限50%需63点）
                     │   └─ 幸运（每点+1.5%稀有掉落/好事件概率）
                     │
                     └─ 装备属性（来自装备词条 + 强化 + 宝石）
                         ├─ 攻击力 / 攻击力%
                         ├─ 防御力 / 防御力%
                         ├─ 生命值 / 生命值%
                         ├─ 速度（数值）
                         ├─ 命中率 / 闪避率 / 格挡率
                         ├─ 暴击率 / 暴击伤害倍率（基础150%）
                         ├─ 技能伤害 / 冷却缩减
                         ├─ 幸运 / 金币加成 / 经验加成
                         ├─ 吸血
                         └─ 套装效果（特殊词条 + 套件特效）
```

## 2. 一级属性 — 基础属性（随等级自动成长）

这些属性由角色等级决定，无需玩家分配，不可重置。

### 2.1 HP（生命值）

| 项目 | 内容 |
|------|------|
| **意义** | 角色在战斗中能承受的伤害总量。HP ≤ 0 则战斗失败（无死亡惩罚，见 §3.5.2）。 |
| **计算** | `HP = (基础HP + 装备生命值) × (1 + 装备生命%)` |
| **基础HP** | `500 + (等级 - 1) × 80` [待定] |
| **Lv.1** | 500 |
| **Lv.50** | 500 + 49×80 = 4,420 |
| **Lv.100** | 500 + 99×80 = 8,420 |
| **恢复** | 休息格：回 max(HP上限×20%, 50)；脱离战斗后不自动回复 |

> 设计意图：HP成长线性，Lv.1为500，Lv.50为4,420，Lv.100为8,420；装备可继续提供百分比成长。
> 装备可在此基础上叠加 20%~40%，确保 HP 始终有"血量安全感"但不会被一击秒杀。

### 2.2 基础攻击力

| 项目 | 内容 |
|------|------|
| **意义** | 攻击力的"白值"部分，与装备攻击力相加后构成总攻击力。 |
| **计算** | `基础攻击力 = 25 + (等级 - 1) × 2` [待定] |
| **Lv.1** | 25 |
| **Lv.50** | 25 + 49×2 = 123 |
| **Lv.100** | 25 + 99×2 = 223 |

> 最终攻击力 = (基础攻击力 + 装备攻击力) × (1 + 自由攻击点×2% + 装备攻击% + buff%)
> 详见 §7 总公式。

### 2.3 基础防御力

| 项目 | 内容 |
|------|------|
| **意义** | 防御力的"白值"部分，与装备防御力相加后代入减伤公式。 |
| **计算** | `基础防御力 = 15 + (等级 - 1) × 1` [待定] |
| **Lv.1** | 15 |
| **Lv.50** | 15 + 49 = 64 |
| **Lv.100** | 15 + 99 = 114 |

> 最终防御力 = 基础防御力 + 装备防御力 × (1 + 装备防御%)
> 减伤效果见 §3.10.2 防御减伤公式。

### 2.4 复活币

| 项目 | 内容 |
|------|------|
| **意义** | 战斗失败时的复活资源。有币 → 复活继续；无币 → 惩罚并重置。 |
| **初始值** | 3 枚 |
| **上限** | 3 枚（不可超过） |
| **获取** | 踩 🛌休息格 → +1 枚（不超过上限）；满币时踩休息格 → 金币奖励替代 |
| **消耗** | 每次战斗失败 → -1 枚 |
| **耗尽惩罚** | 复活币 = 0 时战斗失败 → ① 强制传送回 🏠勇者之家 ② 扣除当前金币 × 15% ③ 复活币回复到 3 枚 |
| **适用** | 全部战斗类型（普通/精英/挑战/Boss） |

```
复活币生命周期：

  [初始 3/3]
       │
       ├─ 战斗失败 → -1 → 原地满血复活，继续走圈
       │
       ├─ 踩休息格 → +1（不超过3）
       │
       └─ 0/3 时战斗失败 → 强制回勇者之家 + 扣15%金币 + 回复到 3/3
```

> 设计意图：复活币是"软失败容忍"机制。日常战斗失败 = 消耗1枚，无损失惩罚；
> 连续失败 3 次以上 = 强制回起点 + 扣金币，形成"你要调整 Build 了"的提醒。
> 回复到 3 枚确保玩家在起点重新出发时有完整复活能力。

每升1级获得 **2点** 自由属性点，可在4种属性间任意分配。

### 2.3.1 洗点

```
玩家可在任意时刻重置全部自由属性点，重新分配。

洗点消耗：
  金币 = 玩家等级 × 200 金

洗点流程：
  Step 1 — 打开属性面板 → 点击"洗点"
  Step 2 — 确认弹窗："重置全部属性点，消耗 XXX 金币？"
  Step 3 — 确认 → 扣除金币 → 所有自由属性点归还（等级×2点）
           → 装备/宝石属性不受影响
           → 重新分配

反向情况（规则2）：
  金币不足 → 按钮灰掉，提示"金币不足（需要 XXX 金）"
  0 自由点 → 洗点无意义，按钮灰掉

设计意图：洗点 = 重新分配流派的通道。
  按等级扣金保证前期便宜后期慎重——低等级随便试，高等级需考虑。
```

### 3.1 攻击（自由点）

| 项目 | 内容 |
|------|------|
| **意义** | 提升角色造成的所有伤害。 |
| **机制** | 每1点 = 最终伤害 +1.8%（与装备攻击百分比词条计入同一乘区） |
| **上限** | 无上限 |
| **适用** | 普攻、技能伤害均受加成 |
| **极端Build** | Lv.100全点攻击 = 198点 → +356.4%最终伤害（约4.564×倍率） |

> 与装备"攻击%"词条**加算**（不是乘算），合并计入同一乘区。
> 例：自由点50(+100%) + 装备攻击%15% = +115% 最终伤害。

### 3.2 防御（自由点）

| 项目 | 内容 |
|------|------|
| **意义** | 直接百分比减免受到的伤害。 |
| **机制** | 每1点 = 受到伤害 -1.2%（乘算） |
| **上限** | **50%**（即减免最多一半伤害），超出部分无效 |
| **适用** | 所有来源的伤害（普攻/技能/Dot） |

> 自由防御减伤 = min(自由防御点 × 1.2%, 50%)
> 该减伤独立于装备防御的减伤公式（§3.10.2），两者**乘算叠加**。
>
> 例：自由防御 20 点 → -24% 伤害；装备防御再减 10% → 最终受到 = 原始伤害 × 0.76 × 0.90 = 原始伤害 × 0.684

| 自由防御点 | 减伤率 | 等效血量提升 |
|-----------|--------|------------|
| 5 | 6% | ×1.06 |
| 10 | 12% | ×1.14 |
| 20 | 24% | ×1.32 |
| 42 | 50%（封顶）| ×2.00 |

### 3.3 速度（自由点）

| 项目 | 内容 |
|------|------|
| **意义** | 缩减战斗中角色的出手 CD。速度越高，攻击频率越高 → DPS 越高。 |
| **机制** | 每1点 = 出手 CD -0.8%（乘算）；公式：`出手CD = 3.0 × (1 - min(速度点×0.008, 0.50))` |
| **上限** | **50%**（即出手 CD 最多减半） |
| **适用** | 仅战斗中的出手 CD（§3.2）。掷骰无冷却——格子事件完成后立即掷骰前进，不受任何属性影响。 |

> 出手 CD 减半 ≈ DPS 翻倍。63 自由速度点（封顶）是"攻速 Build"的核心。

| 速度点 | 出手CD缩减 | 出手CD（基础3.0s）| 相对DPS |
|--------|-----------|------------------|---------|
| 0 | 0% | 3.0s | ×1.00 |
| 16 | 12.8% | 2.62s | ×1.15 |
| 32 | 25.6% | 2.23s | ×1.34 |
| 63 | 50%（封顶）| 1.5s | ×2.00 |

### 3.4 幸运（自由点）

| 项目     | 内容                                                                                                               |
| ------ | ---------------------------------------------------------------------------------------------------------------- |
| **意义** | 提升稀有掉落概率和命运事件的好结果概率。                                                                                             |
| **机制** | 每1点 = +1.5% 概率加成（加算到基础概率上）                                                                                         |
| **上限** | 无硬上限（但概率最高100%）                                                                                                  |
| **适用** | ① 宝箱格品质表：各品质的实际概率 + 幸运点×1.5%（从低品质开始挤占） ② 命运事件：好事件权重 + 幸运点×1.5%（从坏事件权重挤占） ③ 战斗掉落率：基础15% + 幸运×0.5%（此处为 ×0.5% 每点而非 ×2%） |

> 幸运是高方差属性——前期点数少效果不明显，后期堆高可让"传说掉落"从不可能变为可能。

### 4.2 命中 / 闪避 / 格挡 / 暴击 — 三步独立判定规则

> ⚠ 本节已与 [[战斗系统规则案【定案】]] §4 对齐。原"圆桌判定"已废弃。

#### 4.2.1 命中率对抗闪避

```
命中率用于反制闪避流，防止闪避堆高后"谁也打不中谁"。

实际闪避率 = max(0, 目标闪避率 - 攻击者命中率)

规则：
  - 命中率只抵消闪避，不影响格挡和暴击
  - 若命中率 ≥ 目标闪避率 → 闪避完全无效，该次攻击必不 MISS
  - 命中率来自装备词条（"命中+1%~8%"），无独立自由属性点

例：
  目标闪避率 30%，我方命中率 15%
  → 实际闪避率 = 30% - 15% = 15%（仍有 15% 概率 MISS）

  目标闪避率 25%，我方命中率 30%
  → 实际闪避率 = max(0, 25%-30%) = 0%（必不 MISS）
```

#### 4.2.2 三步独立判定流程

```
单次攻击经历三步独立判定（详见 [[战斗系统规则案【定案】]] §4）：

  Step 1 — 命中判定（攻击方命中率 vs 防御方闪避率）
    实际闪避率 = max(0, 防御方闪避率 - 攻击方命中率)
    掷骰 [0, 100) < 实际闪避率 → MISS（伤害=0，无后续判定）
    掷骰 ≥ 实际闪避率 → 命中，进入 Step 2

  Step 2 — 暴击判定（仅技能，普攻跳过）
    掷骰 [0, 100) < 攻击方暴击率 → 暴击
    普攻可暴击（v3.1启用）

  Step 3 — 格挡判定（防御方独立掷骰）
    掷骰 [0, 100) < 防御方格挡率 → 格挡（伤害×0.5）

  暴击和格挡不互斥——可同时触发（暴击伤害×0.5）
```

> 设计意图：命中率是闪避流的天敌，鼓励玩家在"堆闪避"和"堆命中"之间形成博弈。
> 暴击是攻击方独立判定，格挡是防御方独立判定，两者不互斥（详见 [[战斗系统规则案【定案】]] §4.5）。

### 4.3 出手 CD 计算

```
角色出手CD = 3.0秒 × (1 - min(总速度点 × 0.008, 0.50))

总速度点 = 自由速度点 + 装备速度点
（装备加速和自由加速共享 50% 上限）

例：
  自由速度 30 点 + 装备鞋速度 +10 = 40 点
  → 出手CD = 3.0 × (1 - 0.40) = 1.8 秒
```

### 4.4 金币/经验加成

```
金币收益 = 基础金币量 × (1 + 装备金币% + 套装金币% + 神祇效果)
经验收益 = 基础经验量 × (1 + 装备经验% + 神祇效果)
```

### 5.4 自由属性点汇总

```
每升1级 → +2 自由属性点
Lv.1 → Lv.100 共升级99次 → 总计99 × 2 = 198自由属性点

4种属性分配上限：
```

## 5. 属性计算公式汇总

### 6.1 总攻击力

```
总攻击力 = (基础攻击力 + 装备攻击力) × (1 + 自由攻击点×0.018 + 装备攻击% + 套装/buff攻击%)
```

### 6.2 总防御力（装备减伤用）

```
总防御力 = (基础防御力 + 装备防御力) × (1 + 装备防御%)
```

代入 §3.10.2 减伤公式（已重制，见数值设计总表 v3.1 §2）：
```
装备减伤系数 = 1 - 总防御力 / (总防御力 + 400)
```

### 6.3 伤害计算全流程

```
Step 1 — 原始伤害 = 总攻击力 × 技能倍率（普攻=100%）

Step 2 — 装备减伤（重制公式, 见数值设计总表 §2）
  减伤系数 = 1 - 总防御力/(总防御力 + 400)
  伤害 = 原始伤害 × (1 - 减伤系数)

Step 3 — 自由防御减伤
  伤害 = 伤害 × (1 - min(自由防御点 × 0.012, 0.50))

Step 4 — 命中率对抗（先抵消闪避）
  实际闪避率 = max(0, 目标闪避率 - 我方命中率)

Step 5 — 三步独立判定（命中→暴击→格挡，详见 [[战斗系统规则案【定案】]] §4）
  Step 5a — 命中判定：掷骰 < 实际闪避率 → MISS（伤害=0）
  Step 5b — 暴击判定（仅技能）：掷骰 < 攻击方暴击率 → 暴击（伤害 × 暴击伤害倍率）
  Step 5c — 格挡判定：掷骰 < 防御方格挡率 → 格挡（伤害 × 0.5）
  暴击和格挡可同时触发 → 伤害 × 暴击伤害倍率 × 0.5

Step 6 — 其他修正（神祇/buff/套装等）
  战神增益 → 最终伤害 × 1.5
  衰神减益 → 最终伤害 × 0.5
  等等...

Step 7 — 最终伤害应用于目标 HP
```

### 6.4 总 HP

```
总HP = (基础HP + 装备生命值) × (1 + 装备生命%)
```

### 6.5 出手 CD

```
出手CD = 3.0 × (1 - min(总速度点 × 0.008, 0.50))
总速度点 = 自由速度点 + 装备速度点
```

### 6.6 技能行动冷却

```
实际行动冷却 = max(1, 技能基础行动间隔 × (1 - 技能冷却缩减%))
技能冷却缩减仅来自有效装备、宝石和状态，多来源加算，上限50%。
技能释放后记录实际行动冷却；该单位每次真正获得行动时减少1，硬控跳过行动时不减少。
Dot/Hot仍按真实秒数触发，不使用行动冷却。
```
