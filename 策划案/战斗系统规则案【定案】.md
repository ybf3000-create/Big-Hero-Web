## 1. 战斗宏观流程

```
触发战斗（踩到🗡战斗格 / ⚔精英格 / 🏆挑战格 / Boss格）
  ↓
Step A — 战斗初始化
  ├─ 生成怪物（等级/属性/外观/被动）
  ├─ 初始化战斗状态（HP全满、技能行动冷却=0、计时器归零）
  └─ 进入战斗场景
  ↓
Step B — 战斗主循环（全自动）
  ├─ CD 倒计时（真实时间流逝）
  ├─ 单位 CD 归零 → 执行行动
  ├─ 行动后重置该单位 CD
  └─ 每次行动后检查胜负条件
  ↓
Step C — 战斗结束
  ├─ 判定胜负
  ├─ 结算奖励（EXP/金币/掉落）
  └─ 回到地图，立即掷骰继续走圈
```

| 特性 | 说明 |
|------|------|
| 操作方式 | 全自动，无需玩家操作 |
| 时间流速 | 真实时间（1秒 = 现实 1 秒） |
| 中途操作 | 仅"撤退"按钮（在线时） |
| 地图影响 | 战斗期间地图走圈暂停，战斗结束立即恢复 |

每场战斗由 **玩家角色** vs **敌方怪物阵容** 组成。

### 2.1 玩家战斗属性（带入战斗的值）

战斗开始时，从角色当前属性快照以下值，战斗内不变：

| 属性     | 来源                 | 说明                      |
| ------ | ------------------ | ----------------------- |
| 总HP    | 角色属性案 §6.4         | 战斗内 HP 上限，可被护盾临时增加      |
| 当前HP   | = 总HP（开局满血）        | 挑战格连战时保留上一波剩余 HP        |
| 总攻击力   | 角色属性案 §6.1         | 普攻 + 技能的伤害基数            |
| 总防御力   | 角色属性案 §6.2         | 代入装备减伤公式                |
| 自由防御减伤 | 自由点 × 1.2%（上限 50%） | 独立乘算减伤                  |
| 出手CD   | 角色属性案 §6.5         | `3.0 × (1 - 总速度点×0.008)` |
| 命中率    | 装备词条               | 对抗目标闪避                  |
| 暴击率    | 装备 + 宝石            | 普攻和技能均可暴击 |
| 暴击伤害倍率 | 基础 150% + 装备 + 宝石  |                         |
| 闪避率    | 装备 + 宝石 + 套装       |                         |
| 格挡率    | 装备 + 头盔            |                         |
| 技能列表   | 已装备的 2~6 个技能       | 每个技能独立 CD               |
| 吸血%    | 装备 + 套装            | 伤害 × 吸血% → 治疗自身         |

## 3. 行动队列与 CD 系统

### 3.1 CD 队列机制

```
所有参战单位各有独立的"出手CD 计时器"。

出手CD 计时器 = 实时倒计时，按真实时间每秒递减。
计时器归零 → 该单位进入"行动队列"。
行动队列按 CD 归零先后顺序排队执行。

执行完毕后 → 该单位出手CD 重置为完整值，重新开始倒计时。
```

### 3.2 出手CD 计算公式

```
所有参战单位（玩家+怪物）统一使用同一公式：

出手CD = 3.0 × (1 - min(总速度点 × 0.008, 0.50))

总速度点来源：
  玩家：  自由速度点 + 装备速度点
  怪物：  见怪物案 §2.3 速度类型表（极慢5/慢速8/标准15/快速25/极速35）
  Boss：  见怪物案 §4.2（Boss1~15=标准, Boss16~50=快速, Boss51~200=极速）
```

| 单位 | 速度类型 | 速度点 | 出手CD | 
|------|---------|--------|--------|
| 玩家 | 自由分配 | min(自由+装备, 63) | 3.0 × (1-点×0.008), 最低1.5s |
| 怪物·极慢 | 坦克型 | 5 | 2.88s |
| 怪物·慢速 | 均衡偏肉 | 8 | 2.81s |
| 怪物·标准 | 标准 | 15 | 2.64s |
| 怪物·快速 | 刺客型 | 25 | 2.40s |
| 怪物·极速 | Boss/特殊 | 35 | 2.16s |

> 速度上限 63 点（CD 最低 1.5s）。怪物默认不达到上限。减速/控制效果（出手CD×1.5）对所有单位正常生效。

### 3.3 单次行动流程

```
[单位出手CD归零]

Step 1 — 技能选择
  检查所有已装备且行动冷却已归零的技能 → 按优先级选1个（见§6）
  若无可用的技能 → 执行普攻（见 §5）

Step 2 — 执行动作
  选定技能 → 进入攻击判定流程（见 §4）
  普攻 → 直接进入伤害计算

Step 3 — CD 重置
  该单位出手CD = 3.0 × (1 - 速度点 × 0.008)
  该单位使用的技能记录行动冷却（=基础行动间隔×冷却缩减与状态系数，见§6.4）

Step 4 — 胜负检查
  检查敌方是否全灭 → 胜利
  检查玩家是否阵亡 → 失败
  检查回合上限（50 回合）→ 平局
  否则 → 继续战斗循环
```

### 3.4 同时归零处理

```
若多个单位的出手CD在同一帧归零：
  按以下优先级排序：
    1. 速度点高者优先
    2. 速度相同时 → 玩家优先
    3. 同为单位类型 → 随机排序
```

## 4. 攻击判定流程（修正版：三步独立判定）

> ⚠ 本节修正了原 GDD §3.10.1 的"圆桌一次ROLL"方案。
> 理由：暴击是攻击方参数，闪避/格挡是防御方参数，不应混在同一桌互斥。

### 4.1 判定总流程

```
每个攻击动作（普攻或技能）经历以下三步：

Step 1 — 命中判定（攻击方 vs 防御方闪避）
Step 2 — 暴击判定（仅技能，攻击方独立掷骰）
Step 3 — 格挡判定（防御方独立掷骰）
```

### 4.2 Step 1：命中判定

```
实际闪避率 = max(0, 防御方闪避率 - 攻击方命中率)

掷骰 [0, 100)：
  骰子 < 实际闪避率 → MISS（本攻击结束，伤害 = 0，无后续判定）
  骰子 ≥ 实际闪避率 → 命中，进入 Step 2

特殊情况：
  怪物命中率 = 100% → 怪物攻击玩家必定不 MISS
  怪物闪避率 = 0% → 玩家攻击怪物必定命中（先忽略命中属性）
```

### 4.3 Step 2：暴击判定

```
对该次攻击（普攻或技能）进行暴击判定：

掷骰 [0, 100)：
  骰子 < 攻击方暴击率 → 暴击标记 = true
  骰子 ≥ 攻击方暴击率 → 暴击标记 = false

普攻和技能一视同仁，均正常进行暴击判定。
```

### 4.4 Step 3：格挡判定

```
若攻击命中 → 防御方独立掷骰 [0, 100)：
  骰子 < 防御方格挡率 → 格挡标记 = true
  骰子 ≥ 防御方格挡率 → 格挡标记 = false

怪物格挡率 = 0%（当前版本，Boss 可能有特殊机制）
```

### 4.5 判定结果组合

| 命中 | 暴击 | 格挡 | 结果 | 伤害倍率 |
|------|------|------|------|---------|
| ❌ MISS | — | — | 无伤害 | 0 |
| ✅ 命中 | ❌ | ❌ | 普通命中 | ×1.0 |
| ✅ 命中 | ✅ | ❌ | 暴击 | ×暴击伤害倍率 |
| ✅ 命中 | ❌ | ✅ | 格挡 | ×0.5 |
| ✅ 命中 | ✅ | ✅ | 暴击且格挡 | ×暴击伤害倍率 × 0.5 |

> 暴击和格挡不互斥——可以同时触发（暴击的伤害被格挡减半），
> 这比原"圆桌互斥"更符合攻防独立的直觉。

### 4.6 AOE 与多目标判定

```
AOE 技能（敌方全体/前排全体/后排全体）攻击多个目标时，
对每个目标独立执行完整的 §4.1 三步判定流程。

即：
  AOE 技能打 3 个目标 → 每个目标各自走一遍：
    Step 1（命中 vs 该目标的闪避率）
    Step 2（暴击，攻击方独立掷骰 × 每个目标各掷一次）
    Step 3（格挡，该目标独立掷骰）

结果：可能命中 2 个、MISS 1 个；暴击 1 个、普通命中 2 个；各目标独立。
    不会出现"全暴或全不暴"的情况。

反向情况（规则2）：
  - 所有目标都 MISS → 技能完全落空，视觉效果显示全部 MISS
  - AOE 仅 1 个目标存活 → 等同于单体技能，正常三步判定
  - AOE 无存活目标（全灭）→ 技能不执行

设计意图：每目标独立判定让 AOE 有"散弹枪"的感觉——
  不是整齐划一的全体暴击/不暴击，而是每个目标有自己的命运。
  这也让"敌方格挡率"在 AOE 面前仍有防范价值。
```

## 5. 普攻规则

### 5.1 触发条件

```
单位行动时，若所有已装备技能的 CD 均未归零 → 执行普攻。

普攻特性：
  - 无 CD，始终可用（是兜底动作）
  - 可暴击，与伤害技能统一执行命中→暴击→格挡三步独立判定
  - 不触发任何特殊效果（冰冻/燃烧/Dot 等）
  - 不消耗任何资源
```

### 5.2 普攻目标选择（基于站位）

> 完整站位规则见 [[怪物系统细化案【定案】]] §3。
> 站位图示：
> ```
>   玩家侧              敌人侧
>   ┌────┐   ┌────┬────┬────┐   ┌────┬────┬────┐
>   │ 👤 │ ←→│ 前1│ 前2│ 前3│   │ 后1│ 后2│ 后3│
>   └────┘   └────┴────┴────┘   └────┴────┴────┘
>              ↑前排（近战位）      ↑后排（远程位）
> ```

```
普攻按位序锁定目标：

Step 1 — 检查前排：
  若前排有存活怪物 → 锁定前排最左侧存活位置
    顺序：前1 → 前2 → 前3
    前排死亡后同排右侧自动左移补位（前2→前1，前3→前2）

Step 2 — 前排全灭 → 检查后排：
  锁定后排最左侧存活位置
    顺序：后1 → 后2 → 后3

Step 3 — 锁定规则：
  普攻不跨排：前排存活时不打后排
  目标锁定后持续攻击，直到该目标死亡 → 重新走 Step 1

Step 4 — Boss 战特殊：
  Boss 始终在前1位置，优先被锁定
  若 Boss 召唤小怪到后/前排其他位置，不改变普攻锁定优先级
```

### 5.3 普攻伤害（进入 §7 伤害管道）

```
普攻原始伤害 = 总攻击力 × 100%
→ 进入伤害计算管道（见 §7）
```

## 6. 技能释放规则

### 6.1 技能可用判定

```
每次行动时，扫描所有已装备技能：
  若技能当前行动冷却≤0 → 该技能可用
  若全部技能行动冷却>0 → 无可用技能，执行普攻
```

### 6.2 技能优先级

> 技能装备规则、优先级设定、完整技能列表 → 详见 [[技能系统细化案【定案】]]

```
当单位行动时，扫描所有已装备技能：

Step 1 — 筛选可用技能（行动冷却≤0）
Step 2 — 若有多个可用技能：
  → 按玩家设定的优先级等级排序（3 > 2 > 1，默认均为 1）
  → 同优先级内 → 按技能槽从左到右的顺序释放
Step 3 — 若全部技能行动冷却均未归零 → 执行普攻

例：
  技能槽 [护盾:3] [毒刃:2] [重击:2] [治疗波:1] [连击:1] [烈焰灼烧:1]
  行动冷却归零的技能：重击(2)+连击(1)+烈焰灼烧(1)
  → 最高优先级 = 2 → 重击优先释放
  → 若只有连击(1) + 烈焰灼烧(1) → 从左到右，连击先释放
```

### 6.3 技能目标选择

> 完整目标选择规则（含站位逻辑、控制状态处理）→ 详见 [[技能系统细化案【定案】]] §3
>
> 战斗引擎仅执行：技能系统返回目标单位ID → 战斗引擎对该目标执行伤害/治疗/控制。

```
技能目标由技能系统根据"目标标签"和当前战场站位计算得出：

  输入：技能目标标签（如"前排位序"、"全场最低HP"、"敌方全体AOE"）
  处理：技能系统查询当前战场存活单位列表，按标签规则筛选目标
  输出：目标单位ID列表（1个或多个）

  战斗引擎接收目标列表 → 对每个目标执行 §4 判定流程 → §7 伤害管道
```

### 6.4 技能行动冷却计算

```
技能释放后 → 该技能记录实际行动冷却：

实际行动冷却 = max(1, 基础行动间隔 × (1 - min(冷却缩减%, 50%)) × 状态系数)

每次该单位真正获得行动时，全部未归零的技能行动冷却减少1；冻结、眩晕等硬控导致跳过行动时不减少。
麻痹期间释放技能的状态系数为1.3，其他情况为1.0；麻痹不追溯修改已经存在的冷却。

例：基础行动间隔8，冷却缩减15%，无麻痹
  → 实际行动冷却=8×(1-0.15)=6.8个自身行动
```

## 7. 伤害计算全流程

一次攻击从原始伤害到最终扣血的完整管道：

```
Step 1 — 计算原始伤害
  原始伤害 = 总攻击力 × 技能倍率（普攻=100%）

Step 2 — 装备减伤（防御方）
  减伤系数 = max(0.05, 1 - 防御方防御力 / (防御方防御力 + 85 × 攻击方等级 + 400))
  伤害 = 原始伤害 × 减伤系数

  → 保底 5%：防御再高也不会完全免疫伤害

Step 3 — 自由防御减伤（仅玩家有）
  伤害 = 伤害 × (1 - min(自由防御点 × 0.012, 0.50))

Step 4 — 暴击/格挡修正（来自 §4 判定结果）
  暴击 → 伤害 × 暴击伤害倍率
  格挡 → 伤害 × 0.5
  两者同时 → 伤害 × 暴击伤害倍率 × 0.5

Step 5 — 其他修正（buff/debuff/神祇/套装/精英被动等）
  战神增益(+50%) → 伤害 × 1.5
  衰神减益(-50%) → 伤害 × 0.5
  技能大赛(+30%) → 伤害 × 1.3
  等等...（全部乘算叠加）

Step 6 — 吸血结算
  若攻击方有吸血% → 攻击方回复 HP += 最终伤害 × 吸血%

Step 7 — 护盾吸收（防御方）
  若防御方有护盾 → 护盾值优先吸收伤害
    护盾值 ≥ 伤害 → 伤害全部由护盾吸收，防御方HP不变，护盾值 -= 伤害
    护盾值 < 伤害 → 护盾被击破（归零），剩余伤害继续扣除HP
  无护盾 → 跳过此步

Step 8 — 最终扣血
  防御方当前HP -= 剩余伤害（经护盾吸收后）
  若防御方HP ≤ 0 → 该单位死亡
```

### 7.1 Dot 伤害规则

```
Dot（持续伤害）来源：毒刃、烈焰灼烧、撕裂等技能

Dot 实例模型：
  每个技能施加的 Dot 是独立实例，用 dot-id 区分。
  dot-id = 技能ID + 施加序号

  - 不同技能 → 不同 dot-id → 独立实例，各自跳伤害，互不影响
  - 同一技能再次施加 → 由技能的 Dot叠加模式 决定：
    模式A（刷新，默认）：刷新持续时间（不创建新实例）
    模式B（叠加）：创建新实例（与旧实例共存，各自独立计时）
  - 详见 [[技能系统细化案【定案】]] §6.7

Dot/Hot触发规则：
  Dot与Hot使用真实秒数计时，不随目标速度、行动次数或技能行动冷却改变。
  释放瞬间立即触发第1次，之后每1秒触发1次，直到配置的固定总次数耗尽。
  每跳Dot伤害=施放者攻击力快照×Dot倍率，不受防御、暴击或格挡影响。

  例：毒刃配置直伤80%+Dot30%×4次
    t=0：结算直伤并立即结算第1跳
    t=1/2/3秒：分别结算第2/3/4跳
    无论目标出手间隔是1.5秒还是3秒，总跳数都为4次。

实例上限：同一目标最多同时存在10个Dot实例（不区分类型和dot-id）。
  超出时 → 移除最早施加的实例（先进先出），新实例正常加入。

极端与反向情况：
  ├─ 固定总次数为1 → 只在释放瞬间触发，不保留后续实例
  ├─ 目标被冻结、眩晕或沉默 → Dot/Hot仍按真实时间触发
  ├─ 目标死亡 → 立即清除该目标全部Dot/Hot，不再产生后续事件
  ├─ 战斗结束 → 清除全部Dot/Hot计时器
  └─ 同id刷新、叠加、爆发与传播规则 → 以[[技能系统细化案【定案】]] §8为准

设计柱检验：固定次数使Dot/Hot收益可预测，不因速度或控制状态产生反直觉增减，满足柱2与柱5。
```

## 9. 战斗胜负条件

### 9.1 胜利

```
条件：敌方全体单位 HP ≤ 0
结果：
  → 立即结束战斗
  → 结算奖励（EXP + 金币 + 装备掉落）
  → 玩家 HP 保持当前值（不回满）
  → 回到地图，继续走圈
```

### 9.2 失败

```
条件：玩家 HP ≤ 0
结果：
  Step 1 — 检查复活币数量
    若有复活币（≥ 1）：
      → 复活币 -1
      → 玩家 HP 回满
      → 回到地图，继续走圈
      → 无其他惩罚
    若无复活币（= 0）：
      → 强制传送回 🏠勇者之家
      → 扣除当前金币 × 15%
      → 复活币回复到 3/3
      → 玩家 HP 回满
      → 回到地图，从勇者之家继续走圈
      → 无 EXP/装备掉落惩罚（仅扣金币）

  Boss 战失败特殊规则：
    → 无复活币时同样强制回勇者之家 + 扣金币
```

> 复活币来源：初始 3 个，上限 3 个。踩 🛌休息格 +1。3枚耗尽后→ 强制回勇者之家 + 扣15%金币 + **回复到3枚**。详见 [[角色属性策划案【定案】]] §2.4 和 [[大地图规则细化案【定案】]] §6。

### 9.3 平局（50回合上限兜底）

```
条件：战斗进行了 50 回合仍未分胜负
  （1 回合 = 所有参战单位各行动 1 次）

结果：
  → 按失败处理（无收益 + HP回满）
  → 记录日志：[平局] 玩家Lv{X} vs 怪物Lv{Y}，回合=50

触发场景：多单位精英战中"双方回血 > 伤害"导致无限循环。
          正常战斗约 15~30 回合，50 回合极少触发（是安全兜底）。
```

```

  → 无任何收益
  → 玩家 HP 保持当前值（不回满）
  → 回到地图，继续走圈

限制：
  仅在线时可用
  离线时不触发撤退（服务器自动战斗至结束）
  Boss 战不可撤退
```

## 11. 离线收益计算

### 11.1 结算公式

离线期间不执行战斗模拟，也不生成装备和其他道具。只结算金币与经验：

```
T = clamp(当前时间-last_online, 0, 12小时)
离线金币 = floor(最近有效在线金币时薪 × T/3600 × 10%)
离线经验 = floor(最近有效在线经验时薪 × T/3600 × 10%)
```

最近有效时薪使用战斗结算的实际金币、经验和战斗耗时换算，并用 25% 权重平滑更新。某场收益为 0 时不覆盖旧值。旧存档没有历史速率时，使用当前等级的保守基准。

### 11.2 边界情况

- `T < 60秒`：不结算。
- `T > 12小时`：按12小时结算。
- 系统时间回拨：按 0 秒处理。
- 离线不走格、不战斗、不掉装备、不消耗复活币、不触发彩票或天气。
- 领取后刷新时间戳并保存，防止重复领取。

> 设计柱检验：10%效率保留回归奖励但确保在线游玩是主要成长方式；批量公式为 O(1)，不会因离线时长增加运算量。
