## 通用原则（所有格子共用）

### 地图结构

- 地图为一圈环形，首尾相连。第 1 格和最后 1 格相邻。
- 格子编号从 0 开始：0 = 🏠勇者之家，1~N-1 为其他格子，N = 地图总格数。
- 角色只能顺时针前进，不能后退。
- 走过第 N-1 格后，下一步自动回到第 0 格（勇者之家），继续前进。

### 移动规则

- 玩家掷骰得到 N 点 → 角色从当前位置开始，逐格前进 N 步（1 步 = 1 格）
- 第 1~N-1 步经过的格子 = **路过**
- 第 N 步落定的格子 = **停留**（最终停格）
- 若步数超过当前位置到第 N-1 格的距离 → 自动绕回第 0 格继续走（环形不中断）

```
例：地图 30 格，角色在位置 28，掷骰 5 点
  第 1 步 → 位置 29（路过）
  第 2 步 → 位置 0（路过勇者之家）
  第 3 步 → 位置 1（路过）
  第 4 步 → 位置 2（路过）
  第 5 步 → 位置 3（停留）
```

### 掷骰奖励系统（扑克牌牌型）

每次掷骰时，系统记录该次掷骰的 `[数值(1~6) + 花色(♦♣♥♠)]`。每 3 次掷骰结算一次，结算后记录清空，重新开始记录。

#### 牌型检测

| 牌型 | 条件 | 示例 | 金币倍率 |
|------|------|------|---------|
| **一对** | 3 次中有 2 个数值相同 | 5♠ 3♦ 5♥ | ×2 |
| **同花** | 3 次花色全部相同 | 2♦ 5♦ 6♦ | ×3 |
| **顺子** | 3 个数值排序后连续（差值均为 1） | 2♠ 3♦ 4♥ | ×4 |
| **三条** | 3 个数值全部相同 | 6♦ 6♠ 6♥ | ×6 |
| **同花顺** | 同花 + 顺子同时满足 | 3♦ 4♦ 5♦ | ×10 |

#### 结算规则

```
Step 1 — 每次掷骰 → 记录 [数值+花色]，追加到当前周期记录队列

Step 2 — 记录数 < 3 → 什么都不发生，等待下次掷骰

Step 3 — 记录数 == 3 → 立即结算
  检测是否达成牌型：
    达成 → 发放金币奖励：奖励 = 当前等级 × rand(10, 50) × 牌型倍率
           多条同时达成 → 仅发放最高倍率
           弹出提示："（牌型名）！金币 ×（倍率）"
    未达成 → 无奖励，无提示
  结算后清空全部 3 条记录

Step 4 — 下一轮从第 1 次掷骰重新开始累积
```

#### 反向情况（规则 2）

```
├─ 3 次掷骰均未达成任何牌型 → 无奖励，清空记录，下轮重新开始
├─ 等级为 1 时 → 奖励公式仍然有效（rand(10,50) × 1 × 倍率）
└─ 离线期间 → 角色不移动、不掷骰，不触发此系统
```

#### 极限情况（规则 3）

```
├─ 同花顺（最高倍率 ×10）→ 最高等级 999 × 50 × 10 = 499,500 金 / 次
├─ 一对（最低倍率 ×2）→ 最低 1 × 10 × 2 = 20 金 / 次
└─ 不受格子触发影响 → 纯掷骰机制，不占用踩格事件
```

> **设计柱检验**：掷骰奖励满足柱 1（挂机爽感 — 每 3 次掷骰自动抽一个小奖，不额外操作）+ 柱 4（格子策略 — 即使踩普通格也有牌型激励，增强走格子本身的乐趣）。

### 触发方式（仅此 2 种）

1. **路过** — 角色移动轨迹中途经过，不停留。绝大多数格子路过无效果。
2. **停留** — 角色走完骰子步数后最终落定的格子。大部分格子仅在此时触发。

> 注：所有格子的"停留"不是固定时长，而是以格子事件完成为准。
> 事件完成（前台表现播放完毕，如战斗结束、开箱动画结束）→ 立即掷骰，继续前进。

### 特殊移动说明

- ⚡ **闪电格跳跃**：角色被传送到目标格，中间格子全部跳过不触发。跳到目标格 = 视为"停留"在该目标格，触发目标格的停留事件。
- 🌀 **折跃格传送**：角色被传送到指定建设格，中间格子全部跳过不触发。传送到目标格 = 视为"停留"在该目标格，触发目标格的停留事件。
- 停留规则：格子事件完成后立即掷骰继续前进，无固定停留时长。
- 离线规则：所有格子离线行为统一定义，见下方 §离线规则。

## 离线规则

### 核心原则

- 离线期间不走格、不触发战斗、彩票、天气、命运、神祇或装备掉落。
- 离线收益只有金币和经验，属于纯增量，不扣金币、复活币或其他资源。
- 有效离线时长`T = clamp(当前时间-last_online, 0, 12小时)`；不足1分钟不结算。
- 收益基于最近有效战斗的在线每小时金币/经验速率；没有历史数据时采用当前等级保守基准。
- `离线金币 = floor(在线金币时薪 × T/3600 × 0.1)`。
- `离线经验 = floor(在线经验时薪 × T/3600 × 0.1)`。
- 离线不获得彩票，也不触发彩票开奖。

### 边界与反向情况

- 离线超过12小时：只按12小时结算；超出部分不累计。
- 最近战斗收益为 0：不覆盖已有有效速率；从未战斗则使用等级基准。
- 系统时间回拨：离线时长按 0 处理，不产生负收益。
- 多次读档：领取后立即刷新 `last_online` 并保存，不能重复领取同一时段。

> 设计柱检验：收益仅为正常游玩的1/10，满足柱1（回来有收获），同时明显低于在线收益，避免鼓励纯离线放置；12小时封顶控制通胀。

## 1. 🏠 勇者之家

### 触发条件

触发类型：**停留 + 路过**
触发简述：触发后，路过时圈数 +1；停留时圈数 +1 并让所有持续性 buff/debuff 剩余圈数 -1。

### 执行流程

```
[路过位置0]
Step 1 — 完成圈数 +1
Step 1b — 圈数 % 5 == 0 → 触发彩票开奖（见 [[§14 彩票格]]）

[停留位置0]
Step 1 — 完成圈数 +1
Step 1b — 圈数 % 5 == 0 → 触发彩票开奖（见 [[§14 彩票格]]）
Step 2 — 所有持续性地图 buff/debuff 的剩余圈数 -1
  若某效果的剩余圈数归零 → 移除该状态
Step 3 — 事件完成，立即掷骰继续前进
```

> 圈数计算：路过或到达 🏠起点（勇者之家）即算完成一圈，瞬移路过起点也算。仅停留时才会让持续效果倒计。
> 术语定义详见 [[天气系统细化案【定案】]] §3.4。

### 功能扩展（待定）

```
当前版本：仅作为圈数里程碑，无额外功能。
后续版本候选：展示本圈统计摘要（金币/EXP/战斗胜负数）。
```

> 离线期间此格不触发。离线规则见 §离线规则。

## 2. 🗡 战斗格（普通）

### 触发条件

触发类型：**停留**
触发简述：触发后，进入全自动战斗，击败怪物获得金币、EXP 和装备掉落。

角色按骰子点数逐格前进，走完步数后最终停留在战斗格上。路过不触发。

### 执行流程

```
Step 1 — 计算怪物等级
  MonsterLv = max(当前区域最低等级, playerLv - 3) + rand(0, 2)
  （rand(0,2) = 均匀随机整数 0 或 1 或 2）

Step 2 — 计算怪物属性
  HP     = 300 × 等级缩放系数 × 1.0（普通倍率）
  攻击   = 30  × 等级缩放系数 × 1.0
  防御   = 20  × 等级缩放系数
  出手CD = 见怪物案 §2.3 速度类型表（3.0×(1-速度点×0.008)）

  等级缩放系数 = 1 + (MonsterLv - 1) × 0.15

Step 3 — 选取怪物外观（纯视觉，不影响属性）
  从全局怪物外观池均匀随机抽取1个外观
  外观池：Slime / 蝙蝠 / 蘑菇 / 哥布林 / 骷髅 / 蜥蜴人 / 蜘蛛 / 幽灵
  （外观不与区域绑定，全局共用）

Step 4 — 进入战斗（参见 [[战斗系统规则案【定案】]]）
  战斗全自动进行
  战斗结束判定：玩家HP≤0 → 失败；怪物HP≤0 → 胜利

Step 5 — 战斗结算
  [胜利]
    金币 = min(怪物等级, 100) × rand(2, 5)
    EXP  = 怪物等级 × rand(10, 18)
    装备掉落：参见"战斗格掉落规则"（见下方）
  [失败]
    金币 = 0
    EXP  = 0
    无掉落

Step 6 — 立即回到地图，继续走圈
```

### 战斗格装备掉落规则

```
每次战斗胜利，进行以下判定：

Step A — 是否掉落装备？
  基础掉落率 = 15%
  实际掉落率 = 基础掉落率 + (幸运属性 × 0.5%)

Step B — 若掉落，抽品质：
  普通(灰)  60%
  精良(绿)  28%
  稀有(蓝)  10%
  史诗(紫)   1.7%
  传说(橙)   0.3%

Step C — 抽部位（从当前已解锁的装备槽位中均匀随机）

Step D — 生成词条（见 [[装备系统细化案【定案】]] §3）
```

> 离线期间此格不触发。离线规则见 §离线规则。

## 3. ⚔ 精英战斗格

### 触发条件

触发类型：**停留**
触发简述：触发后，进入全自动精英战斗（怪物拥有随机被动技能），胜利必掉装备。

角色按骰子点数逐格前进，走完步数后最终停留在精英格上。路过不触发。

### 执行流程

```
Step 1 — 计算怪物等级
  MonsterLv = max(当前区域最低等级, playerLv - 1) + rand(0, 1)

Step 2 — 计算怪物属性
  HP     = 300 × 等级缩放系数 × 3.0（精英倍率）
  攻击   = 30  × 等级缩放系数 × 1.8
  防御   = 20  × 等级缩放系数
  出手CD = 见怪物案 §2.3 速度类型表（精英与普通同公式，速度点相同）

Step 3 — 选取怪物外观（同普通战斗格，全局随机）

Step 4 — 为精英怪随机分配1个被动技能（从精英被动池均匀随机 6 选 1）
  被动池：铁壁 / 狂暴 / 回复 / 荆棘 / 嗜血 / 护盾
  被动在战斗开始时立即生效

Step 5 — 进入战斗
  格子标注"⚔ 精英"提醒玩家这是精英战

Step 6 — 战斗结算
  [胜利]
    金币 = min(怪物等级, 100) × rand(5, 10)
    EXP  = 怪物等级 × rand(25, 40)
    装备：必定掉落 1 件装备（品质见精英掉落品质表）
  [失败]
    金币 = 0，EXP = 0，无掉落
```

| 稀有(蓝) | 35% |

| 传说(橙) | 4% |

> 精英战斗无普通品质掉落。

## 4. 🎁 宝箱格

### 触发条件

触发类型：**停留**
触发简述：触发后，三层随机抽取奖励（金币/装备/天命卡/宝石其中一种），含品质权重和幸运修正。

角色按骰子点数逐格前进，走完步数后最终停留在宝箱格上。路过不触发。

### 执行流程（三层随机）

```
Step 1 — 第一层：抽产出类型
  金币      55%
  装备      25%
  命运卡    12%
  宝石       8%

Step 2A — [金币被选中]
  金币量 = min(怪物等级, 100) × rand(6, 12)
  金币直接入账

Step 2B — [装备被选中]
  抽品质（宝箱品质表，受幸运影响）：
    基础品质权重：
      普通(灰)  20%
      精良(绿)  34%
      稀有(蓝)  28%
      史诗(紫)  13%
      传说(橙)   5%
    
    幸运修正（见 [[角色属性策划案【定案】]] §3.4）：
      幸运点 × 1.5% → 从低品质开始逐档挤占。
      挤占顺序：普通→精良→稀有→史诗→传说。
      例：幸运 10 点 → 普通 -20% → 从品质表中从低到高依次扣除
        普通：min(20%, 0%有剩余) → 挤掉 20%，普通 = 0%
        精良：还需挤 0%，精良 = 34%
        稀有：28% → 史诗：13% → 传说：5%
        实际表：普通 0% / 精良 34% / 稀有 28% / 史诗 23% / 传说 15%
      例：幸运 25 点 → 挤占 50%
        普通 0% / 精良 4% / 稀有 28% / 史诗 13% / 传说 55%
  → 抽部位（已解锁槽位均匀随机）
  → 生成装备（见 [[装备系统细化案【定案】]] §3）

Step 2C — [天命卡被选中]
  获得1张统一类型的天命卡，加入道具背包并按99张/格堆叠。
  不进行品质、稀有度或卡面效果随机。

Step 2D — [宝石被选中]
  宝石类型均匀随机（8种，包含银宝石）
  宝石等级随机：
    Lv.1    60%
    Lv.2    25%
    Lv.3    12%
    Lv.4     3%
  → 直接加入背包

Step 3 — 显示开箱动画 + 弹出奖励提示 → 事件完成，掷骰继续前进
```

### 建设后的变化

```
宝箱格建设方向为"宝箱"时，每级品质提升1档：
  Lv.1~9：原品质概率表的"普通"比例逐步转移到"精良"
  Lv.10（黄金宝库）：必定掉落1件装备（品质仍随机，但无普通(灰)品质）
```

> 离线期间此格不触发。离线规则见 §离线规则。

## 5. 🎲 命运事件格（原天命卡）

### 触发条件

触发类型：**停留**
触发简述：触发后，从事件池（50%好/35%坏/15%特殊）按权重随机抽取一个命运事件立即执行。

角色按骰子点数逐格前进，走完步数后最终停留在命运事件格上。路过不触发。

### 权重分配（确认版 — 50%好/35%坏/15%特殊）

> `M = min(怪物等级, 100)`

每次踩入，从下方事件池按权重随机抽取1个事件执行：

```
总权重 = 100
奖励类合计权重 = 50（50%）
惩罚类合计权重 = 35（35%）
特殊类合计权重 = 15（15%）
调整后与设计意图接近 50/35/15 分布。

幸运修正（见 [[角色属性策划案【定案】]] §3.4）：
  幸运点 × 1.5% → 抽到惩罚类事件时的"重抽概率"。
  逻辑：先按权重正常抽取事件 → 若抽到惩罚类 → 掷骰 [0,100)
    骰子 < 幸运×2% → 丢弃结果，重新从完整池中再抽一次（仅1次重抽机会）
    骰子 ≥ 幸运×2% → 接受该惩罚结果

  例：幸运 10 点 → 抽到惩罚类时有 20% 概率重抽
        实际坏事件概率 ≈ 35% × 0.8 = 28%（直观降低）
  例：幸运 25 点 → 抽到惩罚类时有 50% 概率重抽
        实际坏事件概率 ≈ 35% × 0.5 = 17.5%
  例：幸运 50 点 → 抽到惩罚类时 100% 重抽（封顶 50%，即 50 点以上不再增加）

注：特殊类权重不受幸运影响。重抽仅1次，不递归。
```

### 执行规则

```
Step 1 — 按权重随机抽取1个事件
Step 2 — 立即执行该事件效果
Step 3 — 若效果是"持续性"（如技能大赛+30%），记录计数器

命运事件重复触发与叠加规则：
  同一事件再次触发时，按效果类型分别处理：

  计数器类（次数叠加）：
    技能大赛、攻击削弱 → 次数叠加，新触发 +3 次，上限 9 次
    装备促销 → 次数叠加，上限 10 次（见 §5 表格）
    小憩（步数+1）→ 仅当次生效，不叠加
    暴风雨 → 次数叠加，上限 15 投

  即时类（立即结算，不叠加）：
    股市大涨/崩盘、宝石行情好、天命降临、获得宝石/打孔器 → 立即结算
    命运逆转 → 立即生效，第2次同一圈触发时覆盖不叠加
    传送门 → 立即传送

  状态类（覆盖不叠加）：
    诅咒降临 → 重新随机减益神祇覆盖旧的
    拆迁通知 → 新等级-1覆盖旧目标，不累计减值

  金币百分比类（股市大涨/崩盘/钻石雨）：
    以结算时的当前金币为准，先结算增益再结算惩罚

Step 4 — 显示事件文本弹出 → 事件完成，掷骰继续前进
Step 5 — 继续走圈
```

### 持续性效果的计数器规则

```
"接下来X场战斗"类效果：每次战斗结束（不论胜负）减少1计数
"接下来X步"类效果：每次掷骰落定（角色移动落位）减少1计数
持续到计数归0后效果移除
```

### 5.1 天气专属命运事件（联动 [[天气系统细化案【定案】]] §3.5）

特定天气下，天气专属事件以高权重直接合并到常规事件池中一起抽取，一次掷骰决定结果。天气事件权重显著高于任何单个常规事件，使天气对走圈体验产生明显影响。

#### 触发规则（规则 6 随机明确）

```
[非指定天气 → 纯常规池]
Step 1 — 前提判定
  天气 = 晴天 或 天气系统未解锁
  → 使用常规事件池（总权重 100），按 §5 权重表正常抽取
  → 无天气事件参与，与旧规则一致

[指定天气 → 合并池]
Step 1 — 前提判定
  天气 ∈ {暴风雪, 细雨, 大雾, 沙暴, 北极光} 且 天气系统已解锁
Step 2 — 将该天气的专属事件以指定权重加入常规池
  合并池总权重 = 常规池 100 + 天气专属事件权重
Step 3 — 从合并池中按总权重随机抽取 1 个事件（单次抽取）
  → 抽到谁就是谁，不再分"先判定触发/不触发"两个阶段
```

```
[核心区别]
旧规则：先掷骰(30%+幸运)→走天气池 OR 走常规池（二选一）
新规则：天气事件混入常规池，一次抽取。天气事件权重高
        → 自然有更大几率被抽到，但常规事件也不会被"屏蔽"

[合并池总权重速查]

| 当前天气 | 专属事件 | 专属权重 | 合并池总权重 | 专属事件占比 |
|---------|---------|---------|-------------|-------------|
| ❄️ 暴风雪 | 🏔️ 冬眠 | 30 | 130 | 23.1% |
| 🌧️ 细雨 | 🌱 滋润 | 25 | 125 | 20.0% |
| 🌫️ 大雾 | 👻 雾中秘径 | 22 | 122 | 18.0% |
| 🌪️ 沙暴 | 💰 沙中淘金 | 20 | 120 | 16.7% |
| 🌌 北极光 | ✨ 许愿 | 15 | 115 | 13.0% |

设计意图：天气事件权重远高于常规池中最高的单事件（股市崩盘 8 权重），
       确保在对应天气下命运格有明显"天气风味"，但不会完全取代常规事件。
```

#### 反向情况（规则 2）

```
├─ 天气为晴天 → 无专属事件，100% 常规池
├─ 天气系统未解锁 → 同晴天，100% 常规池
├─ 合并池中抽到常规事件 → 正常执行常规事件效果（含幸运修正/重抽）
└─ 合并池中抽到天气专属事件 → 执行天气事件效果（不受幸运重抽影响，
   因为重抽仅针对惩罚类常规事件）
```

#### 天气专属事件表（5 个）

| 天气 | 事件名 | 权重 | 类型 | 效果 | 持续 |
| --- | --- | --- | --- | --- | --- |
| ❄️ 暴风雪 | 🏔️ 冬眠 | 30 | 特殊 | 所有怪物格不进入战斗，直接按战斗胜利结算全额奖励（金币+EXP+装备掉落，与在线战斗胜利完全相同） | 1 圈 |
| 🌧️ 细雨 | 🌱 滋润 | 25 | 奖励 | 立即回复 1 枚复活币（不超过上限 3 枚；满币时事件正常消耗无效果） | 触发即消 |
| 🌫️ 大雾 | 👻 雾中秘径 | 22 | 特殊 | 立即传送到地图上随机 1 个宝箱格并触发该宝箱格（地图无宝箱格时→改为从常规池重抽，保底不亏） | 触发即消 |
| 🌪️ 沙暴 | 💰 沙中淘金 | 20 | 奖励 | 立即获得 玩家等级 × 200 金币 | 触发即消 |
| 🌌 北极光 | ✨ 许愿 | 15 | 奖励 | 立即获得 1 件橙色（传说）品质装备，等级与玩家当前等级匹配 | 触发即消 |

> 天气专属事件在合并池中视为"特殊/奖励类"（非惩罚类），不受幸运重抽机制影响。幸运仅对常规池中的惩罚类事件生效（见 §5 权重分配）。

#### 极端情况（规则 3）

```
├─ 冬眠 + 1 圈内没有怪物格 → 无效果不返还
├─ 滋润 + 复活币已满（3/3）→ 事件消耗，不返还
├─ 雾中秘径 + 地图无宝箱格 → 改为从常规池重抽（剔除雾中秘径）
└─ 许愿无失败条件（必定获得传说装备）
```

> **设计柱检验**：
> - 合并池一次抽取 → 满足柱 1（挂机爽感，减少判定步骤）+ 柱 6（简单规则）
> - 天气事件高权重 → 满足柱 2（Build 深度，天气选择影响命运格产出）+ 柱 4（格子策略）
> - 非指定天气无专属事件 → 满足柱 5（不肝不氪，晴天不亏，雨天白赚）
> - 冬眠 23.1% 让暴风雪天走圈效率明显提升；许愿 13.0%（旧：≈0.6%）让北极光含金量暴增

> 离线期间此格不触发。离线规则见 §离线规则。

### B：已建设格子——停留触发（骰子停在该格）

```
[🏪商店建设格（停留）]
Step 1 — 计算收益
  间隔回合 = 当前回合数 - lastCollectTurn
  基础收益 = 玩家等级 × 10
  间隔加成 = 间隔回合 × (建设等级 × 5)
  金币收益 = 基础收益 + 间隔加成
Step 2 — 更新 lastCollectTurn = 当前回合数
Step 3 — 金币直接入账，显示 "+XXX 金" 弹出
Step 4 — 事件完成，掷骰继续前进
（停留和路过共用同一套计算逻辑，无区别）

[🎁宝箱建设格（停留）]
Step 1 — 自动开宝箱
Step 2 — 宝箱品质 = 普通宝箱品质基础上，最低品质档提高"建设等级"档
  Lv.1：移除普通(灰)
  Lv.3：移除精良(绿)及以下
  Lv.5：移除稀有(蓝)及以下，最低史诗(紫)
  Lv.10（黄金宝库）：必定掉落装备，品质随机（无灰/绿）
Step 3 — 事件完成，掷骰继续前进

[🗡战斗建设格（停留）]
Step 1 — 进入战斗（同本格 §2普通战斗格规则），但战利品倍率提升
  金币 × (1 + 0.15 × 建设等级)
  EXP  × (1 + 0.15 × 建设等级)
  装备掉落率 × (1 + 0.10 × 建设等级)
  Lv.10（精英战场）：装备品质无灰色，必出精良以上
Step 2 — 战斗结束 → 继续走圈
```

### C：已建设格子——路过触发（骰子经过但未停）

三个方向均已建设时，路过均触发对应奖励，不中断移动。**路过不触发升级操作**（升级仅能在停留时手动操作）。

```
[🏪商店建设格（路过）]
Step 1 — 计算收益（与停留完全相同的公式）
  间隔回合 = 当前回合数 - lastCollectTurn
  基础收益 = 玩家等级 × 10
  间隔加成 = 间隔回合 × (建设等级 × 5)
  金币收益 = 基础收益 + 间隔加成
Step 2 — 更新 lastCollectTurn = 当前回合数
Step 3 — 金币直接入账，显示 "+XXX 金" 弹出（简短版）
  （不中断移动，角色继续行进，弹出浮在角色头顶）

[🎁宝箱建设格（路过）]
Step 1 — 自动开宝箱（与停留完全相同的规则）
Step 2 — 宝箱品质 = 普通宝箱品质基础上，最低品质档提高"建设等级"档
  （品质档位同 B 停留触发规则，不中断移动，弹出开箱结果浮在角色头顶）
Step 3 — 继续行进

[🗡战斗建设格（路过）]
Step 1 — 自动进入战斗（与停留完全相同的规则）
  战利品倍率同 B 停留触发规则（金币/EXP/装备掉落率均有倍率提升）
Step 2 — 战斗结束 → 继续走圈
  （战斗期间移动暂停，战斗结束立即恢复掷骰前进）
```

### 🏪 商店建设格收益公式详解

```
核心公式：
  间隔回合 = 当前回合数 - 该商店格的 lastCollectTurn
  金币收益 = 玩家等级 × 10 + 间隔回合 × 建设等级 × 5

设计意图：
  - "玩家等级 × 10"：基础收益随玩家成长，保证不会在后期变成废格
  - "间隔回合 × 建设等级 × 5"：鼓励建设升级 + 鼓励走大圈（跑远再回来）
  - 同一圈内路过同一商店格只收取1次（lastCollectTurn 更新后间隔=0）

示例（建设等级 Lv.3 的商店格，玩家15级）：
  隔1回合路过 → 15×10 + 1×3×5 = 150 + 15 = 165 金
  隔5回合路过 → 15×10 + 5×3×5 = 150 + 75 = 225 金
  隔20回合路过 → 15×10 + 20×3×5 = 150 + 300 = 450 金

建设等级 Lv.10 的商店格，玩家30级：
  隔20回合路过 → 30×10 + 20×10×5 = 300 + 1000 = 1300 金

离线期间：
  回合数照常递增，离线回来后第一次路过商店格会拿到离线期间累积的全部收益。
  （离线期间不自动收取，必须路过或停留才触发结算）
```

### 建设格升级规则

```
升级费用 = 建设等级 × 1500 金（当前等级，升到下一级的费用）
升级上限 = Lv.10
升级时机 = 下次角色停留在该格时，玩家手动点击"升级"按钮
离线期间不自动升级（需玩家在线操作）
```

### 拆除规则

```
随时可拆除（通过地图界面点击建设格→拆除）
拆除效果：格子恢复为🔧建设格，可重新选方向
费用：免费，但已支付的建设费和升级费全部不退还
该商店格的 lastCollectTurn 数据一并清除
```

## 12. 🔮 合成格

### 触发条件

触发类型：**停留**
触发简述：触发后，选择 2 件装备合成；同品质确定 +1 阶，不同品质在区间内等概率随机；词条重新随机。

角色按骰子点数逐格前进，走完步数后最终停留在合成格上。路过不触发。

### 合成规则（方案 B — 品质+1阶 / 区间随机 + 词条重随机）

```
Step 1 — 弹出合成界面
  展示玩家背包中的所有装备（可滚动）
  提示："选择 2 件装备进行合成，同品质 +1 阶，不同品质在区间内随机"

Step 2 — 玩家选择 2 件装备（在线时无时间限制）
  离线兜底：10 秒后自动关闭，玩家获得 1 张🔮合成券

Step 3 — 确认合成
  消耗：2 件选中的装备（销毁）
  结果品质规则：

  [情况A：两件同品质]
    结果品质 = 当前品质 + 1 阶（确定，无随机）
    例：灰+灰 → 绿 / 绿+绿 → 蓝 / 蓝+蓝 → 紫 / 紫+紫 → 橙
    传说(橙) + 传说(橙) → 传说(橙)（上限封顶）

  [情况B：两件不同品质]
    设较低品质数值 = low，较高品质数值 = high（灰=0, 绿=1, 蓝=2, 紫=3, 橙=4）
    区间 = [low, min(high + 1, 4)] → 封顶传说(橙)
    在区间内等概率均匀随机抽取一个品质数值作为结果品质
    例：灰(0) + 蓝(2) → 区间 [0, min(3, 4)=3]
         等概率 4 选 1：灰(25%) / 绿(25%) / 蓝(25%) / 紫(25%)
    例：绿(1) + 紫(3) → 区间 [1, min(4, 4)=4]
         等概率 4 选 1：绿(25%) / 蓝(25%) / 紫(25%) / 橙(25%)
    例：蓝(2) + 橙(4) → 区间 [2, min(5, 4)=4]
         等概率 3 选 1：蓝(33.3%) / 紫(33.3%) / 橙(33.3%)

  品质数值 ↔ 名称对照：
    0 = 普通(灰) / 1 = 精良(绿) / 2 = 稀有(蓝)
    3 = 史诗(紫) / 4 = 传说(橙)

  品质上限封顶：传说(橙)，不溢出。

  结果部位规则：
    两件装备相同部位 → 结果为同部位
    两件装备不同部位 → 从两件的部位中随机选 1 个（50/50）

  结果词条规则：
    词条数量 = 结果品质对应的基础词条数（见 [[装备系统细化案【定案】]] §1.1）
    词条内容：完全从词条池重新随机（不继承任何原有词条，生成规则见 [[装备系统细化案【定案】]] §3）
    套装专属词条：按结果品质的概率规则正常判断是否触发

Step 4 — 显示合成结果 → 新装备进入背包 → 事件完成，掷骰继续前进
```

### 合成反向情况（规则 2）

```
├─ 两件同品质 → 确定 +1 阶（唯一结果，无随机）
├─ 两件不同品质 → 区间内等概率随机（可能出比高品质还差的结果）
├─ 区间含传说(橙) → 正常纳入等概率抽取
├─ 两件橙 → 结果仍为橙（上限封顶不溢出）
└─ 不同品质且区间最大时（灰+紫=4选1）→ 有 25% 概率直达传说
   不同品质且区间最小时（灰+绿=3选1）→ 有 33.3% 概率 +2 跳到蓝
```

### 合成极端情况（规则 3）

```
├─ 品质跨度最大（灰+橙=5级差）→ 区间 [灰,橙] 5选1，各20%
├─ 品质跨度最小（差1档，如灰+绿）→ 区间 [灰,蓝] 3选1，各33.3%
├─ 两件均为最低品质（灰+灰）→ 确定→绿（无随机，保底提升）
├─ 两件均为最高品质（橙+橙）→ 确定→橙（封顶不变）
└─ 区间结果含橙时 → 上限封顶为橙，不溢出
```

> **设计柱检验**：
> - 同品质确定 +1 → 满足柱 1（挂机爽感：用两件同品质装备稳定换一件更高品质，有确定回报）+ 柱 6（简单规则：同品=固定升阶，直观易懂）
> - 不同品质区间随机 → 满足柱 4（格子策略：高风险高回报，有 25% 概率出橙也可能掉回低品质，玩家需权衡）+ 柱 1（抽卡式爽感：踩合成格=小抽一次奖）
> - 区间等概率 → 满足柱 5（不肝不氪：全部随机概率透明，不搞暗箱）

### 合成约束

不可合成的情况（以下情况无法进行合成）：

- 选择的 2 件中有任何 1 件已装备在身上（需先脱下）
- 背包总装备数 < 2
- 合成格每次停留只能进行 1 次合成（合成后界面关闭，继续走圈）

### 合成券使用规则

```
获得合成券的方式：
  离线时路过合成格（10 秒超时后补偿 1 张）
  上限：5 张

使用合成券：
  在任意时候打开"背包 - 合成券"界面
  点击使用 → 直接弹出合成界面（不需要踩格子）
  使用规则与停留在合成格相同
```

## 14. 🪙 彩票格

### 触发条件

触发类型：**停留**
触发简述：触发后，免费获得一张 3 位随机数彩票（存入独立彩票背包，上限 10 张）。每 5 圈自动开奖一次。

角色按骰子点数逐格前进，走完步数后最终停留在彩票格上。路过不触发。

### 彩票获取规则

```
[在线]
踩到彩票格 → 自动获得 1 张彩票，无需确认、免费获得、无金币消耗。
  彩票号码=服务端安全随机整数[0,999]（1,000个结果等概率，显示补足3位）
  彩票存入独立「彩票背包」（存储规则见 [[背包道具货币系统案【定案】]] §3.6）

[离线]
此格不触发（见 §离线规则）。
```

### 彩票背包

彩票为独立存储通道，不占道具背包格子。上限 10 张，同一号码可重复出现。满格处理、数据结构等完整规则见 [[背包道具货币系统案【定案】]] §3.6。

### 全局圈数与开奖触发

复用 §1 勇者之家的圈数计数器。每次路过或停留勇者之家时圈数 +1。圈数达到 5 的倍数（5, 10, 15, 20, ...）时触发一次开奖。

```
[开奖触发时机]
勇者之家停留事件中（参见 §1 执行流程）：
  Step 1 — 圈数 +1
  Step 1b — 若圈数 % 5 == 0 → 触发彩票开奖（本 § §开奖流程）
  Step 2 — 持续效果倒计
  Step 3 — 掷骰继续

开奖发生在圈数 +1 之后、持续效果倒计之前。
```

### 开奖流程（规则 6 随机明确）

```
Step 1 — 检查彩票背包
  彩票背包全空（无有效号码）→ 跳过开奖，无任何提示，直接继续走圈
  彩票 ≥ 1 张 → 进入开奖

Step 2 — 系统抽取开奖号码
  开奖号码=服务端安全随机整数[0,999]（与彩票范围完全一致）
  与玩家彩票号码范围完全一致

Step 3 — 比对中奖
  遍历彩票背包中所有有效号码
  若存在任意一张号码 == 开奖号码 → 中奖！
  若无匹配 → 未中奖

Step 4 — 结算
  [中奖] → 获得中奖奖励包（见下方 §中奖奖励）
           弹出开奖动画 + 奖励展示面板
  [不中奖] → 显示"未中奖"浮动提示，无奖励

Step 5 — 清空彩票
  无论中奖与否，清空彩票背包（全部槽位重置为 -1）
  洗牌完成 → 继续走圈
```

### 中奖概率（规则 6）

```
单次开奖中奖概率：
  P(中奖) = 不同彩票号码数量 / 1000
  （000~999共1,000个可能值，使用服务端安全随机源等概率抽取整数[0,999]）

  例：持有1张彩票 → 1/1000 = 0.1%
  例：持有5张不同号码彩票 → 5/1000 = 0.5%
  例：持有10张不同号码彩票 → 10/1000 = 1%

注意：重复号码不增加中奖概率（比对的是号码值，不是彩票张数）。
      如持有 10 张但其中 2 张重复 → 有效号码数 < 10，实际概率略低。
```

### 中奖奖励（现有奖励之和）

中奖后一次性获得以下全部 7 项奖励：

| 奖励项  | 内容                               |
| ---- | -------------------------------- |
| 小奖金币 | min(怪物等级, 100) × rand(15, 40) 金  |
| 宝石   | 随机类型 Lv.1~2 宝石 1 颗               |
| 稀有装备 | 稀有(蓝)以上装备 1 件                    |
| 金币大包 | min(怪物等级, 100) × rand(80, 150) 金 |
| 天命卡  | 史诗(紫)+传说(橙)天命卡 1 张（50/50）        |
| 史诗装备 | 史诗(紫)装备 1 件，部位随机                 |
| 传说装备 | 传说(橙)装备 1 件，部位随机                 |

> 中奖后，所有装备按正常掉落流程生成词条（见 [[装备系统细化案【定案】]] §3）。
> 背包满时按 [[背包道具货币系统案【定案】]] §3.6.4 和 §5.2 的满格处理规则执行。

### 反向情况（规则 2）

```
├─ 彩票满 10 张时踩彩票格 → 弹窗提示，不给新票，不补偿
├─ 圈数未到 5 的倍数 → 不开奖，彩票继续累积
├─ 开奖时彩票 0 张 → 跳过，不触发，无提示
├─ 开奖未中奖 → 无奖励，清空彩票
├─ 中奖但背包满 → 按满格规则处理（见 [[背包道具货币系统案【定案】]] §3.6.4）
└─ 号码重复不影响概率 → 系统不检测去重
```

### 极限情况（规则 3）

```
├─ 彩票 10 张全满 → 再踩彩票格无效
├─ 圈数溢出 → 圈数计数器无上限（int64），到 5 的倍数就触发
├─ 彩票号码边界 → 随机整数[0,999]，000和999均可能出现，显示时固定补足3位
├─ 开奖号码与彩票号码范围一致 → 000~999，无遗漏
└─ 离线期间 → 圈数不增加，彩票格不触发，彩票不累积也不开奖
```

> **设计柱检验**：彩票系统满足柱 1（挂机爽感 — 免费获票，自动开奖）+ 柱 4（格子策略 — 彩票格积攒 vs 勇者之家引爆的预期差）+ 柱 5（不肝不氪 — 概率完全透明，无付费入口）。中奖率极低（1%）但奖励极其丰厚（7 项全拿），每次路过勇者之家都是一次心跳加速。

> 离线期间此格不触发。离线规则见 §离线规则。

## 15. 🌀 折跃格

### 触发条件

触发类型：**停留**
触发简述：触发后，选择已建设的格子瞬间传送过去，并触发目标格的停留事件。

角色按骰子点数逐格前进，走完步数后最终停留在折跃格上。路过不触发。

### 执行流程

```
[在线]
Step 1 — 弹出传送界面
  展示所有玩家已建设的格子列表（显示格子类型/等级/位置）
Step 2 — 玩家选择目标建设格
  无时间限制
Step 3 — 确认传送：角色立即移动到目标格（跳过所有中间格）
Step 4 — 触发目标格的停留事件（视该格已建设的方向正常执行）
Step 5 — 从目标格继续走圈（而非回到折跃格的位置）

[挂机中（玩家不在，自动选择）]
10 秒内无人操作 → 自动选择目标：
  → 传送到当前等级最高且未满 Lv.10 的建设格
    若多个同级建设格 → 优先商店方向 > 宝箱方向 > 战斗方向
    若无任何建设格 → 折跃格无效果，继续走圈（不弹窗、不等待）
```

### 边界情况

```
若玩家无任何建设格 → 折跃格无效，显示"无建设目标"，继续走圈
传送后触发的目标格事件 = 完整触发（包括战斗、开宝箱等）
传送后继续走圈的起始位置 = 目标建设格的位置（不回到折跃格）
```

## 16. 地图扩张规则

本规则从 [[GDD-走格子挂机游戏-总纲草案]] §2.3 和 §13 迁入，改为保护区模式。

> v0.1→v0.2 变更：原追加扩张改为「当前位置 ±3 格（共 7 格）不变，其余重新随机」。

### 16.1 基础公式

- 初始：28 格（环形）
- 每击败 1 只 Boss（1~20）：+5 格
- Boss 21~200：地图不再扩张（维持 128 格封顶），仅档位继续增长
- 20 只 Boss 全击败后地图定格：28 + 20×5 = 128 格
- Boss 1~20：逐步解锁全部 15 种格子类型（见 §16.2）
- Boss 21~200：档位继续提升怪物难度，地图不变（见 [[怪物系统细化案【定案】]] §1.2）

### 16.2 格子类型解锁进度（每 2 Boss +1 新种）

### 16.4 地图扩张算法（保护区模式）

每位玩家地图由个人种子 (PlayerSeed) + Boss 击杀数独立生成，互不干扰。
击败 Boss 不重置角色位置 —— 采用保护区模式重新随机。

#### 核心逻辑：保护区 + 重新随机

```
[击败 Boss 时触发]
Step 0 — 触发：击败 Boss
Step 1 — 地图尾部 +5 格（从总格数往后追加）
Step 2 — 查表：根据当前已击败 Boss 数，查 §16.3 分布表得到目标数量
Step 3 — 差额计算：当前已有数量 vs 目标数量 → 追加新格子池
Step 4 — 标记保护区：
  保护范围 = [当前位置 - 3, 当前位置 + 3]（环形取模）
  保护区共 7 格（含当前位置本身）
  保护区内格子不变（类型、等级、建设状态全部保留）
Step 5 — 保护区外所有格子（含新追加的 5 格）合并为"待洗牌池"
Step 6 — 从待洗牌池中，按分布表的目标差额重新生成格子类型
Step 7 — 对重新生成的待洗牌池进行 Fisher-Yates 洗牌
Step 8 — 间距约束检查（见 §16.5）
Step 9 — 将洗牌后的池插入回原地图（保护区位置不动，两端连接）
Step 10 — 保存新布局
```

> 设计意图：保护区保证玩家当前所在区域和前后路不受打乱，避免"踩到一半的格子在眼皮底下变了"。保护区外的大洗牌仍保证地图整体的随机性和公平性。

#### 示例

```
地图 53 格，角色在位置 25。
保护区 = [22, 23, 24, 25, 26, 27, 28]（7 格不变）
保护区外 = [0~21] + [29~52] + 新追加 5 格 = 共 51 格重新随机
```

### 16.5 间距约束规则

| 格子 | 间距要求 |
| --- | --- |
| ⚔精英格 | ≥3 格 |
| 🛌休息格 | ≥5 格 |
| ⚡闪电格 / 🌀折跃格 | 互相≥8 格 |
| 🪙彩票格 | ≥6 格 |
| 🔧建设格 | 连续不超过 2 个 |

> 约束规则生效前提：池内已存在至少该数量的该类型格子，否则跳过。

## 17. BOSS 挑战排队机制

### 17.1 排队触发

- 触发前提：玩家在任意时刻点击地图上的 BOSS 格 → 进入 BOSS 挑战队列
- 排队时无需停留在 BOSS 格上（可远程预约）
- 同一时间只能排队 1 个 BOSS（重复点击覆盖旧排队）

### 17.2 执行时机（核心规则）

BOSS 挑战的触发时机严格固定：

```
[当前格子事件完成] → [检查 BOSS 队列] → [有排队？] → [触发 BOSS 战]
                                               ↓
                                        [无排队？] → [掷骰继续]
```

每次触发时机：

- 停留在任一格子的事件完成后（战斗结束、开箱结束、锻造完成等）
- 在下一次掷骰之前检查 BOSS 排队状态
- 若有排队 → 不掷骰，立即进入 BOSS 战
- BOSS 战完成后 → 回到地图，掷骰继续前进（正常推进）

#### 详细流程

```
若角色在正常走圈过程中触发 BOSS 挑战排队：

[踩到格子 → 格子事件执行 → 事件完成]
           ↓
    检查 BOSS 排队状态
    ├─ 有排队 → [进入 BOSS 战]
    │    ↓
    │  BOSS 战结束（胜/败）
    │    ↓
    │  回到地图 → 掷骰继续前进
    │
    └─ 无排队 → 掷骰继续前进（正常流程）
```

### 17.3 排队期间的同步规则

**在线行为**：

```
点击 BOSS → 排队标记设置
玩家继续自动走圈（格子正常触发）
当前格子事件完成 → 触发 BOSS 战
BOSS 战期间走圈暂停
BOSS 战结束后 → 恢复走圈
```

**离线行为**：

```
离线前若有 BOSS 排队标记
与在线相同逻辑：事件完成 → BOSS 战 → 继续前进
若 BOSS 战失败 → 标记消耗，继续走圈（不掉层）
```

**退出排队**：

```
玩家可随时点击已标记的 BOSS 格 → 取消排队
取消排队后 BOSS 排队标记清除
```

### 17.4 边界情况

```
多次排队：
  同一 Boss 格连续多次排队 → 覆盖前一次（只保留最后一次）

BOSS 战与挑战格冲突：
  若排队 BOSS 与踩到挑战格同时发生 → BOSS 优先
  挑战格事件正常完成 → 触发排队 BOSS → BOSS 完成后继续前进

排队 BOSS 升级：
  若排队后玩家属性/等级发生变化 → BOSS 等级以进入战斗时的
  玩家属性为准（BossLv = playerLv + 2，见 Boss 系统）

排队切换：
  排队 A Boss → 点击 B Boss → 排队切换为 B Boss
```

### 17.5 设计柱检验

| 设计决策 | 满足柱 | 说明 |
| --- | --- | --- |
| BOSS 排队不打断当前走圈 | 柱 1 挂机爽感 | 玩家可预约 BOSS 而不必中断自动挂机，事件完成后自然插入 |
| 事件完成→掷骰前触发 | 柱 4 格子策略 | 排队机制不改变格子的基本节奏，只在"事件→掷骰"间隙插入 |
| 远程预约无需踩格 | 柱 1 挂机爽感 | 全图任意位置均可预约，减少"专程走过去"的无效操作 |
