# 角色创建与存档管理系统案 v0.5

> 对应：联网版角色创建、删除和服务端持久化；本地存档槽仅供开发回归
> 版本：v0.5 | 日期：2026-09-17 | 状态：已按联网规则修订
> v0.2→v0.3 变更：① §7.1 新增技能槽/装备槽解锁状态持久化；② §7.8 新增 Boss 排队标记 + 持续性效果计数器；③ §7.10 天气段补全种子/序列索引/骰子计数器/阈值/缓冲/预生成序列；④ 新增 §7.14 离线数据（最后在线时间戳）

> 联网版覆盖规则：每个账号只允许1个角色，角色和资产以服务端数据库为准；不迁移`slot_0~2.json`。§2、§4~§6原三槽切换流程仅供本地开发回归，不属于网页网络服功能。联网账号与角色规则以[[账号注册登录与安全系统案【定案】]] §4.3、§5、§9为准。

| 设计决策 | 满足柱 | 说明 |
|---------|--------|------|
| 联网每账号1角色 | 柱5不肝不氪 | 无角色槽扩容和多角色重复养成，登录流程简单 |

## 2. 本地回归模式存档槽位（联网版不适用）

### 2.1 基础规则

| 项目 | 内容 |
|------|------|
| 总槽位数 | 3 个 |
| 同时激活数 | 1 个 |
| 存档数据 | 本地文件存储，每槽位 1 个独立文件 |
| 新增槽位 | 3 个永久，不可扩容、不可购买额外槽位 |

```
存档结构：
  slot_0.json  — 槽位 1（默认首选）
  slot_1.json  — 槽位 2
  slot_2.json  — 槽位 3
```

### 2.2 槽位状态

| 状态 | 图标 | 说明 |
|------|------|------|
| 空槽位 | `[ + ]` | 未创建角色，点击进入创建流程 |
| 已创建（非激活） | 角色名 + 等级 + 最后游玩时间 | 点击可切换激活或删除 |
| 已创建（激活中） | 角色名 + 等级 + `[当前]` 高亮标记 | 当前正在游玩的存档 |

> 游戏启动时自动加载上次激活的存档。若该存档损坏或不存在 → 回退到主界面选择槽位。

## 3. 角色创建

### 3.1 创建流程

```
Step 1 — 在主界面选择一个空槽位，点击 [ + ]

Step 2 — 进入角色创建界面
  ├─ 输入角色名称
  │   ┌──────────────────────────────────┐
  │   │ 输入角色名称（权重最多14）          │
  │   │ ┌──────────────────────────────┐ │
  │   │ │                              │ │
  │   │ └──────────────────────────────┘ │
  │   │ 字节数：0 / 14                    │
  │   └──────────────────────────────────┘
  │
  ├─ 角色形象预览（默认外观，后续 [待设计] 可自定义）
  │
  └─ [开始冒险] 按钮（名称合法时可用）

Step 3 — 确认创建
  弹出二次确认："确定以「角色名」开始冒险吗？"
  确认 → 写入 slot_N.json，设为激活存档，进入游戏
  取消 → 返回创建界面

Step 4 — 创建完成
  角色自动出现在 🏠勇者之家（位置 0）
  所有初始数据按 [[角色属性策划案【定案】]] §1 初始值初始化
```

### 3.2 角色名称规则

| 规则 | 内容 |
|------|------|
| 长度 | 名称权重1~14；汉字计2，英文字母和数字计1 |
| 允许字符 | 汉字、英文字母、数字 |
| 禁止字符 | 空格、下划线、标点、表情及其他字符 |
| 敏感词 | 首版不接入敏感词词库 |
| 唯一性 | 联网服全服唯一；英文字母比较时不区分大小写 |

```
名称权重容量：
  纯英文/数字 → 最多14个字符（如"HeroOfLight"）
  纯中文 → 最多7个汉字
  中英混搭 → 如"勇者ABC"权重=2×2+3=7
  
边界（规则 3）：
  权重超过14 → 拒绝输入，输入框下方实时显示"名称长度：X / 14"
  删除到权重0 → 名称输入框为空 → [开始冒险]灰掉，提示"请输入角色名"
  服务端发现重名 → 不创建角色，保留输入并提示更换名称
```

### 3.3 反向情况（规则 2）

```
├─ 名称包含空格、符号或表情 → 客户端提示且服务端拒绝
├─ 名称仅1个字母/数字或1个汉字 → 权重在1~14内，允许
├─ 点击开始前关闭窗口 → 不保存，回到主界面
└─ 槽位已有存档时误点击 → 不会进入创建，只有空槽位显示 [ + ]
```

## 4. 本地回归模式存档删除（联网版不适用）

### 4.1 删除流程

```
删除入口：主界面 → 选择一个已创建的存档 → 点击 [删除] 按钮

Step 1 — 点击 [删除]
  弹出警告对话框：
  ┌──────────────────────────────────┐
  │ ⚠ 确定要删除「角色名」吗？       │
  │                                  │
  │ 等级：Lv.（等级）                │
  │ 最后游玩：（日期）               │
  │                                  │
  │ 此操作不可撤销！                 │
  │                                  │
  │ 长按 [删除] 3 秒确认             │
  │ ┌──────────────────────────┐    │
  │ │     ■ 长按以删除          │    │
  │ └──────────────────────────┘    │
  │                                  │
  │          [ 取 消 ]                │
  └──────────────────────────────────┘

Step 2 — 长按 3 秒进度条走满
  → 删除 slot_N.json 文件
  → 槽位恢复为 [ + ] 空槽位
  → 提示"「角色名」已被删除"

Step 3 — 取消
  点击 [取消] 或未长按满 3 秒松开 → 对话框关闭，存档保留
```

### 4.2 删除激活存档

```
若删除的存档是当前激活的存档（标记 [当前]）：
  Step 1 — 同上（长按确认）
  Step 2 — 删除文件
  Step 3 — 自动回到主界面
          若其他槽位有存档 → 不自动激活，停留在槽位选择界面
          若全部槽位为空 → 显示空槽位界面，引导创建新角色
```

### 4.3 反向情况（规则 2）

```
├─ 长按未满 3 秒松开 → 删除取消，存档保留
├─ 删除确认期间退出游戏 → 不删除，重新启动后存档仍在
├─ 删除过程中断电/异常 → 文件删除操作是原子性的（先写临时文件再重命名 [需与程序确认]）
└─ 删除文件失败（磁盘满/权限不足）→ 弹窗提示"删除失败，请检查磁盘空间"，存档保留
```

## 5. 本地回归模式存档切换（联网版不适用）

### 5.1 切换流程

```
主界面 → 点击一个非激活的已创建存档

Step 1 — 弹出确认
  "确定切换到「角色名」吗？当前「激活中的角色名」将被挂起。"

Step 2 — 确认切换
  保存当前存档（自动保存）→ 加载目标存档 → 设为激活

Step 3 — 取消
  不切换，保留当前激活存档
```

### 5.2 切换时机

```
可在以下时机切换：
  ├─ 游戏主界面（启动时、退出到主界面后）
  ├─ 游戏内设置菜单 → [返回主界面] → 再切换
  └─ 不可在游戏运行中直接切换（必须回到主界面）
```

### 5.3 挂起存档行为

```
当前激活存档被切换后：
  ├─ 角色停留在当前格位置，不继续移动
  ├─ 所有持续效果（神祇/天气/增益）保留剩余时间
  ├─ 不会触发离线结算（因为玩家在线，只是切换了存档）
  └─ 下次切换回来 → 从上次离开的位置继续
```

> **设计柱检验**：挂起存档不触发离线结算 → 防止玩家通过反复切换刷离线收益。纯单存档激活 = 简单清晰。

## 6. 本地回归模式极限情况（联网版不适用）

```
├─ 3 个槽位全满 → [ + ] 不显示，无法新建 → 需先删除一个存档
├─ 3 个槽位全空 → 只显示 3 个 [ + ]，必须先创建角色才能进入游戏
├─ 存档文件损坏 → 读取失败 → 该槽位显示"存档损坏"标记，提供 [删除] 按钮重建
├─ 存档文件被外部删除（玩家手动删文件）→ 下次启动时该槽位恢复为 [ + ]
├─ 名称权重为1 → 允许（如"A"）
├─ 名称含emoji → 非法字符，拒绝创建
└─ 升级/卸载游戏 → 存档文件在游戏目录下 → 卸载前提示备份 [待设计]
```

## 7. 存档数据完整清单

以下为每个存档槽位（`slot_N.json`）必须持久化的全部数据，按系统分块。标注 `[T]` 表示该字段在离线期间也会被修改（需要保存），标注 `[R]` 表示纯运行时计算不存入存档（由其他字段推导）。

### 7.0 存档元信息

```
version          — 存档格式版本号（升级兼容用）
character_name   — 角色名（汉字计2、字母/数字计1，总权重1~14）
created_at       — 创建时间戳
last_saved       — 上次保存时间戳
last_online      — 上次在线时间戳（用于计算离线收益）
```

### 7.1 角色属性（→ [[角色属性策划案【定案】]]）

```
[T] level              — 当前等级 (1~50)
[T] exp                — 当前 EXP
[T] hp_current         — 当前 HP
[T] free_attr_points   — 未分配的属性点数

自由属性点分配（玩家手动加点）：
[T] attr_atk           — 攻击自由点
[T] attr_def           — 防御自由点
[T] attr_spd           — 速度自由点
[T] attr_lck           — 幸运自由点

技能与装备槽位解锁（随等级解锁，见 [[角色属性策划案【定案】]] §5.3）：
[T] skill_slots_num         — 已解锁的技能槽数量 (2~6)
[T] equip_slots_unlocked    — 已解锁的装备槽数量 (3~8)

[R] 以下为派生值，运行时计算，不存入存档：
   total_atk, total_def, total_hp, total_spd, atk_cd
```

### 7.2 货币（→ [[背包道具货币系统案【定案】]] §2）

```
[T] gold               — 金币 (int64, 无上限)
[T] revive_coins       — 复活币 (int32, 0~3)
[T] essence            — 分解精华 (int64, 无上限)
[T] item_inventory     — 道具堆叠（含打孔器；每格上限见[[背包道具货币系统案【定案】]] §3.2）
```

### 7.3 装备（→ [[装备系统细化案【定案】]]）

#### 7.3.1 已装备槽位（8 槽 × 3 套）

```
[T] equipped_slot[set_0..2][slot_0..7] = 装备引用 或 null
      槽位: 0=武器 1=防具 2=鞋子 3=戒指 4=项链 5=披风 6=头盔 7=护符
```

#### 7.3.2 每件装备的数据

```
[T] equip_id               — 唯一标识
[T] equip_quality           — 品质 (0=普通 1=精良 2=稀有 3=史诗 4=传说)
[T] equip_slot_type         — 部位
[T] equip_name              — 装备全名（按命名规则生成，也存一份便于恢复）
[T] equip_level             — 装备等级（出处：档位）
[T] equip_enhance_lv        — 强化等级（绑定到槽位而非装备，见 §7.3.3）
[T] equip_main_attr         — 主属性值
[T] equip_affixes[]         — 附加词条列表 [{id, type, value}]
[T] equip_set_name          — 套装名 (null = 无套装)
[T] equip_set_affixes[]     — 套装专属词条列表 [{id, name, effect}]
[T] equip_gem_slots         — 宝石孔数（初始生成）
[T] equip_gems[]            — 已镶嵌宝石列表 [{type, level}] 或 null
[T] equip_locked            — 锁定状态 (bool)
[T] equip_created_at        — 获取时间戳
```

#### 7.3.3 槽位强化等级（独立于装备，参考 §7 → 装备槽位强化）

```
[T] slot_enhance_lv[slot_0..7] — 每个槽位的强化等级 (0~200)
      3 套装备共享强化等级，存入一次
```

#### 7.3.4 多套切换状态

```
[T] active_set_index     — 当前激活的套装编号 (0/1/2)
```

### 7.4 道具背包（→ [[背包道具货币系统案【定案】]] §3）

#### 7.4.1 背包容量

```
[T] backpack_item_capacity      — 道具背包总容量 (100~1000)
[T] backpack_equip_capacity     — 装备背包总容量 (100~1000)
```

#### 7.4.2 道具列表

```
道具背包 — 每格：
[T] item_type      — 道具类型 (gem / destiny_card / synth_ticket / boost_talisman)
[T] item_subtype   — 子类型 (gem: 红/蓝/绿/黄/紫/钻/橙/银; destiny: 绿/蓝/紫/橙)
[T] item_level     — 等级 (仅宝石: 1~10)
[T] item_count     — 堆叠数量 (仅堆叠类型)
[T] item_slot      — 占用的格子编号

天命卡特别字段（不堆叠，每张独占 1 格）：
[T] card_rarity    — 稀有度 (精良/稀有/史诗/传说)
[T] card_name      — 卡名 (如 "小有财运")
```

### 7.5 装备背包（→ [[背包道具货币系统案【定案】]] §4）

```
装备背包 — 每格存放一件装备的引用（equip_id），不重复存储装备数据。
装备数据本身存在全局装备注册表中（见 §7.3.2）。
```

```
[T] lottery_tickets[]   — 彩票号码数组（int[10]，空槽=-1，号码范围0~999，显示补足3位）

### 7.7 拍卖行仓库（→ [[背包道具货币系统案【定案】]] §4.6 / [[拍卖行系统细化案【定案】]] §2、§4）

### 7.8 大地图（→ [[大地图规则细化案【定案】]]）

```
[T] map_current_pos          — 角色当前所在格号 (0~N-1)
[T] map_total_cells           — 当前地图总格数
[T] map_boss_defeated[]       — 已击败的 Boss 编号列表
[T] map_tier                  — 当前档位 (= 已击败 Boss 数量)
[T] map_lap_count             — 当前圈数计数器

```
[T] map_ongoing_effects[]   — 来自命运事件的持续效果
        [{effect_name, remaining_count}]
        例：技能大赛：剩余 N 场 / 攻击削弱：剩余 N 场 /

```
[T] deity_active[]      — 当前激活的神祇效果列表

### 7.10 天气（→ [[天气系统细化案【定案】]]）

[T] weather_current           — 当前天气名称 (enum: 晴天/雷雨天/细雨/大雾/暴风雪/烈日/沙暴/北极光)
[T] weather_dice_counter      — 当前轮已掷骰次数 (0~15)
[T] weather_threshold         — 触发下一次变更需要的骰子次数 (1~15)
