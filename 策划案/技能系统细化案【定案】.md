# 技能系统细化案 v0.8

> v0.8 | 2026-09-17 | 状态：已定案；Boss档位上限同步为200

## 0. v0.6 核心改动：行动间隔与持续效果定案

### 0.1 技能获得

- 新角色免费永久解锁「重击」「治疗波」，并默认装备，保证 Lv.1 的两个槽位均可使用。
- 其余 34 个技能仅使用金币永久解锁，不消耗道具，不随机掉落，不设置等级或 Boss 前置。
- 购买成功：金币立即扣除，技能加入当前角色的永久技能池，立刻可装备，并立即自动存档。
- 购买失败：金币不足、技能不存在或已经解锁时，不扣金币、不改变技能池。
- 解锁归属当前存档，不跨角色共享；删档后不可恢复。
- 技能解锁不退款。后续数值调整不追补差价，也不收回已解锁技能。
- 旧存档迁移：免费补发「重击」「治疗波」，原先已经装备的技能视为已解锁，避免损失原 Build。

### 0.2 行动冷却

玩家技能不再使用秒数 CD，改为「行动间隔」。技能释放后，每次该单位真正获得行动时，冷却推进 1；硬控导致的跳过行动不推进技能冷却。

本文后续统一使用“技能行动冷却”。旧称“技能CD”若出现在历史版本记录中，只表示历史术语，不表示按真实秒数倒计时。

```text
行动间隔 = 1：每次自身行动都可参与技能选择
行动间隔 = 2：本次释放后，下一次行动冷却，第二次行动重新可用
实际时间约等于：行动间隔 × 当前出手间隔
```

速度继续缩短出手间隔，因此会等比例加快普攻和技能循环；Dot/Hot 使用真实秒数计时，不随行动速度改变。冷却缩减最多 50%，计算后保留小数，冷却每次行动减少 1；因此它仍有效，但存在整数行动断点。多个技能同时就绪时，继续按优先级 3 > 2 > 1、同级槽位从左到右选择。

### 0.3 金币定价依据

现行经济模型在怪物 Lv.10/30/50/100 时，日均总金币约为 41万/122万/204万/408万。技能采用低门槛横向收集定位，总收藏价为 **127.6万金币**，不承担主要经济回收职责；主要金币消耗仍由装备强化、背包扩容和建设承担。

### 0.5 成功、失败与边界

- 战斗中只能使用已解锁且已装备的技能；购买不自动替换现有槽位。
- 同一技能只能解锁一次、装备一次；槽位已满时装备失败，不改变原槽位。
- 金币恰好等于价格时允许购买，购买后金币为 0；金币不得为负数。
- 行动间隔最小为 1；冷却缩减不会让同一技能在一次行动中释放多次。
- 无尽打击首次使用按90%结算，第10次封顶180%，第11次及以后仍为180%；使用其他技能不清除累计次数，战斗结束清零。
- 持续效果总次数最小为1，施加瞬间必定先触发1次；目标死亡后不再触发剩余次数。
- 同名刷新型Dot会立即触发新一轮首跳并重置剩余次数；不同来源实例独立，单目标最多10个实例。
- 购买发生在非战斗技能面板；已经开始的战斗使用开战时技能快照。

## 1. 技能装备规则

### 1.1 技能槽

```
技能槽数：
  Lv.1  → 2 槽（初始）
  Lv.5  → 3 槽
  Lv.15 → 4 槽
  Lv.35 → 5 槽
  Lv.45 → 6 槽（上限）

每槽可装备 1 个技能，每个技能只能装备 1 次（不可重复装备同名技能）。
玩家可从已解锁的技能池中自由选择搭配。
```

### 1.2 优先级系统

```
每个技能槽有独立的"优先级等级"，玩家手动设定：

  默认值：1（最低）
  可调范围：1 ~ 3（最高）

当多个技能的 CD 同时归零时：
  → 先按优先级等级排序（3 > 2 > 1）
  → 同一优先级有多个技能可用 → 按技能槽从左到右的顺序释放
  → 全部技能行动冷却未归零 → 执行普攻

例：
  技能槽 [护盾:3] [毒刃:2] [重击:2] [治疗波:3] [连击:1] [烈焰灼烧:1]
  当前 CD 归零的技能：重击(2) + 烈焰灼烧(1) + 连击(1)
  → 最高优先级 = 2（重击），先放重击
  → 若护盾(3) CD 也归零 → 护盾 > 重击（3 > 2）
```

> 设计意图：玩家通过调整优先级来定制"自动战斗中的决策逻辑"。
> Lv.3 = 我希望这个技能第一时间放（如生存/控制）；Lv.1 = 填充输出。

## 2. 普攻规则

### 2.1 触发条件

```
当单位行动时，所有已装备技能的 CD 均未归零 → 执行普攻。

普攻特性：
  - 无 CD，始终可用
  - 不暴击
  - 不触发任何特殊效果
  - 不消耗资源
```

### 2.2 普攻目标选择

```
根据 [[怪物系统细化案【定案】]] §3.3 站位规则：

1. 若敌方前排有存活怪物 → 锁定前排怪物
2. 若前排已空 → 锁定后排中 HP 最低的怪物
3. 普攻不跨排：绝不跳过存活的敌方前排去攻击后排

普攻伤害 = 总攻击力 × 100%
  → 进入 [[战斗系统规则案【定案】]] §7 伤害管道
```

> 战场布局：玩家在左，敌人在右，敌人分前排（前1/前2/前3）和后排（后1/后2/后3）。

### 3.1 目标标签总表

| 目标标签 | 选择规则 | 跨排 | 示例技能 |
|---------|---------|------|---------|

| 后排位序 | 锁定后排最左侧存活目标（后1→后2→后3）；后排空→转前排最左 | ✅ 后排空时跨 | [待设计] |

| 玩家角色 | 目标为自己（玩家） | — | 护盾、铁壁姿态 |
| 玩家角色治疗 | 恢复自己 HP | — | 治疗波、生命绽放 |

### 3.2 目标选择执行流程

```
技能系统接收战斗引擎请求：
  输入：技能目标标签 + 当前战场存活单位列表
  
  Step 1 — 筛选存活单位
    排除已死亡单位
    排除处于"不可选中"状态的单位（若有）
  
  Step 2 — 按标签规则排序/筛选
    位序类 → 按位置顺序取第一个存活
    数值类 → 按对应属性排序取最值
    AOE类 → 返回范围内所有存活单位
    贯穿类 → 先取前排目标，再取同行后排目标（2个ID）；前排全空→取后排位序最左目标（1个ID，无穿透）
  
  Step 3 — 控制状态处理
    若目标处于"免疫控制"状态（坚毅/某些Boss）→ 控制技能跳过该目标，选下一个
    若目标已处于同类型控制 → 新控制覆盖旧控制（刷新持续时间）
    若目标已处于不同类型控制 → 可同时存在（见 §6.5 控制叠加规则）
  
  Step 4 — 返回目标单位ID列表
    单体 → 返回1个ID
    AOE → 返回多个ID
    玩家角色 → 返回玩家ID

  战斗引擎接收目标列表 → 对每个目标执行 [[战斗系统规则案【定案】]] §4 判定流程
```

### 3.3 控制目标特殊处理

```
控制技能（冰冻/眩晕/沉默/麻痹）选择目标时：

  若主目标免疫控制 → 跳过该目标，按标签规则选下一个
    例：冰冻射击（前排位序）→ 前1免疫 → 选前2 → 前2也免疫 → 选前3
  
  若全部前排都免疫 → 技能仍释放，但无控制效果（伤害正常结算）
  
  AOE控制 → 对每个目标单独判定免疫，免疫的目标不受控制但受伤害
```

## 4. 控制状态完整定义（差异化设计）

### 4.1 状态总览

| 状态  | 图标  | 核心效果            | 差异化特点                          | 对Boss    |
| --- | --- | --------------- | ------------------------------ | -------- |
| 冻结  | ❄️  | 无法行动 + 出手CD暂停   | 受击触发"破冰"（+50%伤害），**破冰后立即移除冻结** | 持续时间×0.5 |
| 眩晕  | 💫  | 无法行动 + 出手CD暂停   | **持续到时间结束**，不受击解除              | 持续时间×0.5 |
| 沉默  | 🚫  | 无法释放技能 | 技能行动冷却正常推进，可普攻 | 持续时间×0.5 |
| 麻痹  | ⚡   | **新进入的技能行动冷却×1.3** | 软控制，不影响普攻和移动 | 持续时间×0.5 |
| 减速  | 🐌  | 出手CD×1.5        | 软控制，不影响行动                      | 持续时间×0.5 |
| 禁疗  | 💔  | **受到治疗效果-50%**  | 针对治疗/护盾体系                      | 持续时间×0.5 |

### 4.2 冻结（Freeze）

```
效果：
  - 目标完全无法行动（不能普攻、不能放技能）
  - 出手CD计时器暂停（冻结结束后从暂停处继续）
  - 目标被一层冰霜包裹（视觉表现）

破冰机制：
  - 冻结期间目标受到任何伤害 → 触发"破冰"
  - 破冰效果：该次伤害额外 +50%（与冰霜套装4件效果加算，见 [[装备系统细化案【定案】]] §4.2）
  - ⚠ 破冰后冻结**立即移除**（状态结束，目标恢复行动）

与眩晕的区别：
  - 冻结：受击必破冰+50%伤害，**破冰即解除**
  - 眩晕：持续到时间结束，不受击解除
  - 冻结更适合"控住后单次爆发"，眩晕更适合"稳定控场时间"

叠加规则：
  - 同一目标被再次冻结 → 刷新持续时间
  - 冻结期间不可叠加层数（与Dot不同）

免疫/抵抗：
  - 坚毅状态：免疫冻结
  - Boss：冻结持续时间 × 0.5（8秒→4秒）
  - 部分Boss可能有"抗寒"被动：完全免疫冻结
```

### 4.3 眩晕（Stun）

```
效果：
  - 目标完全无法行动（不能普攻、不能放技能）
  - 出手CD计时器暂停
  - 目标头顶旋转星星（视觉表现）

持续时间规则：
  - 眩晕**持续到时间结束**，不受击解除
  - 设计意图：眩晕 = 稳定的硬控时间，玩家可以精确计算控制窗口

与冻结的区别：
  - 冻结：受击必破冰+50%伤害，破冰后立即解除
  - 眩晕：持续到时间结束，无额外伤害
  - 冻结更适合"控住后单次爆发"，眩晕更适合"稳定控场时间"

叠加规则：
  - 同一目标被再次眩晕 → 刷新持续时间

免疫/抵抗：
  - 坚毅状态：免疫眩晕
  - Boss：眩晕持续时间 × 0.5
```

### 4.4 沉默（Silence）

```
效果：
  - 目标无法释放技能（技能按钮变灰）
  - 目标仍可执行普攻（普攻是"基础动作"，非技能）
  - 沉默期间每次真正行动仍推进技能行动冷却（只是不能释放技能）

与冻结/眩晕的区别：
  - 冻结/眩晕：完全不能动（包括普攻）
  - 沉默：可以普攻，不能放技能
  - 对玩家：沉默 = 只能普攻，考验普攻Build
  - 对怪物：沉默 = 怪物只能普攻（怪物普攻通常较弱）

叠加规则：
  - 同一目标被再次沉默 → 刷新持续时间

免疫/抵抗：
  - 坚毅状态：免疫沉默
  - Boss：沉默持续时间 × 0.5
```

### 4.5 麻痹（Paralysis）

```
效果：
  - 目标释放技能时，新记录的技能行动冷却×1.3
  - 已经存在的冷却不追溯增加；目标仍可正常普攻和放技能
  - 目标受击时额外 +20%伤害（导电）

与冻结/眩晕的区别：
  - 麻痹：**软控制**，不影响行动，只影响技能频率
  - 冻结/眩晕：**硬控制**，完全无法行动
  - 麻痹适合"压制技能循环"，冻结适合"控后爆发"，眩晕适合"稳定硬控"

叠加规则：
  - 同一目标被再次麻痹 → 刷新持续时间（不叠加倍率，不会CD+60%）

免疫/抵抗：
  - 坚毅状态：免疫麻痹
  - Boss：麻痹持续时间 × 0.5
  - 部分怪物可能有"绝缘"被动：免疫麻痹
```

### 4.6 减速（Slow）

```
效果：
  - 目标出手CD × 1.5（相当于攻击频率降低33%）
  - 目标仍可正常行动（普攻/技能均可）
  - 只是变慢，不是不能动

与冻结/眩晕/麻痹的区别：
  - 减速是"软控制"，其他三种是"硬控制"
  - 减速不影响目标选择、不影响技能释放
  - 减速适合"持续压制"，硬控制适合"打断关键动作"

叠加规则：
  - 同一目标被再次减速 → 刷新持续时间（不叠加倍率，不会×2.25）
  - 减速 + 其他控制 → 可同时存在（见 §6.5）

免疫/抵抗：
  - 坚毅状态：免疫减速
  - Boss：减速持续时间 × 0.5
```

### 4.7 控制状态对比表

| 维度 | 冻结 | 眩晕 | 沉默 | 麻痹 | 减速 | 禁疗 |
|------|------|------|------|------|------|------|
| 能否普攻 | ❌ | ❌ | ✅ | ✅ | ✅ | ✅ |
| 能否放技能 | ❌ | ❌ | ❌ | ✅（新行动冷却×1.3）| ✅ | ✅ |
| 出手CD | 暂停 | 暂停 | 正常走 | 正常走 | ×1.5 | 正常走 |
| 受击额外效果 | +50%伤害（破冰）| 无 | +20%普攻伤害 | +20%伤害 | 无 | 无 |
| 提前解除 | ✅ 受击必解除 | ❌ | ❌ | ❌ | ❌ | ❌ |
| 控制强度 | 中（可被利用）| 高（稳定时间）| 低（可普攻）| 中（软控制）| 极低 | 中（针对治疗）|
| 适用场景 | 控后爆发 | 稳定控场 | 打断技能循环 | 压制技能频率 | 持续压制 | 对抗治疗/护盾 |

### 4.8 控制叠加规则

```
不同控制类型可同时存在：
  例：目标同时被"冻结"+"减速" → 冻结优先（无法行动），减速等冻结结束后生效
  例：目标同时被"麻痹"+"禁疗" → 同时生效（新行动冷却×1.3且治疗-50%）

同类型控制不可叠加，只刷新持续时间：
  例：目标已冻结3秒，再中8秒冻结 → 持续时间刷新为8秒（不是11秒）

控制优先级（同时存在多个时）：
  硬控制 > 软控制
  硬控制：冻结 = 眩晕（同级，按最后施加的生效）
  软控制：沉默、麻痹、减速、禁疗（互不冲突，可同时存在）
  硬控制期间 → 软控制仍生效（但硬控制优先决定能否行动）
    例：冻结+麻痹 → 无法行动（冻结优先），冻结结束后麻痹继续（新行动冷却×1.3）

控制与坚毅：
  坚毅状态 = 免疫所有控制（冻结/眩晕/沉默/麻痹/减速/禁疗）
  坚毅结束后 → 若控制持续时间未过，继续生效
```

## 5. 治疗与护盾

### 5.1 治疗公式

```
治疗量 = 技能基础治疗值 × 受疗修正

受疗修正 = 1.0 × 禁疗修正
  禁疗修正：
    目标处于禁疗状态 → 0.5（治疗效果-50%）
    目标未处于禁疗状态 → 1.0

治疗规则：
  - 治疗量不暴击、不格挡、不受防御影响
  - 过量治疗不溢出（HP 不超过最大值）
  - 治疗可以发生在战斗中任何时刻（包括敌方回合）
  - 治疗不受控制状态影响（被冻结/眩晕仍可被治疗）
  - 禁疗仅影响治疗量，不影响护盾
```

### 5.2 护盾公式

```
护盾量 = 技能基础护盾值 × 护盾修正

护盾修正 = 1.0
护盾持续时间 = 5 秒（所有护盾统一）

护盾规则：
  - 护盾优先于 HP 被扣减（见 [[战斗系统规则案【定案】]] §7 Step 7）
  - 护盾过期：持续时间结束后，剩余护盾值消失
  - 护盾不享受防御减伤（护盾吸收的是"最终伤害"）
  - 护盾可抵挡Dot伤害（Dot每跳先扣护盾）

护盾叠加规则：
  - 获得新护盾时：新护盾数值与剩余护盾数值**叠加**
  - 持续时间**刷新为5秒**（从当前时刻重新计时）
  - 例：当前护盾剩余 200，持续2秒 → 获得新护盾 300 → 总护盾 500，持续5秒
  - 例：当前护盾剩余 500，持续4秒 → 获得新护盾 100 → 总护盾 600，持续5秒

护盾与治疗的区别：
  - 治疗：直接恢复HP，可溢出（但溢出部分浪费）
  - 护盾：临时额外生命，过期消失，不享受防御加成，可叠加刷新
  - 设计意图：护盾 = 预防性生存，鼓励连续获取；治疗 = 恢复性生存
```

### 5.3 治疗/护盾技能列表

| 技能名  | 类型  | 目标   | 效果                   | 行动间隔  |
| ---- | --- | ---- | -------------------- | --- |
| 治疗波  | 治疗  | 玩家角色 | 恢复 攻击力×150% HP       | 4  |
| 生命绽放 | 治疗  | 玩家角色 | 立即恢复5%最大HP，之后每1秒一次，共5次 | 5 |
| 护盾   | 护盾  | 玩家角色 | 生成护盾 = 防御力×300%，持续5秒 | 3  |

> 所有护盾持续时间统一为 5 秒，叠加规则见 §5.2。

### 6.7 技能设计说明

```
Dot/Hot 触发规则（见 [[战斗系统规则案【定案】]] §7.1）：
  - 每个持续效果明确配置：单次倍率、触发间隔、总次数
  - 释放瞬间立即触发第1次，后续按真实秒数间隔触发
  - 触发与单位行动、速度、硬控和行动间隔无关
  - Dot伤害 = 施加者攻击力 × 单次倍率，不经过防御/暴击/格挡管道
  - Hot治疗遵守禁疗及溢出治疗规则
  - 例：生命绽放触发点为0/1/2/3/4秒，共5次，不是“持续5秒后再补第5次”

  Dot 实例模型：
  - 每个技能施加的 Dot 是独立实例，用 dot-id 区分
  - dot-id = 技能ID + 施加序号（程序层确保唯一性）

  不同技能 → 不同 dot-id → 独立实例，各自跳伤害，互不影响：
    例：毒刃(30%×4次) + 毒雾(35%×5次)
    → 2个独立实例，各按自己的真实秒数计时器触发
    即使都叫"中毒"，因 dot-id 不同，伤害独立计算

  同一技能再次施加 → 由该技能的 Dot叠加模式 决定：
    程序层支持2种模式（每个技能在技能表中配置）：
    
    模式A — 刷新模式（默认）：
      已有同id实例 → 重置单次伤害、剩余次数和计时器，不创建新实例，并立即触发新的第1次
      例：毒刃再放 → 立即跳30%，剩余3次重新从2秒计时
    
    模式B — 叠加模式：
      已有同id实例 → 创建新实例（新实例独立计时，与旧实例共存）
      例：某技能配置叠加模式 → 放3次 = 3个同id实例同时跳伤害
      叠加模式适用于"层数概念"技能（如烈焰套灼烧）

    未配置时默认为模式A（刷新）。
    当前所有玩家Dot技能均为模式A，叠加模式预留给未来技能/套装机制。

  Dot 类型（视觉/分类用，影响套装条件判断）：
  - 中毒（绿色）、灼烧（红色）、流血（暗红）等
  - 类型仅决定视觉表现和套装/技能的条件判断（如烈焰套"灼烧实例≥3"）
  - 不同类型的 Dot 天然是不同 dot-id，互不干扰

  实例上限：
  - 同一目标最多同时存在 10 个 Dot 实例（不区分类型和 dot-id）
  - 超出时 → 最早施加的实例被移除（先进先出）
  - 设计意图：防止叠加模式下实例过多影响性能

  结束与边界：
  - 总次数最小为1；配置1次时只在释放瞬间触发，之后不保留实例
  - 目标死亡时，其全部Dot/Hot实例随目标清除，不再产生后续事件
  - 剧毒爆发按“单次伤害×剩余次数”求和；已经立即触发的次数不重复计算，且爆发不消耗Dot
  - 瘟疫传播复制来源当前的剩余次数和距下次触发时间，不补发已经结算的次数

控制技能规则（详见 §4）：
  - 冻结：无法行动，受击破冰+50%伤害，破冰后立即移除
  - 眩晕：无法行动，持续到时间结束
  - 沉默：无法放技能，可普攻+20%
  - 麻痹：持续期间新记录的技能行动冷却×1.3，可正常行动
  - 减速：出手CD×1.5
  - 禁疗：受到治疗效果-50%
  - 控制对普通/精英怪完整生效，对 Boss 效果减半（持续时间 × 0.5）
  - 坚毅状态免疫所有控制

护盾规则（详见 §5.2）：
  - 护盾数值可叠加，持续时间刷新为 5 秒
  - 护盾优先于 HP 被扣除
  - 过期后剩余护盾消失

贯穿规则（详见 §3.1）：
  - 贯穿技能同时攻击 2 个目标（前排 + 同行后排）
  - 两个目标独立判定命中/暴击/格挡
  - 若同行后排无目标 → 仅攻击前排（伤害正常结算）
  - 若前排全空 → 直接攻击后排位序最左目标（单一目标，无穿透，伤害按前排倍率结算）
```

## 7. 技能搭配策略

```
Build 思路取决于玩家对优先级的设定：

爆发流 + 控制流 + 生存流 = Boss 战标准 Build
  优先级建议：护盾(3) > 重击(2) > 冰冻射击(2) > 治疗波(1)

持续流 + Dot流 = 挂机清怪 Build
  优先级建议：毒刃(2) > 连击(1) > 烈焰灼烧(1) > 撕裂(1)

控制流 + 生存流 = 高难度磨血 Build
  优先级建议：治疗波(3) > 冰冻射击(2) > 眩晕锤(2) > 坚毅(2)

全持续流 × 6 = 极致 DPS Build
  6 个持续流技能全部优先级 1 → 从左到右轮流释放，几乎无空窗

控制流变体（麻痹+沉默+禁疗）：
  优先级建议：腐蚀之触(3) > 静默领域(2) > 雷霆一击(2) > 治疗波(1)
  特点：禁疗克制治疗怪，沉默控全场技能，麻痹压制Boss技能频率

贯穿流 + 爆发流 = 后排狙击 Build
  优先级建议：暗影突袭(3) > 裂地斩(2) > 致命一击(2) > 治疗波(1)
  特点：贯穿直击后排脆皮，爆发收割残血
```
